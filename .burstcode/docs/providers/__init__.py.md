## Summary

Lazy provider profile registry that discovers plugins from bundled and user directories, plus legacy single-file modules. User plugins override bundled ones on name collision via last-writer-wins semantics.

## Details

- `_REGISTRY` maps canonical names to `ProviderProfile` instances; `_ALIASES` maps aliases to canonical names
- `register_provider()` adds profile by name and aliases; later registrations replace earlier ones
- `get_provider_profile()` triggers lazy discovery on first call, resolves aliases
- `list_providers()` deduplicates by object identity to return unique profiles
- `_import_plugin_dir()` loads plugin `__init__.py` via `importlib.util.spec_from_file_location`; bundled plugins get stable `plugins.model_providers.<name>` import paths, user plugins get unique `_hermes_user_provider_<name>` names
- `_discover_providers()` runs in order: (1) bundled plugins at `plugins/model-providers/`, (2) user plugins at `$HERMES_HOME/plugins/model-providers/`, (3) legacy `providers/*.py` via `pkgutil.iter_modules`
- User plugins directory resolved via `hermes_constants.get_hermes_home()`
