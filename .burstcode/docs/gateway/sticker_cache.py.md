## Summary

Persistent JSON cache for Telegram sticker descriptions. Stores vision-generated descriptions keyed by `file_unique_id` to avoid re-analyzing identical stickers on every message.

## Details

- **Cache location**: `~/.hermes/sticker_cache.json` (resolved via `hermes_cli.config.get_hermes_home`).
- **Vision prompt**: Fixed concise prompt asking for 1-2 sentence descriptions focusing on character, action, and emotion.
- **API**: `get_cached_description()` and `cache_sticker_description()` for read/write; `build_sticker_injection()` and `build_animated_sticker_injection()` format descriptions into warm-style text for agent context.
- **Data shape**: Each entry stores `description`, `emoji`, `set_name`, and `cached_at` (Unix timestamp).
- **Error handling**: Gracefully handles missing files, JSON decode errors, and empty caches by returning `{}`.
