## Summary

Gateway runtime status and process lifecycle management. Provides PID-file tracking, cross-platform file locking, scoped identity locks, and takeover/planned-stop markers for graceful gateway handoffs and shutdowns.

## Details

- **PID & lock management**: Writes `gateway.pid` and `gateway.lock` under `HERMES_HOME`; uses `fcntl.flock` (POSIX) or `msvcrt.locking` (Windows) for mutual exclusion.
- **Process existence checks**: `_pid_exists()` avoids the Windows `os.kill(pid, 0)` footgun by using `psutil` or ctypes `OpenProcess`/`WaitForSingleObject`.
- **Runtime status persistence**: `gateway_state.json` tracks `gateway_state`, `active_agents`, per-platform states, and timestamps.
- **Scoped locks**: `acquire_scoped_lock()` prevents duplicate external identities (e.g., same Telegram bot token) across different `HERMES_HOME` directories; stale detection uses PID, start-time, cmdline, and `/proc/<pid>/status` state checks.
- **Takeover markers**: `write_takeover_marker()` / `consume_takeover_marker_for_self()` coordinate `--replace` handoffs so the target exits 0 instead of triggering systemd restart loops.
- **Planned stop markers**: Similar mechanism for intentional CLI stops to avoid non-zero exit codes confusing service managers.
- **Stale cleanup**: `get_running_pid()` auto-cleans orphaned PID/lock files when the runtime lock is inactive.
