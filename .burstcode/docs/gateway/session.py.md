## Summary

Core session management module handling context tracking, SQLite/JSONL persistence, reset policies, PII redaction, and dynamic system prompt injection.

## Details

- `SessionSource` and `SessionContext` dataclasses model message origins and connected platforms for system prompt generation.
- `build_session_context_prompt` injects platform-specific behavioral notes, delivery options, and optionally redacts PII for safe platforms.
- `SessionStore` manages session lifecycle: creation, expiration (idle/daily), suspension, resume-pending states, and transcript rewriting.
- Implements dual persistence (SQLite primary, JSONL fallback) with atomic writes and length-based fallback logic to prevent history truncation.
- `build_session_key` deterministically isolates sessions by platform, chat type, thread, and user ID based on config flags.
