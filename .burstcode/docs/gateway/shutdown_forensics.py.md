## Summary

Captures diagnostic context during gateway shutdown signals (SIGTERM/SIGINT) via fast synchronous snapshots and detached async subprocess probes.

## Details

- `snapshot_shutdown_context` gathers signal info, parent process details from `/proc`, systemd invocation markers, load averages, and takeover/planned-stop flags in <10ms.
- `spawn_async_diagnostic` fires a detached `bash` subprocess to run `ps`, `pstree`, and `dmesg`/`journalctl` without blocking the asyncio event loop.
- `check_systemd_timing_alignment` validates that `systemctl`'s `TimeoutStopSec` exceeds the configured drain timeout to prevent phantom SIGKILLs.
- Includes robust duration parsing for systemd unit files and safe signal-handler execution guarantees.
