## Summary

Renders a compact runtime-metadata footer (model, context usage, CWD) appended to the final agent response, with per-platform configuration overrides.

## Details

- `resolve_footer_config` merges built-in defaults, global `display.runtime_footer` settings, and per-platform overrides.
- `format_runtime_footer` conditionally renders requested fields, collapsing `$HOME` to `~` and stripping vendor prefixes from model names.
- `build_footer_line` acts as the top-level entry point for `gateway/run.py`, returning an empty string when disabled or lacking data.
- Designed to avoid cluttering streaming partials; only attaches to the final turn response.
