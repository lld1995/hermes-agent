## Summary

Appends delivery-mirror records to target session transcripts to maintain cross-platform message context.

## Details

- `mirror_to_session()` locates the active session ID by scanning `sessions.json` for matching platform/chat_id/thread_id/user_id.
- Writes a mirror message to both the JSONL transcript and SQLite database via `hermes_state.SessionDB`.
- Handles ambiguous session matches gracefully by returning `False` instead of contaminating unrelated sessions.
- Operates standalone without the full `SessionStore` machinery, making it safe for CLI, cron, and gateway contexts.
