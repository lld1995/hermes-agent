Yuanbao platform media module handling COS uploads, URL downloads, pure-Python image dimension parsing, and Tencent IM message body construction.

## Details

- **COS Uploads**: Fetches temporary credentials via `genUploadInfo`, signs requests with HMAC-SHA1, and uploads files to Tencent Cloud Object Storage using `httpx`.
- **Image Parsing**: Extracts width/height from JPEG, PNG, GIF, and WebP headers using pure Python (`struct`), avoiding heavy dependencies like Pillow.
- **URL Downloads**: Streams remote content with strict size limits, falling back gracefully if `HEAD` requests are unsupported.
- **TIM Message Builders**: Constructs `TIMImageElem` and `TIMFileElem` payloads with correct MIME mappings, format codes, and metadata for downstream protobuf serialization.
- **Utility Functions**: Provides MIME guessing, file ID generation, and MD5 hashing to support consistent media metadata across the Yuanbao integration.
