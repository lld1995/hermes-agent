## Summary

Generic webhook receiver adapter running an aiohttp server. Validates HMAC signatures, renders prompt templates, enforces idempotency and rate limits, and routes agent responses cross-platform or via direct delivery.

## Details

- Hosts aiohttp server at configurable host/port with `/webhooks/{route_name}` endpoints
- Validates signatures for GitHub (`X-Hub-Signature-256`), GitLab (`X-Gitlab-Token`), and generic HMAC-SHA256
- Renders prompt templates using dot-notation payload access and `{__raw__}` JSON dump
- Enforces idempotency via delivery ID cache and per-route fixed-window rate limiting
- Supports `deliver_only` mode for zero-LLM push notifications to external platforms
- Routes agent responses cross-platform via `gateway_runner.adapters` or GitHub CLI comments
- Hot-reloads dynamic routes from `webhook_subscriptions.json` on each request
- Binds delivery info by session chat_id with TTL pruning to prevent memory leaks
