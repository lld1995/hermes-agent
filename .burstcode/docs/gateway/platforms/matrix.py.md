## Summary

Implements a Matrix gateway adapter using the mautrix SDK, supporting E2EE, proxy routing, and reaction-based command approvals. It handles message syncing, media caching, text batching for client-side splits, and Markdown-to-HTML conversion with a regex fallback.

## Details

- **Core Functionality**: Connects to any Matrix homeserver via `mautrix`, managing authentication (access token or password), sync loops, and event dispatching.
- **E2EE Support**: Optional end-to-end encryption using `python-olm`, with SQLite-backed crypto state persistence, device key verification, and cross-signing bootstrap/recovery.
- **Message Handling**: Processes text, media (images, audio, video, documents), and voice messages. Implements startup grace periods, event deduplication, and filters out self-sent or bridge/system messages to prevent echo loops.
- **Text Batching**: Aggregates rapid successive messages to handle Matrix client-side splits (~4000 char limit), using configurable delay thresholds.
- **Reaction System**: Tracks processing lifecycle (eyes/checkmark/cross) and implements reaction-based approval prompts for dangerous commands (`✅`/`❎`), integrating with `tools.approval.resolve_gateway_approval`.
- **Proxy & Networking**: Supports HTTP(S) and SOCKS proxies via `aiohttp` or `aiohttp_socks`, with fallback to environment variables.
- **Formatting**: Converts Markdown to Matrix-compatible HTML using the `markdown` library or a comprehensive regex fallback, protecting code blocks and links.
- **Room & Presence Management**: Handles room creation, invites, DM detection, read receipts, and presence status updates.
