## Summary

Mattermost gateway adapter implementing REST API v4 and WebSocket communication. Handles authentication, message posting, file/image uploads, mention gating, channel whitelisting, and automatic WebSocket reconnection with exponential backoff.

## Details

- Extends `BasePlatformAdapter` to integrate with self-hosted or cloud Mattermost instances
- Uses `aiohttp` for both REST calls (`_api_get`/`_api_post`/`_api_put`) and persistent WebSocket listening
- Implements mention gating (`MATTERMOST_REQUIRE_MENTION`), channel whitelisting, and free-response channel overrides
- Downloads file attachments via authenticated API calls and caches them locally using `base.py` helpers (`cache_image_from_bytes`, etc.)
- WebSocket loop (`_ws_loop`) features exponential backoff, jitter, and permanent auth-failure detection to avoid infinite reconnect loops
- Deduplicates incoming posts using `helpers.MessageDeduplicator` and strips bot mentions before forwarding to `handle_message`
