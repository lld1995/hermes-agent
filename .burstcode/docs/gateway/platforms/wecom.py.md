## Summary

WebSocket-based adapter for WeCom AI Bots that handles subscription, inbound message parsing, text batching, media upload/download, and granular access policies.

## Details

- Implements `WeComAdapter` using aiohttp WebSockets for persistent bot connections
- Manages subscription handshake, heartbeat pings, and automatic reconnection with exponential backoff
- Parses inbound JSON callbacks, extracts text/media, and applies client-side message splitting aggregation
- Enforces DM/group policies via allowlists and per-group configuration
- Handles inbound media caching, base64 decoding, and AES-CBC decryption for encrypted file downloads
- Supports chunked media uploads, markdown replies, and proactive messaging via `aibot_send_msg`
- Includes a synchronous QR code scan flow (`qr_scan_for_bot_info`) for interactive bot credential provisioning
