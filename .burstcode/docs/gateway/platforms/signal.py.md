## Summary

Signal messenger adapter connecting to a signal-cli HTTP daemon. Handles inbound messages via SSE streaming and outbound actions via JSON-RPC 2.0, featuring markdown-to-Signal formatting, typing indicators with exponential backoff, reaction hooks, attachment caching, and recipient UUID resolution.

## Details

- Connects to `signal-cli` daemon over HTTP; inbound events arrive via SSE, outbound uses JSON-RPC
- Converts markdown to Signal's `bodyRanges`/`textStyles` format using UTF-16 code-unit offsets
- Implements typing indicator refresh with per-chat failure tracking and exponential cooldown to prevent log spam
- Supports reactions (👀/✅/❌) tied to processing lifecycle, gated by `SIGNAL_REACTIONS` and DM allowlists
- Handles attachments via base64 RPC fetch, magic-byte extension guessing, and local caching
- Resolves phone numbers to ACI/PNI UUIDs via `listContacts` RPC and caches mappings
- Integrates with `signal_rate_limit` module for batch pacing and retry-after handling
- Filters self-echoes, stories, and contentless envelopes to avoid wasted agent turns
