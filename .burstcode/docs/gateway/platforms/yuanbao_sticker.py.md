## Summary

Implements Yuanbao platform sticker (TIMFaceElem) support, including a built-in catalogue, fuzzy search, and wire-format message construction.

## Details

- Maintains `STICKER_MAP` with metadata (IDs, dimensions, descriptions) for ~50 built-in stickers.
- Provides `get_sticker_by_name` with fallback fuzzy matching and `search_stickers` using character multiset, bigram Jaccard, and subsequence scoring.
- `build_face_msg_body` and `build_sticker_msg_body` serialize sticker metadata into the `TIMFaceElem` JSON payload expected by the Yuanbao TIM protocol.
- Ported from a JavaScript plugin, ensuring compatibility with existing emoji packs.
