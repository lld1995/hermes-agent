## Summary

Email gateway adapter polling IMAP for inbound messages and replying via SMTP, featuring attachment caching, automated-sender filtering, and thread context tracking.

## Details

- Implements `EmailAdapter` using synchronous `imaplib` and `smtplib` wrapped in `run_in_executor` to avoid blocking the async event loop.
- Polls INBOX at configurable intervals, filtering automated/noreply senders via RFC headers and address patterns.
- Extracts multipart bodies, strips HTML fallback, and caches image/document attachments locally via `cache_image_from_bytes`/`cache_document_from_bytes`.
- Tracks `_seen_uids` with a capped sorted set to prevent unbounded memory growth across long-running sessions.
- Maintains `_thread_context` per sender to preserve `In-Reply-To`/`References` headers and subject threading for replies.
- Supports sending plain text, remote image URLs, and local file attachments via MIME multipart construction.
