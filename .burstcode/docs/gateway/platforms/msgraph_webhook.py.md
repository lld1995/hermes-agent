## Summary

Microsoft Graph webhook adapter that hosts an aiohttp server to receive change notifications. Validates subscriptions, filters by CIDR and HMAC clientState, deduplicates receipts, and renders payloads via templates or JSON.

## Details

- Extends `BasePlatformAdapter` but operates as an inbound webhook receiver rather than an outbound client
- Runs an `aiohttp.web.AppRunner` exposing health, validation (`GET`), and notification (`POST`) endpoints
- Enforces security via CIDR source allowlists (`allowed_source_cidrs`) and timing-safe HMAC verification of `clientState`
- Deduplicates notifications using a bounded deque (`_seen_receipt_order`) to prevent memory growth
- Renders incoming payloads using configurable Jinja-like templates or falls back to truncated JSON
- Schedules processed events via an optional `NotificationScheduler` or directly queues them as background tasks tracked in `self._background_tasks`
