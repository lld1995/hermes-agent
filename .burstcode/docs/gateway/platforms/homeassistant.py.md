## Summary

Implements a Home Assistant platform adapter that subscribes to WebSocket state-change events, filters them, and forwards formatted notifications to the agent.

## Details

- Connects to HA via WebSocket API, authenticates, and subscribes to `state_changed` events.
- Applies domain/entity filtering and per-entity cooldowns (`_last_event_time`) to prevent event floods.
- Formats state changes into human-readable messages based on entity domain (climate, sensor, light, etc.).
- Sends outbound replies via HA's REST API (`persistent_notification.create`) to avoid WebSocket race conditions.
- Handles automatic reconnection with exponential backoff and manages separate REST/WebSocket sessions.
