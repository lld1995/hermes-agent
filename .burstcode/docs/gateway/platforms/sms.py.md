## Summary

Twilio SMS adapter using an aiohttp webhook server for inbound messages and the Twilio REST API for outbound. Implements HMAC-SHA1 signature validation, message chunking, basic auth, and echo prevention for multi-tenant phone number routing.

## Details

- Runs an aiohttp server to receive Twilio webhooks at `/webhooks/twilio`
- Validates `X-Twilio-Signature` using HMAC-SHA1 over URL + sorted POST parameters, with port-variant fallback
- Strips markdown for SMS compatibility and chunks messages to ~1600 chars (~10 segments)
- Sends replies via Twilio REST API using HTTP Basic auth (`AccountSid:AuthToken`)
- Prevents echo loops by ignoring messages from the bot's own `TWILIO_PHONE_NUMBER`
- Supports insecure dev mode (`SMS_INSECURE_NO_SIGNATURE`) with explicit warnings
- Dispatches inbound messages asynchronously to avoid blocking Twilio's webhook timeout
- Returns empty TwiML immediately; all replies are pushed via REST API
