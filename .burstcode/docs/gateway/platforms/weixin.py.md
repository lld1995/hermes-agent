## Summary

Implements the Weixin (WeChat) platform adapter for Hermes, connecting to personal accounts via Tencent's iLink Bot API. It manages long-polling for inbound messages, AES-128-ECB encrypted media CDN transfers, QR-code login, and Markdown-to-WeChat formatting adaptations.

## Details

- **iLink API Integration**: Long-polls `getupdates` for inbound messages and uses `sendmessage`/`sendtyping` endpoints for outbound delivery.
- **Context Token Management**: `ContextTokenStore` persists per-peer `context_token` values to disk via atomic JSON writes, restoring them on startup to maintain conversation continuity.
- **Media Handling**: Downloads/uploads media through Tencent's CDN using AES-128-ECB encryption/decryption, with strict host allowlisting to prevent SSRF.
- **QR Login Flow**: Interactive terminal-based QR code generation and polling for initial account authentication and token persistence.
- **Markdown Adaptation**: Rewrites headers, tables, and code blocks for WeChat's limited renderer, and splits long messages into chat-friendly delivery units.
- **Resilience & Deduplication**: Implements message deduplication (ID + content hash), session-expired retry fallbacks (dropping `context_token`), and rate-limit backoff.
- **Direct Send Helper**: `send_weixin_direct` enables one-shot cron/CLI sends by reusing live adapter sessions or spinning up temporary ones, bypassing the long-poll lifecycle.
