## Summary

Implements the synchronous QR-code scan-to-configure registration flow, polling for completion and decrypting credentials.

## Details

- `qr_register()` orchestrates task creation, QR display, and result polling until completion or expiry.
- Uses synchronous `httpx.Client` and `time.sleep` for polling, refreshing the task up to 3 times on expiry.
- Integrates `crypto.py` to decrypt the `client_secret` and returns a dict with `app_id`, `client_secret`, and `user_openid`.
- Falls back to printing a URL if the `qrcode` library is unavailable.
