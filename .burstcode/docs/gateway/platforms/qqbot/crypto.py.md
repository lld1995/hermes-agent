## Summary

Provides AES-256-GCM utilities for securely generating ephemeral bind keys and decrypting bot credentials during QR onboarding.

## Details

- `generate_bind_key()` creates a 256-bit random key encoded in base64 for server-side encryption.
- `decrypt_secret()` parses the IV, ciphertext, and auth tag from the server response and decrypts the `client_secret`.
- Relies on `cryptography.hazmat.primitives.ciphers.aead.AESGCM` for authenticated encryption.
- Ensures the bot secret never traverses the network in plaintext during the scan-to-configure flow.
