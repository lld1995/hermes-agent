## Summary

Implements the QQ Bot v2 chunked upload flow for files exceeding inline size limits, handling preparation, concurrent part uploads to COS, and completion with retry logic.

## Details

- Orchestrates a three-step upload: `upload_prepare`, parallel `PUT` to pre-signed COS URLs, and `complete_upload`.
- Manages concurrency via `_run_with_concurrency` and handles platform-specific error codes (e.g., daily limit `40093002`, retryable `40093001`).
- Computes file hashes (`md5`, `sha1`, `md5_10m`) in a thread pool to avoid blocking the async event loop.
- Decouples from the main adapter by accepting `ApiRequestFn` and `http_put` callables, enabling isolated testing.
