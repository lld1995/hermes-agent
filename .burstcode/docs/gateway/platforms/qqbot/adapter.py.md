## Summary

Implements the QQ Bot platform adapter, managing WebSocket connections, REST API interactions, and message routing for C2C, group, and guild contexts. It handles inline keyboard interactions for approvals, voice-to-text transcription with multiple fallbacks, and chunked media uploads.

## Details

- Connects to QQ Bot Gateway via `aiohttp` WebSocket and uses `httpx` for REST API calls.
- Manages token lifecycle, session resumption, and heartbeat loops with exponential backoff reconnection.
- Routes inbound messages (C2C, Group, Guild, DM) through ACL policies and processes attachments (images, voice, files).
- Implements STT pipeline prioritizing QQ's built-in ASR, then external providers (Zhipu/GLM, OpenAI/Whisper), with `pilk`/`ffmpeg` fallbacks for SILK audio.
- Handles inline keyboard interactions for exec approvals and update prompts, routing clicks to `tools.approval.resolve_gateway_approval` or writing to `.update_response`.
- Supports chunked media uploads via `ChunkedUploader`, handling daily limits and file size constraints with appropriate error reporting.
- Implements cross-adapter gateway contracts (`send_exec_approval`, `send_update_prompt`) for consistent UX across platforms.
