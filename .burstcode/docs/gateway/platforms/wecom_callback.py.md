## Summary

HTTP callback adapter for WeCom self-built enterprise apps that decrypts encrypted XML payloads, deduplicates inbound messages, and routes them to the agent queue while acknowledging requests immediately.

## Details

- Implements `WecomCallbackAdapter` extending `BasePlatformAdapter`
- Runs an aiohttp server to handle GET verification and POST encrypted XML callbacks
- Uses `wecom_crypto.py` to decrypt payloads and validate signatures per configured app
- Maintains an in-memory `_seen_messages` dict with TTL-based pruning to handle WeCom retries
- Queues parsed `MessageEvent`s for async processing and sends replies proactively via the `message/send` API
- Manages per-app access tokens with automatic refresh before expiration
- Supports multiple apps scoped by `corp_id:user_id` to prevent cross-tenant collisions
