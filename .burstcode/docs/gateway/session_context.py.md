## Summary

Replaces process-global os.environ session state with contextvars.ContextVar to ensure concurrency-safe, task-local session tracking in the asyncio gateway.

## Details

- Defines `_SESSION_*` and `_CRON_AUTO_DELIVER_*` context variables with an `_UNSET` sentinel to distinguish "never set" from "explicitly cleared".
- `set_session_vars` and `clear_session_vars` manage variable lifecycles, returning tokens for cleanup.
- `get_session_env` provides a drop-in replacement for `os.getenv("HERMES_SESSION_*")`, falling back to environment variables only when the context variable is `_UNSET` (CLI/cron compat).
- Prevents concurrent message handlers from clobbering each other's routing metadata.
