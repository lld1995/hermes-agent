## Summary

Implements per-platform slash command access control, distinguishing between admin users and regular users across DM and group scopes.

## Details

- `SlashAccessPolicy` dataclass resolves gating rules, checking `admin_user_ids` and `user_allowed_commands` against incoming requests.
- `_ALWAYS_ALLOWED_FOR_USERS` ensures read-only commands like `/help` and `/whoami` remain accessible even when gating is active.
- `policy_for_source` extracts configuration from `gateway_config` and `SessionSource`, mapping chat types to DM/group scopes.
- Supports ergonomic YAML config with comma-separated strings, lists, or scalars, and allows DM scopes to inherit group command allowlists.
