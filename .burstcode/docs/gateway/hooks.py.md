## Summary

Lightweight event-driven hook system that discovers and executes user-defined Python handlers for gateway lifecycle events.

## Details

- `HookRegistry` scans `~/.hermes/hooks/` for directories containing `HOOK.yaml` and `handler.py`.
- Dynamically loads handlers via `importlib`, registering them in `sys.modules` to support forward references and Pydantic models.
- Fires events like `gateway:startup`, `session:start`, and `command:*` (wildcard support) with both sync and async handler support.
- Errors are caught and logged without blocking the main pipeline; `emit_collect()` captures return values for decision-style hooks.
