## Summary

FastAPI backend for the Hermes Achievements dashboard plugin. Scans session history, extracts metrics via regex heuristics, evaluates tiered and multi-condition achievements, and serves cached results through REST endpoints.

## Details

- Mounts at `/api/plugins/hermes-achievements/` and exposes routes for achievements, scan status, recent unlocks, session badges, manual rescans, and state resets.
- Uses `SessionDB` to fetch session metadata and messages, applying a fingerprint-based checkpoint cache to avoid re-analyzing unchanged sessions.
- `analyze_messages` extracts tool calls, error patterns, file touches, and activity signals using compiled regexes (`ERROR_RE`, `INSTALL_RE`, `FILE_RE`, etc.).
- `aggregate_stats` computes lifetime and best-session metrics, including model/provider diversity and weekend/night session counts.
- `evaluate_tiered` and `evaluate_requirements` calculate progress, tier unlocks, and secret/discovered states against the `ACHIEVEMENTS` catalog.
- Long scans run in a daemon thread (`_run_scan_and_update_cache`), publishing partial snapshots every ~250 sessions to keep the UI responsive.
- Persists state, snapshots, and checkpoints under `$HERMES_HOME/plugins/hermes-achievements/`.
