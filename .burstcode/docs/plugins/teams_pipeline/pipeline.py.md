## Summary

Core orchestration for Teams meeting summaries. Manages job lifecycle, resolves meetings, fetches transcripts or falls back to recording STT, generates LLM/heuristic summaries, and writes results to Notion, Linear, and Teams sinks.

## Details

- Implements `TeamsMeetingPipeline` with durable state persistence via `TeamsPipelineStore`.
- Prioritizes native transcripts, falling back to recording download + ffmpeg extraction + STT if unavailable.
- Generates summaries via `async_call_llm` with a JSON schema prompt, degrading to heuristic parsing on failure.
- Dispatches results to `NotionWriter`, `LinearWriter`, and a configurable Teams sender.
