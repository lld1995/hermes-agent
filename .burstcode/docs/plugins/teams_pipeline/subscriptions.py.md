## Summary

Microsoft Graph subscription lifecycle manager. Syncs remote subscriptions with the local store, validates expiration, and renews managed subscriptions via `MicrosoftGraphClient` while tracking renewal status.

## Details

- Defines helpers to build `MicrosoftGraphClient` and parse datetime/boolean values from Graph payloads.
- `sync_graph_subscription_record()` normalizes and upserts subscription data into the local store.
- `is_managed_subscription()` checks if a subscription is tracked locally or matches an expected client state.
- `maintain_graph_subscriptions()` iterates remote subscriptions, syncs them, identifies expiring ones, and patches expiration dates via Graph API.
- Returns detailed maintenance reports including synced, renewed, and skipped subscription counts.
