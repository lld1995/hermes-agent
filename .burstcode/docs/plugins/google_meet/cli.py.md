## Summary

CLI command handlers for the Google Meet plugin. Implements `hermes meet` subcommands for setup, install, auth, join, status, transcript, say, stop, and remote node management.

## Details

- **setup**: Preflight check for platform, playwright, chromium, and Google auth state
- **install**: Installs pip deps (playwright, websockets), Chromium browser, and optional platform audio tools (pulseaudio-utils on Linux, BlackHole+ffmpeg on macOS)
- **auth**: Opens headed Chromium for Google sign-in, saves `storage_state` to `workspace/meetings/auth.json`
- **join**: Validates URL is `meet.google.com`, supports local and remote node execution, accepts guest_name, duration, headed, and mode (transcribe/realtime)
- **say**: Enqueues speech text for active realtime meeting, supports remote nodes
- **status/transcript/stop**: Query and control the Meet bot via process manager
- **node**: Remote node management (run/list/approve/remove/status/ping) with lazy import fallback
- **Auth state**: Stored at `$HERMES_HOME/workspace/meetings/auth.json`
- **Remote execution**: Uses `NodeRegistry` and `NodeClient` for distributed Meet bot hosting
