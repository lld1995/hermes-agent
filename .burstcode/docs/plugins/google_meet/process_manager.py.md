## Summary

Subprocess lifecycle manager for the Meet bot. Spawns detached `meet_bot.py` instances, tracks active sessions in `.active.json`, and provides local APIs for status checks, transcript reading, speech queueing, and graceful termination.

## Details

- Enforces single-active-meeting semantics; stops existing bots before spawning new ones.
- Spawns `meet_bot.py` with detached I/O, capturing logs to `bot.log` and passing config via env vars.
- `status` and `transcript` read bot-written files, merging `.active.json` metadata with live `status.json`.
- `enqueue_say` validates `realtime` mode before appending to `say_queue.jsonl`.
- `stop` sends SIGTERM, polls for exit, falls back to SIGKILL, and clears the active pointer.
