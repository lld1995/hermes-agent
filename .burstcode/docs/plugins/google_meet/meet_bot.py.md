## Summary

Headless Playwright bot for Google Meet that scrapes live captions via DOM observers and supports v2 realtime agent speech. Handles lobby admission, duration limits, and graceful shutdown while routing synthesized audio through virtual audio bridges.

## Details

- Spawns as a detached subprocess, reading config from env vars and writing state/transcripts to disk.
- Injects JavaScript to observe caption containers via `MutationObserver` and drains entries into a deduplicated transcript file.
- Implements v2 realtime mode: provisions virtual audio devices (PulseAudio/BlackHole), starts an OpenAI Realtime speaker thread, and handles barge-in cancellation when humans speak.
- Manages admission detection, lobby timeouts, and clean exit via SIGTERM/SIGINT handlers.
- Strictly validates `meet.google.com` URLs before navigation.
