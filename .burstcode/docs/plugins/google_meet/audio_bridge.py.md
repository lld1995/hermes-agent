## Summary

Virtual audio bridge for feeding generated speech into Chrome's microphone input. Provisions platform-specific virtual audio devices (PulseAudio null-sink on Linux, BlackHole on macOS) for the Meet bot's Chromium instance.

## Details

- **Linux**: Uses `pactl` to load `module-null-sink` and `module-virtual-source`, creating a virtual microphone that Chrome can read
- **macOS**: Verifies BlackHole 2ch installation via `system_profiler`; does not auto-switch system audio input
- **Windows**: Explicitly unsupported
- **Lifecycle**: `setup()` provisions the device, `teardown()` unloads PulseAudio modules (idempotent)
- **Rollback**: If virtual-source creation fails, unloads the null-sink to prevent leaks
- **Chrome flags**: `chrome_fake_audio_flags()` returns `--use-fake-ui-for-media-stream` to skip permission prompts
- **Environment**: Callers must set `PULSE_SOURCE=<device_name>` in Chrome's env on Linux
- Returns device metadata (name, sample_rate, channels, module_ids, write_target) for downstream use
