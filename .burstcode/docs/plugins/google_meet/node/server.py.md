## Summary

WebSocket server for remote bot hosts. Validates incoming RPC requests against a persisted token, dispatches commands to `process_manager`, and directly writes speech requests to the bot's JSONL queue.

## Details

- Generates and persists a 32-char hex token on first boot, restricting file permissions to owner-only.
- `_handle_request` validates envelopes, routes `ping`/`start_bot`/`stop`/`status`/`transcript` to `process_manager`.
- `say` handler bypasses `process_manager` and writes directly to `say_queue.jsonl` in the active meeting's output directory.
- Runs an async WebSocket server loop that decodes raw frames, dispatches handlers, and encodes replies.
