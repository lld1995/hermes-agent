## Summary

OpenAI Realtime API WebSocket client and queue-driven speaker. Manages session setup, text-to-audio synthesis, PCM file writing, barge-in cancellation, and polls a JSONL queue to sequentially process speech requests.

## Details

- `RealtimeSession` handles WS connection, session configuration, and synchronous `speak()` calls that block until audio deltas are fully received.
- Decodes base64 audio chunks and appends them to a PCM sink file for external consumption.
- `cancel_response` sends `response.cancel` to interrupt in-flight generation (barge-in).
- `RealtimeSpeaker` polls `queue_path`, processes entries sequentially, tracks processed items, and handles queue rewriting to avoid race conditions.
