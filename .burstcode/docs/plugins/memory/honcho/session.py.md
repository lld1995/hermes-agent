## Summary

Manages conversation sessions backed by the Honcho AI-native memory system, providing local caching, async message syncing, dialectic querying, and migration of legacy local memory files.

## Details

- `HonchoSession` dataclass caches messages locally and tracks sync state.
- `HonchoSessionManager` orchestrates peer creation, observation settings, and session lifecycle.
- Supports configurable write frequencies (`async`, `turn`, `session`, or N turns) with a background daemon thread for non-blocking syncs.
- Implements dialectic querying and context prefetching to avoid blocking the main agent loop.
- Migrates legacy local memory files (`MEMORY.md`, `USER.md`, `SOUL.md`) and conversation history to Honcho upon activation.
- Uses `threading.RLock` and `Lock` to protect shared caches and prefetch results.
