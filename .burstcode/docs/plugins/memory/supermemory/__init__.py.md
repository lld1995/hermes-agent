## Summary

Supermemory memory plugin implementing the MemoryProvider interface. Provides semantic long-term memory with profile recall, multi-container support, explicit memory tools, cleaned turn capture, and session-end conversation ingest via the Supermemory Python SDK.

## Details

- Implements `MemoryProvider` with tools: `supermemory_store`, `supermemory_search`, `supermemory_forget`, `supermemory_profile`
- `_SupermemoryClient` wraps the `supermemory` Python SDK with container tag scoping and search mode selection
- Config loaded from `$HERMES_HOME/supermemory.json` with extensive defaults: container tags, auto-recall/capture toggles, profile frequency, entity context, search mode
- Multi-container support: optional `container_tag` parameter on tools, validated against an allowlist
- `prefetch()` fetches profile (static/dynamic facts) and search results, formatted with deduplication and relative timestamps
- `sync_turn()` captures conversation turns asynchronously, filtering trivial messages and stripping existing context tags
- `on_session_end()` ingests full conversation history via direct HTTP POST to Supermemory conversations endpoint
- `on_memory_write()` mirrors explicit memory additions with category detection
- Thread-safe with per-operation daemon threads; `shutdown()` joins all background threads
