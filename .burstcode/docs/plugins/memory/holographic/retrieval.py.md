## Summary

Implements FactRetriever, a hybrid search engine combining SQLite FTS5, Jaccard similarity, and Holographic Reduced Representation (HRR) vectors for trust-weighted memory retrieval.

## Details

- Provides multi-strategy retrieval via `search`, `probe`, `related`, `reason`, and `contradict` methods.
- Pipeline: FTS5 candidate generation → Jaccard token overlap reranking → HRR vector similarity → trust-score weighting → optional temporal decay.
- Automatically redistributes search weights (FTS5/Jaccard) when `numpy` is unavailable, falling back to keyword search for compositional queries.
- Strips raw HRR bytes from results to ensure JSON serializability for downstream consumers.
