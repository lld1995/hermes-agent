## Summary

RetainDB cloud memory plugin implementing the MemoryProvider interface. Provides semantic search, user profile retrieval, dialectic synthesis, agent self-modeling from SOUL.md, and a shared file store. Uses a durable SQLite write-behind queue for crash-safe async session ingest.

## Details

- Implements `MemoryProvider` with tools: `retaindb_profile`, `retaindb_search`, `retaindb_context`, `retaindb_remember`, `retaindb_forget`, plus file tools (upload, list, read, ingest, delete)
- `_Client` wraps synchronous `requests` calls to RetainDB REST API with Bearer auth and project scoping
- `_WriteQueue` uses SQLite-backed pending table for crash-safe async session ingest; replays unflushed rows on startup
- Background prefetch threads fetch context overlay, dialectic synthesis, and agent model at turn-end; consumed at next turn-start
- Seeds agent identity from `SOUL.md` in background during `initialize()`
- `_build_overlay` deduplicates profile and query results against local entries
- Config via `RETAINDB_API_KEY`, `RETAINDB_BASE_URL`, `RETAINDB_PROJECT` env vars or `hermes config.yaml`
- `on_memory_write` mirrors built-in memory additions to RetainDB
- `shutdown()` joins prefetch threads and drains write queue
