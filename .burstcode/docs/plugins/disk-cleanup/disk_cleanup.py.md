## Summary

Core library for ephemeral file cleanup. Implements deterministic cleanup rules by category (test, temp, cron-output, research, chrome-profile), atomic JSON tracking, and path safety checks scoped to HERMES_HOME.

## Details

- **Cleanup rules**:
  - test files: delete immediately (age ≥ 0)
  - temp files: delete after 7 days
  - cron-output: delete after 14 days
  - research: keep 10 newest, prompt for older (deep only)
  - chrome-profile: prompt after 14 days (deep only)
  - >500 MB files: prompt always (deep only)
- **Path safety**: `is_safe_path()` rejects paths outside HERMES_HOME and `/tmp/hermes-*`, blocks Windows mounts and system directories
- **Tracking**: `tracked.json` with atomic write (`.tmp` → backup → rename), auto-restores from `.bak` on corruption
- **Auto-categorization**: `guess_category()` classifies paths by directory (cron→cron-output, cache→temp) and filename patterns (test_*, *.test.py→test)
- **Protected dirs**: Never deletes top-level state dirs (logs, memories, sessions, skills, plugins, etc.)
- **Audit log**: Appends to `cleanup.log` with timestamps; failures are silently caught
- **Deep cleanup**: Interactive mode with `confirm` callable for risky deletions
