## Summary

Disk cleanup plugin that auto-tracks ephemeral files created by tool calls and cleans them up at session end. Wires `post_tool_call` and `on_session_end` hooks, plus a `/disk-cleanup` slash command.

## Details

- **Auto-tracking**: `post_tool_call` hook inspects `write_file`, `patch`, and `terminal` tool results for newly-created paths matching test/temp patterns
- **Path extraction**: Parses `write_file` args directly, extracts paths from terminal commands via `shlex.split` and regex on output (limited to 4KB)
- **Per-task tracking**: Uses `_recent_test_tracks` dict keyed by task_id/session_id, guarded by a threading lock for concurrent tool calls
- **Session-end cleanup**: `_on_session_end` drains tracked paths and runs `disk_cleanup.quick()` if any test files were tracked
- **Slash command**: `/disk-cleanup` with subcommands: status, dry-run, quick, deep, track, forget
- **Registration**: Wires hooks and command via `register(ctx)` pattern
- Delegates all cleanup logic to `disk_cleanup.py` library module
