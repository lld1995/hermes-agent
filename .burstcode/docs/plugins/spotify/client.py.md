## Summary

Thin HTTP client for the Spotify Web API. Handles credential resolution, request execution with automatic 401 retry, structured error shaping, and playback/search/playlist/library operations. Includes helpers for normalizing Spotify URIs and IDs.

## Details

- Wraps `httpx` requests with a 30s timeout and automatic token refresh on 401 responses.
- Translates raw HTTP errors into `SpotifyAPIError` with friendly messages for playback, rate limits, and scope issues.
- Provides methods for player control, queue management, catalog search, playlist manipulation, and library operations.
- Includes `normalize_spotify_id` and `normalize_spotify_uri` utilities to handle various input formats (IDs, URIs, web URLs).
