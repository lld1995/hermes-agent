## Summary

LINE Messaging API platform adapter implementing an aiohttp webhook server, signature verification, markdown stripping, and a slow-LLM postback button state machine. Handles media serving with path traversal guards and provides standalone cron delivery.

## Details

- Runs an `aiohttp` webhook server to accept and verify LINE events via HMAC-SHA256 signatures.
- Implements a `RequestCache` state machine (PENDING → READY → DELIVERED/ERROR) to handle slow LLM responses by sending a tappable postback button before the 60s reply token expires.
- Strips unsupported Markdown while preserving bare URLs for LINE's auto-linking.
- Serves outbound media via temporary HTTPS URLs (`/line/media/<token>/<filename>`) guarded against directory traversal.
- Provides `_standalone_send` for out-of-process cron job delivery, bypassing the live adapter.
- Registers via `register(ctx)` with env-var enablement and interactive setup hooks.
