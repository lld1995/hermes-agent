## Summary

Microsoft Teams platform adapter bridging the `microsoft-teams-apps` SDK to an aiohttp webhook server. Handles message processing, Adaptive Card approvals, meeting summary delivery, and standalone cron dispatch with strict security validation.

## Details

- Bridges the Teams SDK's HTTP routing into a custom `aiohttp.web.Application` via `_AiohttpBridgeAdapter` to avoid FastAPI/uvicorn dependencies.
- Processes inbound messages, strips `@mention` tags, caches `ConversationReference` objects, and handles image attachments via `cache_image_from_url`.
- Implements `TeamsSummaryWriter` for meeting pipeline delivery via Incoming Webhooks or Microsoft Graph API.
- Manages command approvals using Adaptive Cards with `ExecuteAction` buttons, enforcing `TEAMS_ALLOWED_USERS` or `TEAMS_ALLOW_ALL_USERS` gates.
- Provides `_standalone_send` for cron jobs, acquiring Bot Framework bearer tokens and validating `service_url` against an allowlist to prevent SSRF.
- Registers via `register(ctx)` with env-seeding and interactive CLI setup.
