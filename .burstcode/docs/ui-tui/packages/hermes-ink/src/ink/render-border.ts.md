## Summary

Renders box borders with configurable styles, per-edge colors, dimming, and embedded text positioning (top/bottom borders with start/end/center alignment).

## Details

- Supports `cli-boxes` styles plus custom `dashed` style
- Per-edge color control: `borderTopColor`, `borderBottomColor`, `borderLeftColor`, `borderRightColor`
- Per-edge dimming: `borderTopDimColor`, etc.
- `borderText` option embeds pre-rendered ANSI content into top or bottom border lines
- `embedTextInBorder()`: positions text with start/end/center alignment and optional offset
- Computes content width accounting for visible left/right borders
- Writes border segments via `output.write()` at computed positions
- Handles partial borders (e.g., `borderTop: false`)
