## Summary

Core terminal rendering engine that collects write/blit/clear/clip/shift/noSelect operations, applies them to a Screen buffer with clipping and absolute-node ghost prevention, and caches grapheme-clustered characters across frames.

## Details

- `Output` class collects operations (`write`, `blit`, `clear`, `clip`, `unclip`, `shift`, `noSelect`) and applies them in `get()`
- `charCache`: `Map<string, ClusteredChar[]>` persists across frames; capped at 16384 entries
- Two-pass execution: pass 1 expands damage regions and collects absolute clears; pass 2 applies all operations
- Clip stack supports nested `overflow:hidden` via `intersectClip()`
- Blit operations exclude cells covered by absolute-positioned node clears to prevent ghost artifacts
- `writeLineToScreen` handles ANSI tokenization, grapheme clustering, BIDI reordering, tab expansion, control char skipping, and wide-char edge cases
- `noSelect` operations applied last so they win over blits and writes
- Debug logging when write ratio exceeds blit ratio (suggests blitting isn't working)
