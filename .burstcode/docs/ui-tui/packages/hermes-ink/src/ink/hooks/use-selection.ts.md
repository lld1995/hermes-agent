## Summary

React hooks for text selection operations in fullscreen mode. `useSelection` exposes copy, clear, shift, and capture methods; `useHasSelection` provides reactive selection-exists state via useSyncExternalStore.

## Details

- `useSelection()`: Returns an object with methods for:
  - `copySelection` / `copySelectionNoClear`: Copy selected text
  - `clearSelection`: Clear the selection
  - `hasSelection`: Check if text is selected
  - `getState`: Read raw mutable selection state
  - `subscribe`: Subscribe to selection mutations
  - `shiftAnchor` / `shiftSelection`: Move selection points with clamping
  - `moveFocus`: Keyboard selection extension (shift+arrow)
  - `captureScrolledRows`: Capture text from rows about to scroll out
  - `setSelectionBgColor`: Set selection highlight color (theme-piping)
  - `version`: Monotonic counter for selection mutations
- `useHasSelection()`: Reactive boolean via `useSyncExternalStore`, always false outside fullscreen mode
- Both hooks look up Ink instance via `instances.get(process.stdout)`
