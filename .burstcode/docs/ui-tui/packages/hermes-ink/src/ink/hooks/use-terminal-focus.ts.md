## Summary

React hook that reports whether the terminal currently has focus, using DECSET 1004 focus reporting escape sequences handled automatically by Ink.

## Details

- Returns `boolean`: true if terminal is focused (or focus state is unknown)
- Uses `TerminalFocusContext` for the focus state
- Focus reporting is handled at the Ink level; escape sequences are filtered from `useInput`
- Default value is true (unknown state treated as focused)
