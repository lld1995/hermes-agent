## Summary

React hook that declares where the terminal cursor should be parked after each frame. Uses CursorDeclarationContext and nodeCache rects to position the cursor relative to a Box, with careful handling of sibling handoff and memoization hazards.

## Details

- Returns a ref callback to attach to the Box containing the input
- Declares `(line, column)` relative to the Box's `nodeCache` rect
- Uses `useLayoutEffect` (no deps) to re-declare every commit, handling:
  - Memoized inactive instances that don't re-render
  - Sibling handoff where focus moves opposite to sibling order
- Conditional clearing: only clears if the currently-declared node matches, preventing clobbering
- Separate cleanup effect with empty deps fires once on unmount
- Timing: layout effects fire before `onRender`'s microtask, so the declaration is fresh on the first frame
