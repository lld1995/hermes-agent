## Summary

React hook and utility for running external processes while temporarily suspending the Ink TUI. Enters alternate screen before execution and exits afterward, preserving the TUI state.

## Details

- `withInkSuspended(run)`: Looks up the Ink instance via `instances.get(process.stdout)`, enters alternate screen, runs the async function, then exits alternate screen in a `finally` block
- `useExternalProcess()`: Returns a memoized callback wrapping `withInkSuspended`
- If no Ink instance exists, runs the function directly without screen switching
