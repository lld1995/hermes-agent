## Summary

React hook for declaratively setting the terminal tab-status indicator via OSC 21337. Emits colored dots and status text for idle/busy/waiting states, with automatic cleanup on null transitions.

## Details

- `useTabStatus(kind)`: Accepts `'idle' | 'busy' | 'waiting' | null`
- Emits OSC 21337 sequences with preset colors:
  - idle: green dot, gray "Idle"
  - busy: orange dot, orange "Working…"
  - waiting: blue dot, blue "Waiting"
- Pass `null` to opt out; emits `CLEAR_TAB_STATUS` if a status was previously set
- Wrapped for tmux/screen passthrough via `wrapForMultiplexer`
- Terminals without OSC 21337 support discard the sequence silently
- Uses `TerminalWriteContext` for raw terminal writes
