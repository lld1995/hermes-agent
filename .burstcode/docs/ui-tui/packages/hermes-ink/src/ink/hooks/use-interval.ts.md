## Summary

React hooks backed by the shared ClockContext for time-based updates. `useAnimationTimer` returns clock time at a given interval; `useInterval` fires a callback at intervals. Both piggyback on the single shared clock.

## Details

- `useAnimationTimer(intervalMs)`: Returns elapsed clock time, updating at the given interval. Subscribes as non-keepAlive (won't drive the clock alone).
- `useInterval(callback, intervalMs)`: Fires callback at the given interval. Pass `null` to pause. Uses a ref to track the latest callback.
- Both hooks subscribe to `ClockContext` rather than creating independent `setInterval` timers, consolidating wake-ups into one clock tick.
