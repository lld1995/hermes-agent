## Summary

React hook for handling user keyboard input. Registers a stable listener on the stdin emitter, manages raw mode toggling via useLayoutEffect, and respects isActive gating and Ctrl+C exit behavior.

## Details

- `useInput(handler, options)`: Calls the handler for each keystroke or pasted text
- Uses `useLayoutEffect` to enable raw mode synchronously during React's commit phase (prevents cooked-mode echo)
- Listener registration is stable (no re-append on `isActive` toggle) to preserve `stopImmediatePropagation()` ordering
- Uses `useEventCallback` to keep handler reference stable while reading latest closure values
- Respects `exitOnCtrlC` flag: if true, Ctrl+C bypasses the handler and exits the app
- `isActive: false` disables the handler without unregistering the listener
