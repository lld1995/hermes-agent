## Summary

React hook for synchronized animations that pause when offscreen. Subscribes to a shared ClockContext and useTerminalViewport visibility, returning a ref and elapsed time. Animations auto-slow when the terminal is blurred.

## Details

- Returns `[ref, time]` tuple: ref to attach to the animated element, elapsed time in ms
- Uses `ClockContext` for a shared clock across all animation instances
- Subscribes with `keepAlive: true` when visible, driving the clock
- Pass `null` for `intervalMs` to pause (unsubscribes from clock)
- Integrates with `useTerminalViewport` to auto-pause when element scrolls offscreen
- Terminal blur is handled by the clock itself, not by consumers
