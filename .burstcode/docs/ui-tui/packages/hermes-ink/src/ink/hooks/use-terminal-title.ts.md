## Summary

React hook for declaratively setting the terminal tab/window title. Strips ANSI escapes automatically, uses OSC 0 on Unix and process.title on Windows.

## Details

- `useTerminalTitle(title)`: Accepts a string or `null` to opt out
- Strips ANSI escape sequences via `strip-ansi` before setting
- On Windows: sets `process.title` (classic conhost doesn't support OSC)
- On Unix: writes OSC 0 (set title+icon) via `TerminalWriteContext`
- Pass `null` to leave the terminal title untouched
