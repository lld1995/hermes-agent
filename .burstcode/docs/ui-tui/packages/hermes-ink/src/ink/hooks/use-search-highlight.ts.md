## Summary

React hook for screen-space search highlighting. Sets a query that inverts all visible occurrences on the next frame, and supports position-based current-match highlighting with scroll offset tracking.

## Details

- Returns `{ setQuery, scanElement, setPositions }`
- `setQuery(query)`: Non-empty query inverts all visible occurrences (SGR 7, screen-buffer overlay). Empty clears.
- `scanElement(el)`: Paints a DOM subtree to a fresh Screen and returns match positions (element-relative)
- `setPositions(state)`: Sets the current highlight position with scroll offset tracking. Overlays on top of the scan-highlight.
- Highlights RENDERED text, not source text — truncated/ellipsized matches won't highlight
- Looks up Ink instance via `instances.get(process.stdout)`
