## Summary

React hook for detecting if a component is within the terminal viewport. Returns a ref and visibility entry, updated during layout phase without triggering re-renders to avoid infinite loops.

## Details

- Returns `[ref, { isVisible }]` tuple
- Uses `useLayoutEffect` (no deps) to walk the DOM ancestor chain and compute absolute position
- Subtracts `scrollTop` from scroll containers to handle scrolled-into-view elements
- Accounts for cursor-restore scroll (1 extra row into scrollback when content overflows)
- Updates a ref (not state) to avoid cascading re-renders during the commit phase
- Visibility changes don't trigger re-renders; callers pick up fresh values during their own renders
- Walks DOM parent chain (not yoga.getParent()) to detect scroll containers
