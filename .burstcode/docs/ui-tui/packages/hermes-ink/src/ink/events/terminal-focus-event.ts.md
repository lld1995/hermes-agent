## Summary

Terminal window focus event for DECSET 1004 focus reporting, distinguishing terminal-level focus from component-level focus.

## Details

- Extends `Event` with `type` property of `'terminalfocus'` or `'terminalblur'`
- Fired when the terminal window itself gains or loses focus (not component focus within the app)
- Uses DECSET 1004 escape sequences: `CSI I` (\x1b[I) for focus gained, `CSI O` (\x1b[O) for focus lost
- Separate from `FocusEvent` which handles component-level focus changes within the Ink tree
