## Summary

Event dispatcher implementing React-style two-phase (capture/bubble) propagation with priority-based scheduling for discrete and continuous events.

## Details

- `collectListeners` walks target→root, prepending capture handlers and appending bubble handlers
- `processDispatchQueue` executes listeners with propagation control (`stopPropagation`, `stopImmediatePropagation`)
- `getEventPriority` maps event types to React priorities: discrete (keydown, click, focus) vs continuous (resize, scroll, mousemove)
- `Dispatcher.dispatch` sets `currentEvent` for reconciler priority inference
- `dispatchDiscrete` wraps dispatch in `discreteUpdates` for sync user-initiated events
- `dispatchContinuous` temporarily elevates priority for high-frequency events
