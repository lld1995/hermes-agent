## Summary

Keyboard event class mirroring browser KeyboardEvent semantics, with literal character keys for printable keys and named keys for specials.

## Details

- Extends `TerminalEvent` with `key`, `ctrl`, `shift`, `meta`, `superKey`, and `fn` properties
- `keyFromParsed` maps `ParsedKey` to browser-compatible key strings:
  - Ctrl combos: returns the letter name (e.g., `'c'` for Ctrl+C)
  - Single printable chars (0x20–0x7E): returns the literal character
  - Special keys: returns the parsed name (e.g., `'ArrowDown'`, `'return'`)
- Bubbles and is cancelable, matching browser `keydown` semantics
