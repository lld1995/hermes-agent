## Summary

Focus event class for component focus changes, carrying the related target and bubbling to match browser focusin/focusout semantics.

## Details

- Extends `TerminalEvent` with `relatedTarget` property (the element gaining/losing focus)
- Constructor accepts `'focus'` or `'blur'` type with optional `relatedTarget`
- Both focus and blur events bubble (`bubbles: true`), enabling parent components to observe descendant focus changes
- Matches react-dom's use of `focusin`/`focusout` rather than non-bubbling `focus`/`blur`
