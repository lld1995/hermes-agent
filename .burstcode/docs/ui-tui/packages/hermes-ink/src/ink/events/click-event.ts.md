## Summary

Mouse click event class with screen coordinates, local-relative offsets, and blank-cell detection for ignoring clicks on empty terminal space.

## Details

- Extends `Event` with `col`, `row`, `localCol`, `localRow`, and `cellIsBlank` properties
- `localCol`/`localRow` are recomputed by `dispatchClick` before each handler fires, relative to the handler's Box
- `cellIsBlank` is true when the clicked screen buffer cell has no visible content (both packed words are 0)
- Bubbles from deepest hit node; `stopImmediatePropagation()` prevents ancestor handlers from firing
