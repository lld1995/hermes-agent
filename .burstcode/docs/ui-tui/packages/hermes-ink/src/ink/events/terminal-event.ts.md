## Summary

Base terminal event class implementing DOM-style propagation with target, currentTarget, eventPhase, stopPropagation, and preventDefault.

## Details

- Extends `Event` with `type`, `timeStamp`, `bubbles`, `cancelable` properties
- Private state: `_target`, `_currentTarget`, `_eventPhase`, `_propagationStopped`, `_defaultPrevented`
- `stopPropagation()` stops further bubbling; `stopImmediatePropagation()` also halts same-node handlers
- `preventDefault()` sets `_defaultPrevented` if the event is cancelable
- Internal `_setTarget`, `_setCurrentTarget`, `_setEventPhase` setters used by `Dispatcher`
- `_prepareForTarget` hook allows subclasses to do per-node setup before each handler fires
- `EventTarget` type defines the minimal interface for nodes in the propagation chain
