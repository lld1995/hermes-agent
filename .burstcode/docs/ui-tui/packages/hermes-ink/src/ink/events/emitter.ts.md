## Summary

EventEmitter wrapper that respects React-style `stopImmediatePropagation()` on the first argument when it's an Event instance.

## Details

- Extends Node's `EventEmitter` with `setMaxListeners(0)` to suppress spurious warnings from many React hooks
- `emit` delegates to parent for `'error'` events (special Node.js semantics)
- For other events, iterates listeners and breaks early if the first arg is an `Event` with `didStopImmediatePropagation()`
- Bridges Node.js event semantics with React's propagation control model
