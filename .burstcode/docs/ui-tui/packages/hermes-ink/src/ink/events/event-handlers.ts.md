## Summary

Type definitions and lookup tables mapping terminal event types to React-style handler prop names for capture and bubble phases.

## Details

- Defines handler function types for keyboard, focus, paste, resize, click, mouse, and hover events
- `EventHandlerProps` type follows React convention: `onEventName` (bubble) and `onEventNameCapture` (capture)
- `HANDLER_FOR_EVENT` maps event type strings to `{ bubble, capture }` prop name pairs for O(1) lookup
- `EVENT_HANDLER_PROPS` Set lists all handler prop names so the reconciler can store them in `_eventHandlers` instead of attributes
