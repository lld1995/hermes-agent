## Summary

Single-pass text measurement utility that computes both width and wrapped height for a string given a max width, using `indexOf` to avoid array allocations from `split('\n')`.

## Details

- Imports `lineWidth` from `line-width-cache.js` for per-line width computation
- Handles empty strings (returns 0,0) and non-positive/infinite `maxWidth` (no wrapping)
- Iterates lines via `indexOf('\n')` to avoid intermediate array allocation
- Tracks max line width and accumulates wrapped height using `Math.ceil(w / maxWidth)`
- Single-pass design avoids the two-iteration pattern of `widestLine + countVisualLines`
