## Summary

Shared LRU eviction utility for Ink's hot-path caches. Provides bulk eviction by keeping a ratio of entries, deleting from the beginning of the Map (oldest).

## Details

- `lruEvict(cache, keepRatio)`: Evicts entries down to `keepRatio` of current size
- `keepRatio <= 0`: Clears the entire cache
- Deletes from `cache.keys().next().value` (Map iteration order = insertion order)
- Used by `line-width-cache.ts` and other hot-path caches
- Touch-on-read LRU updates are inlined per-cache; only bulk eviction is factored here
