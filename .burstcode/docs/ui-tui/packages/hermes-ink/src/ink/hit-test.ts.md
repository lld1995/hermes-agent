## Summary

Implements hit-testing and event dispatch for the terminal DOM. Finds the deepest DOM element at a given (col, row) coordinate using cached rects, then bubbles ClickEvent, MouseEvent, and hover events up the parent chain with propagation control.

## Details

- `hitTest()`: Recursively finds the deepest DOMElement whose `nodeCache` rect contains the given coordinates. Traverses children in reverse so later siblings (painted on top) win.
- `dispatchClick()`: Hit-tests the root, fires click-to-focus on the nearest focusable ancestor, then bubbles `ClickEvent` up via `parentNode`, computing local coordinates per handler. Stops on `stopImmediatePropagation()`.
- `dispatchMouse()`: Similar to click dispatch but for `onMouseDown`/`onMouseUp`/`onMouseDrag` handlers. Returns the first node that handled the event.
- `dispatchHover()`: Non-bubbling enter/leave dispatch. Walks up from the hit node collecting ancestors with hover handlers, diffs against the previous `hovered` set, and fires `onMouseLeave`/`onMouseEnter` accordingly. Mutates the `hovered` set in place.
