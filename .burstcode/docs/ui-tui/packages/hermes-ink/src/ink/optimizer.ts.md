## Summary

Single-pass diff optimizer that reduces terminal patch count by removing no-ops, merging consecutive cursor moves, concatenating style patches, deduping hyperlinks, and canceling cursor hide/show pairs.

## Details

- Processes a `Diff` array and returns an optimized `Diff`
- Skips empty stdout patches, (0,0) cursor moves, and zero-count clears
- Merges consecutive `cursorMove` patches by summing deltas
- Collapses consecutive `cursorTo` patches (last one wins)
- Concatenates adjacent `styleStr` patches (transition diffs, not setters)
- Dedupes consecutive hyperlinks with identical URIs
- Cancels adjacent `cursorHide`/`cursorShow` pairs by popping the previous patch
- Single-pass design avoids multiple iterations over the diff array
