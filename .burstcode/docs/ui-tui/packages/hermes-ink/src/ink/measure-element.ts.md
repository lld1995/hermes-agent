## Summary

Measures the computed width and height of a DOM element by reading its Yoga layout node's dimensions, defaulting to zero if the Yoga node is absent.

## Details

- Exports a single `measureElement` function accepting a `DOMElement`
- Reads `yogaNode.getComputedWidth()` and `yogaNode.getComputedHeight()`
- Returns `{ width, height }` with `0` fallbacks for missing Yoga nodes
- Used by layout consumers that need runtime element dimensions without triggering a full layout pass
