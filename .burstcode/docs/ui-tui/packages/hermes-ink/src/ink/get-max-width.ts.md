## Summary

Utility to extract a Yoga node's content width by subtracting padding and border, with a warning about cross-axis overflow in column layouts.

## Details

- `getMaxWidth` computes `getComputedWidth() - leftPadding - rightPadding - leftBorder - rightBorder`
- Warning: in column-direction flex parents, width is the cross axis and `align-items: stretch` never shrinks children below intrinsic size
- Yoga's two-pass measurement (AtMost for width, Exactly for height) means `getComputedWidth()` reflects the wider AtMost result
- Callers should clamp to actual available screen space to keep rendered line count consistent with layout height
