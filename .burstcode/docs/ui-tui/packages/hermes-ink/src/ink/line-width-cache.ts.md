## Summary

LRU cache for string width measurements. During streaming, completed lines are immutable, so caching per-line width avoids re-measuring hundreds of unchanged lines on every token (~50x reduction).

## Details

- `lineWidth(line)`: Returns cached width or computes via `stringWidth`, updating LRU order on hit
- `MAX_CACHE_SIZE = 4096`: Evicts oldest entry when full
- `lineWidthCacheSize()`: Returns current cache size
- `evictLineWidthCache(keepRatio)`: Bulk eviction using shared `lruEvict` utility
- Uses touch-on-read LRU pattern (delete+re-set on hit to move to end)
