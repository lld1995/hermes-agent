## Summary

WeakMap-based cache for layout bounds and pending clear regions, plus a module-level flag tracking absolute-positioned node removals to disable blit optimization when cross-subtree paint overlap is possible.

## Details

- `nodeCache`: `WeakMap<DOMElement, CachedLayout>` storing x/y/width/height/top per node
- `pendingClears`: `WeakMap<DOMElement, Rectangle[]>` tracking rects of removed children needing screen clearing
- `absoluteNodeRemoved`: boolean flag set when an absolute node is removed; signals renderer to skip blit for the next frame
- `addPendingClear()`: appends a rect to a parent's pending clears and sets the absolute flag if needed
- `consumeAbsoluteRemovedFlag()`: reads and resets the flag (reset at start of each render)
- Absolute-positioned nodes can paint over non-siblings, so their removal requires special blit suppression
