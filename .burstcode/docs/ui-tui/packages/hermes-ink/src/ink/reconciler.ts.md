## Summary

React reconciler configuration for Ink that bridges React's virtual DOM to terminal DOM elements, handling node creation, prop diffing, Yoga layout cleanup, focus management, and event dispatching.

## Details

- Uses `react-reconciler` to create a custom host environment
- `createInstance`: creates DOM nodes, applies props (style, textStyles, event handlers, attributes)
- `commitUpdate`: diffs old/new props, applies style changes to Yoga nodes
- `removeChild`/`removeChildFromContainer`: removes nodes, calls `cleanupYogaNode` to free WASM memory, notifies focus manager
- `resetAfterCommit`: triggers `onComputeLayout` (Yoga) then `onRender`; test mode uses `onImmediateRender`
- Host context tracks `isInsideText` to enforce `<Text>` nesting rules
- Wires `dispatcher.discreteUpdates` to break import cycle with `dispatcher.ts`
