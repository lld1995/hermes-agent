## Summary

DOM-like focus manager tracking active element, focus stack for Tab navigation, and tree-aware focus restoration when nodes are removed.

## Details

- `FocusManager` stores `activeElement`, a LIFO `focusStack` (max 32), and an enabled flag
- `focus()` pushes previous element to stack, dispatches blur/focus events
- `handleNodeRemoved` cleans stack of removed nodes, restores focus from stack if activeElement was removed
- `focusNext`/`focusPrevious` walk `collectTabbable` (nodes with `tabIndex >= 0`) in document order
- `isInTree` walks `parentNode` chain to verify a node is still mounted
- `getRootNode`/`getFocusManager` walk up to the root element holding the `FocusManager`
