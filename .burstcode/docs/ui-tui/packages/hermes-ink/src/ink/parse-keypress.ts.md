## Summary

Terminal input parser that tokenizes escape sequences into keypresses, mouse events, and terminal responses, supporting Kitty keyboard protocol, xterm modifyOtherKeys, SGR/X10 mouse, bracketed paste, and fragmented SGR mouse recovery.

## Details

- `parseMultipleKeypresses()`: main entry point; uses `termio` tokenizer, handles paste mode state, emits `ParsedInput[]` (key/mouse/response)
- Terminal response detection: DECRPM, DA1, DA2, Kitty flags, cursor position, OSC, XTVERSION
- Mouse parsing: SGR mouse (CSI < btn;col;row M/m), X10 mouse (CSI M + 3 bytes), wheel events stay as `ParsedKey`
- Fragmented SGR mouse recovery: regex-based re-synthesis of degraded mouse bursts that leaked into text tokens
- Key parsing: Kitty CSI u, xterm modifyOtherKeys, legacy FN keys, meta keys, control chars, iTerm natural editing
- `nonAlphanumericKeys` list filters printable characters from functional key names
- Paste mode: tracks `IN_PASTE` state, flushes on null input or watchdog timeout
