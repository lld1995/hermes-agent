## Summary

Yoga layout engine adapter implementing the LayoutNode interface. Wraps Yoga.Node instances, mapping Ink's layout enums to Yoga's internal enums and delegating all layout operations.

## Details

- `YogaLayoutNode` class wraps a `YogaNode` and implements `LayoutNode`
- Static maps: `EDGE_MAP`, `GUTTER_MAP` for enum translation
- All style setters delegate to Yoga with enum conversion (flex direction, wrap, align, justify, overflow, position)
- `calculateLayout` always uses `Direction.LTR`
- `setMeasureFunc` wraps the callback to translate `MeasureMode` enums
- `createYogaLayoutNode()`: Factory that creates a new `YogaLayoutNode` from `Yoga.Node.create()`
- The TS yoga-layout port is synchronous (no WASM), so no preload/swap machinery is needed
