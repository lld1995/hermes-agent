## Summary

Manages GitHub Copilot authentication, including OAuth device code flow, token validation, exchange to short-lived API tokens, and construction of standard request headers for Copilot endpoints.

## Details

- Validates token prefixes (`gho_`, `github_pat_`, `ghu_`) and rejects unsupported classic PATs (`ghp_`).
- Resolves tokens from environment variables (`COPILOT_GITHUB_TOKEN`, `GH_TOKEN`, `GITHUB_TOKEN`) or falls back to `gh auth token` with a clean subprocess environment.
- Implements RFC 8628 OAuth device code flow (`copilot_device_code_login`) with polling, safety margins, and `slow_down` handling.
- Caches exchanged Copilot API tokens (`_jwt_cache`) keyed by token fingerprint, refreshing before expiry.
- Builds standard Copilot API headers (`copilot_request_headers`) including editor version, integration ID, and vision flags.
