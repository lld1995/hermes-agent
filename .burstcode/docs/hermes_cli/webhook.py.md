## Summary

CLI subcommand for managing dynamic webhook subscriptions, persisting routes to `webhook_subscriptions.json` and supporting hot-reloading by the gateway adapter.

## Details

- **Subscription lifecycle**: `subscribe`, `list`, `remove`, and `test` commands manage dynamic webhook routes without requiring a gateway restart.
- **Atomic persistence**: Routes are saved to `~/.hermes/webhook_subscriptions.json` using `atomic_replace` to prevent corruption during writes.
- **Config validation**: Checks `platforms.webhook.enabled` and extracts host/port/secret from `config.yaml` or environment variables.
- **Test endpoint**: `_cmd_test` constructs an HMAC-SHA256 signature and sends a synchronous POST to the local gateway to verify routing.
- **Delivery modes**: Supports standard agent routing or `deliver_only` mode for direct, zero-LLM-cost forwarding to external platforms.
