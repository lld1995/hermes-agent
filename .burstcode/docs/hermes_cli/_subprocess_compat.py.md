## Summary

Provides cross-platform subprocess helpers to safely launch detached or hidden processes, with special handling for Windows batch shims and console flashes.

## Details

- `resolve_node_command()` uses `shutil.which()` to resolve Node ecosystem commands (npm, npx, etc.) to absolute paths, fixing WinError 193 on Windows.
- `windows_detach_flags()` and `windows_hide_flags()` return Win32 `creationflags` for detaching processes or hiding console windows, returning `0` on POSIX.
- `windows_detach_popen_kwargs()` abstracts `start_new_session=True` (POSIX) vs `creationflags` (Windows) for safe background daemon spawning.
- Guarantees "do no damage on POSIX" by making all helpers no-ops outside Windows.
