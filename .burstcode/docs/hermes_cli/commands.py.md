## Summary

Central registry and dispatcher for Hermes slash commands, defining metadata, aliases, and platform-specific surfacing logic for CLI, Telegram, Discord, and Slack. Handles config-gated exposure, plugin/skill integration, and TUI autocomplete.

## Details

- Defines `CommandDef` dataclass and `COMMAND_REGISTRY` as the single source of truth for all slash commands, aliases, and categories.
- Derives lookup dictionaries (`COMMANDS`, `SUBCOMMANDS`, `GATEWAY_KNOWN_COMMANDS`) at import time for fast resolution.
- Implements gateway availability checks via `gateway_config_gate`, allowing CLI-only commands to conditionally appear in messaging surfaces based on `config.yaml`.
- Generates platform-specific command lists (`telegram_bot_commands`, `discord_skill_commands`, `slack_native_slashes`) with name sanitization, length clamping, and collision avoidance.
- Integrates plugin and skill commands lazily to avoid forcing filesystem scans on import.
- Provides `SlashCommandCompleter` and `SlashCommandAutoSuggest` for TUI input, supporting dynamic model/skin/personality completions, fuzzy file search (`@`), and path expansion.
