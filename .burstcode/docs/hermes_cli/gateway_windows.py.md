## Summary

Windows-specific backend for managing the Hermes gateway as a background service. Supports installation via Windows Scheduled Tasks (`schtasks`) with a fallback to the Startup folder, and handles starting, stopping, restarting, and status reporting.

## Details

- Implements service lifecycle management on Windows using `schtasks` for `ONLOGON` triggers and `pythonw.exe` for detached, console-less execution.
- Includes separate quoting helpers for `cmd.exe` vs `schtasks` parsers to prevent argument injection or parsing failures.
- Falls back to a Startup-folder `.cmd` dropper when Scheduled Task creation is denied (e.g., locked-down corporate environments).
- Spawns processes with `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP | CREATE_NO_WINDOW` flags to survive parent shell exits and job object teardowns.
- Provides `status()`, `start()`, `stop()`, and `restart()` commands that merge schtasks registration, startup entry presence, and live PID scanning.
