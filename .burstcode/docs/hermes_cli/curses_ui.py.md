## Summary

Shared curses-based terminal UI components for interactive multi-select checklists, radio lists, and single-select menus. Includes a `flush_stdin()` utility to prevent escape-sequence corruption after curses exits, plus text-based numbered fallbacks for non-curses terminals.

## Details

- **Purpose**: Reusable TUI widgets used by `hermes tools` and `hermes skills` for interactive selection.
- **`flush_stdin()`**: Drains OS input buffer after `curses.wrapper()` to prevent leftover escape sequences from corrupting subsequent `input()` calls. No-op on non-TTY or Windows.
- **`curses_checklist()`**: Multi-select with keyboard navigation (↑↓/j/k), space to toggle, Enter to confirm, ESC/q to cancel. Supports a `status_fn` callback for live footer info.
- **`curses_radiolist()`**: Single-select radio list with optional multi-line description block.
- **`curses_single_select()`**: Single-select menu with a cancel option appended.
- **Fallbacks**: Each curses function has a `_numbered_*_fallback` that uses plain `input()` for terminals without curses support.
- **Safety**: All functions check `sys.stdin.isatty()` and return defaults immediately for piped/redirected stdin.
