## Summary

Implements CLI subcommands for managing the credential pool, supporting API key injection, OAuth flows, and interactive credential management.

## Details

- Handles `hermes auth add/list/remove/reset/status/logout/spotify` via dedicated command functions.
- `auth_add_command()` routes to provider-specific OAuth flows (Anthropic, Nous, Codex, Gemini, Qwen, MiniMax) or API key entry, clearing suppressions on re-add.
- `auth_remove_command()` delegates to `agent.credential_sources` removal steps and suppresses the source to prevent resurrection.
- `_interactive_auth()` provides a TUI menu for adding, removing, resetting cooldowns, and setting rotation strategies (round-robin, least-used, etc.).
- Parses exhausted status from error codes/reasons to display human-readable retry windows or auth failure hints.
