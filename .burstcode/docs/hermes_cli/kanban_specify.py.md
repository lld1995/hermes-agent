## Summary

Triage task specifier that uses an auxiliary LLM to expand rough Kanban triage items into concrete, actionable task specifications before promotion to the `todo` column.

## Details

- Mirrors `goals.py` auxiliary client pattern for robustness, importing `agent.auxiliary_client` with identical fail-open error handling.
- Sends a structured prompt to generate a tightened title and detailed body (Goal, Approach, Acceptance criteria, Out of scope).
- Features lenient JSON extraction (`_extract_json_blob`) with markdown fence tolerance and greedy brace matching.
- Gracefully falls back to treating the raw LLM response as the body if JSON parsing fails, preventing task stranding.
- Promotes tasks via `kanban_db.specify_triage_task()` and handles race conditions where tasks move out of triage before promotion.
