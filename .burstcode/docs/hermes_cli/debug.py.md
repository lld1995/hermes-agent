## Summary

Debug report collection and upload tool. Gathers system info and log tails, optionally redacts secrets via agent.redact, uploads to paste.rs/dpaste.com, and schedules auto-deletion via a pending.json manifest swept by the gateway cron ticker.

## Details

- **Purpose**: `hermes debug share` uploads a debug report (system dump + log tails) to public paste services; `hermes debug delete` removes pastes.
- **Redaction**: Runs `agent.redact.redact_sensitive_text` with `force=True` on all log content before upload, regardless of user's `security.redact_secrets` setting. `--no-redact` disables.
- **Paste services**: Tries paste.rs first (simple POST), falls back to dpaste.com (multipart form). Both return shareable URLs.
- **Auto-deletion**: Records paste.rs URLs in `~/.hermes/pastes/pending.json` with expiry timestamps. Gateway cron ticker sweeps hourly; CLI runs opportunistic sweep on every `hermes debug` invocation.
- **Log capture**: Reads agent.log, errors.log, gateway.log with rotation fallback (.1). Truncates large files to ~512KB from the end, preserving line boundaries.
- **Dependencies**: `agent.redact` (secret masking), `hermes_cli.logs.LOG_FILES` (log path resolution), `hermes_cli.dump.run_dump` (system info), `utils.atomic_replace` (safe file writes).
