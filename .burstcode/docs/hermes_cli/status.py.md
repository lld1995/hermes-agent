## Summary

CLI status command that reports the health and configuration of all Hermes Agent components, including environment, API keys, OAuth providers, terminal backends, messaging platforms, gateway service, cron jobs, and sessions.

## Details

- Displays a structured status report with sections for Environment, API Keys, Auth Providers, Nous Subscription Features, API-Key Providers, Terminal Backend, Messaging Platforms, Gateway Service, Scheduled Jobs, and Sessions.
- Resolves effective provider via `hermes_cli.runtime_provider.resolve_requested_provider()` and `hermes_cli.auth.resolve_provider()`.
- Checks API key presence for 20+ providers using `hermes_cli.config.get_env_value()`, with special handling for Anthropic OAuth tokens via `get_anthropic_key()`.
- Reports OAuth status for Nous Portal, OpenAI Codex, Qwen, and MiniMax, including token expiration timestamps formatted to local timezone.
- Probes LM Studio reachability when it's the active provider, using `probe_lmstudio_models()` with a 1.5s timeout.
- Inspects terminal backend configuration (local, SSH, Docker, Daytona, Vercel Sandbox) and SDK/auth state via `describe_vercel_auth()`.
- Enumerates messaging platform configuration by checking env vars for 16+ platforms plus plugin-registered platforms from `gateway.platform_registry`.
- Queries gateway runtime snapshot via `hermes_cli.gateway.get_gateway_runtime_snapshot()` for PID and service status.
- Reads `cron/jobs.json` and `sessions/sessions.json` directly for job/session counts.
- `--deep` flag adds OpenRouter connectivity probe and port 18789 socket check.
- All sections are wrapped in try/except to degrade gracefully on import or I/O failures.
