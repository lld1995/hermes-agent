## Summary

CLI subcommand generator for Slack app manifests, synchronizing Hermes slash commands with Slack's native configuration format.

## Details

- Implements `hermes slack manifest` to output JSON for Slack's App Manifest editor.
- Merges dynamic slash command definitions from `hermes_cli.commands.slack_app_manifest()` with static OAuth scopes, socket mode settings, and event subscriptions.
- Supports `--write` to save to `$HERMES_HOME/slack-manifest.json` or a custom path, and `--slashes-only` for partial merges.
- Provides step-by-step installation instructions in stderr when writing to a file.
- Handles display name and description overrides via CLI flags.
