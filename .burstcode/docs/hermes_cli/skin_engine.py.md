## Summary

Data-driven theming engine that loads built-in and user-defined YAML skins to customize CLI colors, branding, and prompt_toolkit styles.

## Details

- Defines `SkinConfig` dataclass and a registry of built-in themes (default, ares, mono, slate, daylight, etc.).
- Loads user skins from `~/.hermes/skins/*.yaml`, merging overrides with the default skin's base values.
- Provides singleton-like access via `get_active_skin()` and `set_active_skin()`, initialized from CLI config at startup.
- Generates `prompt_toolkit` style override dictionaries for live UI theming without app restarts.
- Exposes convenience helpers for prompt symbols, help headers, and goodbye messages used across the CLI.
