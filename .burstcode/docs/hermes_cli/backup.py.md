## Summary

Manages full and quick state backups of the Hermes home directory, handling SQLite consistency, exclusion rules, and pre-update safety snapshots.

## Details

- `run_backup()` walks `~/.hermes/`, excludes transient/code directories, and creates a compressed zip archive.
- `_safe_copy_db()` uses `sqlite3.backup()` to snapshot databases safely, avoiding WAL/shm/journal corruption.
- `run_import()` validates zip markers, strips common prefixes, blocks path traversals, and restores files with tight permissions for secrets.
- Quick snapshots (`create_quick_snapshot()`) capture critical state files (`state.db`, `config.yaml`, pairing data) for fast rollbacks.
- Pre-update/migration backups auto-prune old archives and integrate with `hermes update` and `claw migrate` workflows.
