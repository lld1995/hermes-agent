## Summary

CLI interface for inspecting, testing, revoking, and diagnosing user-defined shell-script hooks that trigger on agent lifecycle events.

## Details

- Acts as a thin wrapper around `agent.shell_hooks`, providing subcommands: `list`, `test`, `revoke`, and `doctor`.
- The `test` command fires hooks with synthetic payloads matching production shapes, allowing safe validation before runtime.
- `doctor` validates script executability, allowlist status, modification timestamps (mtime drift), and JSON output compliance.
- `revoke` removes allowlist entries but warns that running CLI/gateway processes retain cached callbacks until restart.
- Groups configured hooks by event type and cross-references them against `~/.hermes/shell-hooks-allowlist.json`.
