## Summary

Utility module for consistently loading Hermes `.env` files across entrypoints. Handles UTF-8/Latin-1 fallbacks, pre-sanitizes corrupted lines, strips non-ASCII characters from credential variables, and manages user vs. project environment precedence.

## Details

- `load_hermes_dotenv()` loads `~/.hermes/.env` with override precedence, then project `.env` as fallback
- `_sanitize_loaded_credentials()` strips non-ASCII chars from `_API_KEY`/`_TOKEN` vars to prevent HTTP header failures
- `_sanitize_env_file_if_needed()` fixes concatenated `KEY=VALUE` lines before `python-dotenv` parses them
- Uses atomic file replacement to prevent `.env` corruption during sanitization
- Deduplicates warnings via `_WARNED_KEYS` to avoid stderr spam across repeated loads
- Falls back to Latin-1 encoding if UTF-8 decoding fails during dotenv loading
