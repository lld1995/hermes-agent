## Summary

CLI utility for viewing, filtering, and tailing Hermes log files under ~/.hermes/logs/. Supports level, session, component, and relative time filtering, with efficient chunked reading for large files and real-time follow mode.

## Details

- Maps logical log names (`agent`, `errors`, `gateway`) to physical files and resolves paths via `hermes_constants.get_hermes_home`.
- Parses log lines using regexes for timestamps, severity levels, and logger names to apply filters.
- Implements `_read_last_n_lines` with a hybrid strategy: full read for files ≤1MB, chunked reverse reading for larger files to maintain performance.
- Supports `--follow` mode via `_follow_log`, which polls for new content and applies active filters in real-time.
- Integrates with `hermes_logging.COMPONENT_PREFIXES` to map high-level component names to logger name prefixes for scoped filtering.
- Handles relative time ranges (`--since 1h`, `30m`) by parsing strings into `datetime` cutoffs.
