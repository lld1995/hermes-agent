## Summary

Central plugin management module that discovers, loads, and invokes plugins from bundled, user, project, and pip sources. It provides a PluginContext for registering tools, hooks, CLI/slash commands, skills, and specialized providers, while enforcing opt-in enablement and lifecycle isolation.

## Details

- Discovers plugins from four sources (bundled, user, project, pip) with later sources overriding earlier ones on name collision.
- Parses `plugin.yaml` manifests and dynamically imports `__init__.py` modules under a `hermes_plugins` namespace.
- Exposes `PluginContext` to register tools, lifecycle hooks, CLI/slash commands, skills, and specialized providers (image/video/web search, platforms).
- `PluginManager` singleton caches discovery state but supports `force=True` rescans for long-lived sessions.
- Enforces opt-in loading via `plugins.enabled`/`disabled` config keys, with auto-loading for bundled backends/platforms.
- Provides thread-local tool whitelisting and safe async handler resolution for plugin commands.
