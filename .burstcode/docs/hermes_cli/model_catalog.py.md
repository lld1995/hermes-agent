## Summary

Fetches, validates, and caches a remote JSON manifest of curated LLM models. Implements multi-tier caching (in-process, disk, network) with TTL invalidation. Provides accessors for OpenRouter and Nous Portal models, falling back to in-repo defaults on failure.

## Details

- Retrieves a versioned JSON manifest from a configurable URL, validating schema structure (v1).
- Maintains an in-process cache keyed by disk file mtime to avoid redundant parsing.
- Falls back to stale disk cache or empty dict on network failure, ensuring CLI resilience offline.
- Supports per-provider URL overrides for self-hosted catalogs, bypassing the disk cache for freshness.
- Exposes `get_curated_openrouter_models()` and `get_curated_nous_models()` as thin accessors.
- Uses atomic file replacement for safe disk cache updates.
