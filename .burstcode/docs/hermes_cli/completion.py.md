## Summary

Generates shell completion scripts for bash, zsh, and fish by introspecting the live argparse parser tree, ensuring completions dynamically reflect CLI subcommands and flags without hardcoded lists.

## Details

- Walks `argparse.ArgumentParser` recursively via `_walk()` to extract canonical subcommands and flags, ignoring aliases to keep lists clean.
- Generates shell-specific scripts (`generate_bash`, `generate_zsh`, `generate_fish`) that route completions based on command position and previous arguments.
- Includes dynamic profile name completion by scanning `~/.hermes/profiles` at runtime.
- Sanitizes help text for shell safety and truncates long descriptions.
- Avoids external dependencies by relying purely on Python's standard library and runtime parser state.
