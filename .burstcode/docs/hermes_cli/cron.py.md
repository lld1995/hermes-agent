## Summary

CLI interface for managing scheduled cron jobs, wrapping internal cron tools to handle job creation, editing, scheduling, and status reporting while checking gateway availability for automatic execution.

## Details

- Provides CLI handlers (`cron_list`, `cron_status`, `cron_tick`, `cron_create`, `cron_edit`) that format job metadata with color-coded output.
- Delegates core job operations to `tools.cronjob_tools` via `_cron_api()` and queries `cron.jobs`/`cron.scheduler` for state and execution.
- Normalizes skill lists across single/multiple arguments and handles add/remove/clear operations during job edits.
- Checks `find_gateway_pids()` to warn users if the gateway process is down, since automatic job firing depends on it.
- Routes argparse subcommands through `cron_command()` with fallback usage hints.
