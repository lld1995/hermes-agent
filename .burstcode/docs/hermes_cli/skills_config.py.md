## Summary

CLI interface for toggling agent skills globally or per-platform, persisting disabled lists to config.yaml and providing category-based bulk toggling via curses UI.

## Details

- **Purpose**: Manages skill availability across platforms, allowing users to disable specific skills or entire categories without uninstalling them.
- **Key Functions**: `get_disabled_skills`/`save_disabled_skills` (config I/O), `_select_platform` (interactive platform targeting), `_toggle_by_category` (bulk category toggling), `skills_command` (CLI entry point).
- **UI & Interaction**: Uses `hermes_cli.curses_ui.curses_checklist` for terminal selection; supports both individual skill toggling and category-wide bulk operations.
- **Integration Points**: Delegates skill discovery to `tools.skills_tool._find_all_skills`; reads/writes `skills.disabled` and `skills.platform_disabled` in `config.yaml` via `hermes_cli.config`.
