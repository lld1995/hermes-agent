## Summary

Stateless diagnostic engine for the Kanban board that analyzes task events and runs to surface actionable distress signals like hallucinated cards, crash loops, or stranded tasks.

## Details

- Defines `Diagnostic` and `DiagnosticAction` dataclasses with severity ranking (`warning`/`error`/`critical`) and structured recovery actions.
- Implements a registry of rule functions that evaluate task state, event timelines, and run outcomes to emit diagnostics.
- Rules include: hallucinated card IDs, prose phantom references, repeated failures/crashes, stuck-in-blocked, and stranded-in-ready.
- Features auto-clearing logic: diagnostics stop firing when underlying failure modes resolve (e.g., clean completion arrives).
- Tolerates multiple task representations (sqlite3.Row, dataclasses, dicts) via `_task_field()` helper for robust rule execution.
