## Summary

CLI interface for the Hermes Kanban board, exposing task management, board scoping, diagnostics, and dispatcher controls via argparse. Delegates persistence to kanban_db and integrates with gateway status checks, LLM-based triage specification, and slash-command routing for chat interfaces.

## Details

- Constructs a comprehensive argparse subcommand tree (`build_parser`) covering 15+ verbs (create, list, show, assign, claim, complete, block, archive, etc.).
- Manages multi-project boards via filesystem-backed metadata and `HERMES_KANBAN_BOARD` env-var scoping.
- Probes gateway liveness and `dispatch_in_gateway` config in `_check_dispatcher_presence` to warn users when tasks will stall in `ready`.
- Implements `_cmd_specify` to delegate triage tasks to `kanban_specify` for LLM-driven promotion to `todo`.
- Provides `run_slash` to parse `/kanban ...` strings, capture stdout/stderr, and return formatted responses for gateway chat adapters.
- Handles workspace resolution, task claiming, notification subscriptions, and garbage collection of archived workspaces/logs.
