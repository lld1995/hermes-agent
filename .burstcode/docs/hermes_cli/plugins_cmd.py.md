## Summary

Comprehensive CLI and dashboard API for installing, updating, enabling, and configuring Hermes plugins from Git repositories.

## Details

- Manages plugin lifecycle (`install`, `update`, `remove`, `enable`, `disable`, `list`) targeting `~/.hermes/plugins/`.
- Resolves Git URLs (including `owner/repo` shorthand), clones repos, validates `plugin.yaml` manifests, and enforces `_SUPPORTED_MANIFEST_VERSION`.
- Prompts for missing `requires_env` variables, saving them to `.env` via `hermes_cli.config`.
- Maintains `plugins.enabled` and `plugins.disabled` allow/deny lists in `config.yaml`, and dynamically toggles `platform_toolsets` for plugins that register tools.
- Provides an interactive curses UI (`cmd_toggle`) for bulk plugin management and provider configuration (memory/context engines), with a text-based fallback for non-TTY environments.
- Exposes dashboard-compatible functions (`dashboard_install_plugin`, `dashboard_set_agent_plugin_enabled`) for non-interactive web UI integration.
