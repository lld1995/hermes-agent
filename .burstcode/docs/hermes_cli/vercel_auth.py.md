## Summary

Helper module that reports Vercel Sandbox authentication state by checking for OIDC tokens or access token triples, returning a structured status without exposing secret values.

## Details

- `VercelAuthStatus` frozen dataclass with `ok` (bool), `label` (str), and `detail_lines` (tuple of str) fields.
- `describe_vercel_auth()` checks environment variables to determine auth state:
  - OIDC mode: `VERCEL_OIDC_TOKEN` present → returns `ok=True` with development-only warning.
  - Access token mode: all three of `VERCEL_TOKEN`, `VERCEL_PROJECT_ID`, `VERCEL_TEAM_ID` present → returns `ok=True`.
  - Partial access token: some but not all token vars present → returns `ok=False` with missing var list.
  - Not configured: no token vars present → returns `ok=False` with setup recommendations.
- `_present(name)` helper checks `os.getenv(name)` truthiness.
- Never exposes actual token values; only reports presence/absence and mode.
- Used by `hermes_cli/status.py` in the Terminal Backend section to report Vercel Sandbox auth state.
