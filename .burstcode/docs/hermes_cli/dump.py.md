## Summary

CLI command that outputs a compact, plain-text summary of the Hermes setup for support contexts. Reports version, OS, SDK versions, model/provider config, API key status, feature flags, gateway state, and non-default config overrides.

## Details

- Gathers runtime metadata: version, git commit, OS, Python, OpenAI SDK, active profile, and terminal backend
- Lists configured API keys with optional redaction via `agent.redact.mask_secret`
- Counts installed skills, MCP servers, cron jobs, and configured messaging platforms
- Detects non-default config overrides by comparing user values against `DEFAULT_CONFIG`
- Queries gateway runtime snapshot for process state and manager mode
- Outputs strictly plain text (no ANSI/colors) for easy copy-pasting into support channels
- Gracefully degrades on import failures or missing config files
