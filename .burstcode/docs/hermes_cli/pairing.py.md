## Summary

CLI interface for managing DM pairing requests, allowing operators to list, approve, revoke, or clear pending user pairings across supported platforms.

## Details

- Dispatches `hermes pairing` subcommands (`list`, `approve`, `revoke`, `clear-pending`) via `gateway.pairing.PairingStore`.
- Formats pending and approved users into aligned terminal tables, displaying platform, code, user ID, name, and request age.
- Handles approval lockouts by reading `_rate_limits.json` directly to report remaining cooldown time when `approve_code` fails.
- Normalizes platform names and codes (lowercase/uppercase) before passing them to the store.
- Provides clear fallback messages for missing codes, expired requests, or empty pairing states.
