## Summary

CLI command for managing the fallback provider chain. Supports listing, adding, removing, and clearing fallback entries. Migrates legacy config formats, prevents duplicate/self-fallbacks, and safely restores model/auth state after interactive picker usage.

## Details

- Manages `fallback_providers` list in `config.yaml`, migrating legacy `fallback_model` dicts on first write
- `cmd_fallback_add` reuses `select_provider_and_model` picker, snapshotting/restoring `config["model"]` and `auth.json` to avoid side effects
- Prevents adding the primary model as its own fallback or duplicating existing chain entries
- `cmd_fallback_remove` and `cmd_fallback_clear` provide interactive selection with curses or numbered fallback
- `_read_chain`/`_write_chain` normalize config state and ensure single source of truth
- Best-effort auth restoration prevents picker failures from corrupting the active provider
