## Summary

Handles installation, updating, and introspection of shareable Hermes profiles packaged as git repositories. It stages sources, validates manifests, and carefully separates distribution-owned configuration from user-owned state to preserve credentials and runtime data during updates.

## Details

- Manages git-based profile distributions via `distribution.yaml` manifests, supporting install, update, and info subcommands.
- Stages sources from git URLs or local directories, validating `hermes_requires` version constraints before deployment.
- Separates distribution-owned paths (SOUL.md, skills, cron, mcp.json) from user-owned state (auth, sessions, memories) using `USER_OWNED_EXCLUDE`.
- Preserves `config.yaml` during updates unless `--force-config` is passed, protecting user overrides.
- Generates `.env.EXAMPLE` templates from `env_requires` and tracks provenance/source for reliable `update` operations.
- Uses `InstallPlan` to preview changes and handle alias creation or collision checks.
