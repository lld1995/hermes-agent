## Summary

DingTalk Device Flow authorization module. Implements a 3-step registration (init → begin → poll) to obtain client credentials via QR code scanning, with auto-install of the qrcode library and terminal rendering.

## Details

- **Purpose**: Interactive DingTalk app registration via device flow, producing `client_id` and `client_secret`.
- **Flow**: (1) POST `/app/registration/init` for nonce, (2) POST `/app/registration/begin` for device_code + verification URI, (3) poll `/app/registration/poll` until SUCCESS.
- **QR rendering**: Uses `qrcode` library with half-block Unicode characters for compact terminal display. Auto-installs via `uv pip` or `pip` if missing.
- **Polling**: Blocks with configurable interval (default 3s), 2-hour timeout, and 2-minute retry window for transient errors. Progress dots printed every 10 polls.
- **Dependencies**: `requests` for HTTP calls, `hermes_cli.setup` for styled print helpers (`print_info`, `print_success`, etc.).
- **Config**: `DINGTALK_REGISTRATION_BASE_URL` and `DINGTALK_REGISTRATION_SOURCE` env vars override defaults.
