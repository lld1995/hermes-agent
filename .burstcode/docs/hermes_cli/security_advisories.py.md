## Summary

Supply-chain security scanner that checks installed packages against a catalog of known-compromised versions, surfaces remediation steps, and manages user acknowledgments via config and a local cache.

## Details

- **Purpose**: Lightweight, stdlib-only module to detect poisoned dependencies (e.g., `mistralai` worm) and guide users through credential rotation without blocking CLI startup.
- **Key Functions**: `detect_compromised` (scans `importlib.metadata`), `ack_advisory`/`get_acked_ids` (persists dismissals to `config.security.acked_advisories`), `hits_due_for_banner` (gates warnings via 24h cache), `render_doctor_section` (formats output).
- **Design Constraints**: Intentionally avoids heavy imports to remain resilient if core Hermes modules fail; uses `importlib.metadata` instead of `pip` for version checks.
- **Integration Points**: Invoked by `hermes doctor`, CLI startup banner, and gateway initialization; writes acks to `config.yaml` via `hermes_cli.config`.
