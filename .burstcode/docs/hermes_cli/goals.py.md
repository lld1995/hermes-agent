## Summary

Implements the persistent session goal loop ("Ralph loop"), allowing users to set standing objectives that the agent pursues across multiple turns until satisfied, budget exhausted, or paused.

## Details

- Manages `GoalState` persistence in `SessionDB` and orchestrates an auxiliary model "judge" to evaluate goal completion after each turn.
- Features fail-open judge parsing: API/transport errors return `continue`, while consecutive JSON parse failures trigger auto-pause to prevent budget burn.
- Supports dynamic `/subgoal` criteria injected mid-loop, which are appended to both the continuation prompt and the judge evaluation prompt.
- Provides `GoalManager` class for CLI/gateway integration, exposing `set()`, `pause()`, `resume()`, `clear()`, and `evaluate_after_turn()`.
- Continuation prompts are injected as normal user messages to preserve prompt caching and avoid system-prompt mutation.
