## Summary

Hermes Agent uninstaller that removes code, shell PATH entries, wrapper scripts, gateway services, Windows registry env vars, and optionally all user data, with support for named profile cleanup.

## Details

- Offers two modes: "Keep data" (removes code only) and "Full uninstall" (removes everything including `~/.hermes/`).
- `remove_path_from_shell_configs()` scans `.bashrc`, `.bash_profile`, `.profile`, `.zshrc`, `.zprofile` for Hermes PATH entries and removes them.
- `remove_wrapper_script()` deletes `~/.local/bin/hermes` and `/usr/local/bin/hermes` if they reference `hermes_cli`.
- `uninstall_gateway_service()` stops and removes gateway services across platforms: systemd (Linux), launchd (macOS), Scheduled Task + Startup folder (Windows via `gateway_windows`), and standalone processes (all platforms).
- Windows-specific helpers: `remove_path_from_windows_registry()` strips Hermes-owned entries from HKCU\Environment\Path using markers derived from `hermes_home`; `remove_hermes_env_vars_windows()` deletes `HERMES_HOME` and `HERMES_GIT_BASH_PATH`; `remove_portable_tooling_windows()` removes PortableGit, Node, and gateway-service directories.
- Named profile cleanup: `_discover_named_profiles()` finds non-default profiles; `_uninstall_profile()` stops their gateway services, removes alias wrappers, and wipes their `HERMES_HOME` directories.
- Uses `subprocess.run` with timeouts for profile gateway commands to avoid blocking during uninstall.
- All operations are wrapped in try/except with `log_warn` for graceful degradation.
