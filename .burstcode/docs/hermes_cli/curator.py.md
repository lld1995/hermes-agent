## Summary

CLI subcommand module for the skill curator system. Provides status reporting, manual review runs, pause/resume toggles, skill pinning/unpinning, archiving, bulk pruning, and backup/rollback operations. Delegates core logic to agent.curator, tools.skill_usage, and agent.curator_backup.

## Details

- **Purpose**: Thin argparse shell around curator internals; no side effects at import time.
- **Subcommands**: `status`, `run`, `pause`, `resume`, `pin`, `unpin`, `restore`, `archive`, `prune`, `backup`, `rollback`, `list-archived`.
- **Status display**: Shows curator enabled/paused state, run counts, interval/stale/archive thresholds, and skill activity rankings (least-recently-active, most-active, least-active).
- **Run modes**: Supports `--dry-run` (report-only), `--sync` (wait for LLM pass), and `--background` (fire-and-forget).

- **Dependencies**: `agent.curator` (state, intervals, review runs), `tools.skill_usage` (skill records, pinning, archiving), `agent.curator_backup` (snapshots, rollbacks).
