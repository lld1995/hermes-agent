## Summary

Configuration helpers that extract provider-specific request and stale timeouts from config.yaml, supporting both provider-level and model-level overrides.

## Details

- `_coerce_timeout(raw)` safely converts arbitrary config values to positive floats, returning `None` for invalid, zero, or negative values.
- `get_provider_request_timeout(provider_id, model)` returns the configured request timeout in seconds, checking model-specific `timeout_seconds` first, then provider-level `request_timeout_seconds`.
- `get_provider_stale_timeout(provider_id, model)` returns the configured non-stream stale timeout, checking model-specific `stale_timeout_seconds` first, then provider-level `stale_timeout_seconds`.
- `_get_model_config(provider_config, model)` extracts the nested model configuration dict from `provider_config['models'][model]`.
- All functions load config via `hermes_cli.config.load_config()` inside try/except blocks, returning `None` on any failure.
- Config hierarchy: `providers.<provider_id>.models.<model>.timeout_seconds` > `providers.<provider_id>.request_timeout_seconds`.
- Returns `None` if `provider_id` is empty or config is malformed, allowing callers to fall back to defaults.
