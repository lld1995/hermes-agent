## Summary

Central registry defining platform metadata and display labels, merging static built-in platforms with dynamically registered plugin platforms.

## Details

- Defines `PlatformInfo` (label, default_toolset) and a deterministic `PLATFORMS` OrderedDict covering 22 built-in channels (CLI, Telegram, Discord, etc.).
- `platform_label()` resolves display names by checking the static dict first, then falling back to `gateway.platform_registry` for plugin-registered platforms.
- `get_all_platforms()` merges built-in platforms with plugin entries, appending plugin platforms with auto-generated `hermes-<name>` default toolsets.
- Gracefully handles import failures from the plugin registry to prevent crashes during CLI initialization.
