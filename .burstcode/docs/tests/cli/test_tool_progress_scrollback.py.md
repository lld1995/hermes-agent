## Summary

Tests for stacked tool progress scrollback lines in CLI TUI, verifying mode-specific behavior (all/new/off/verbose) and concurrent tool handling.

## Details

- Tests `_on_tool_progress()` prints persistent scrollback lines on `tool.completed` for "all" and "new" modes
- "all" mode: every tool completion prints a stacked line with tool info and duration
- "new" mode: consecutive calls to same tool print only once; different tool breaks the streak
- "off" and "verbose" modes: no scrollback lines printed
- Error suffix `[error]` appended when `is_error=True`
- Spinner text still updates on `tool.started`; timer clears on `tool.completed`
- Concurrent tools (multiple `tool.started` before completions) produce correct stacked lines via FIFO `_pending_tool_info`
- Pending info stores args on `tool.started` and consumes them on `tool.completed`
