## Summary

Tests for the LSP broken-set short-circuit mechanism that prevents repeated timeout penalties when a language server fails to initialize or hangs.

## Details

Tests `agent.lsp.manager.LSPService` broken-set behavior:

- **Key structure**: `_mark_broken_for_file` keys on `(server_id, per_server_root)` so all files in the same project share the broken state
- **Short-circuit**: Once marked broken, `enabled_for` returns `False` for all files in that project, skipping the LSP path entirely
- **Project isolation**: Marking pyright broken for project A does NOT affect project B
- **Graceful no-ops**: Files with unregistered extensions or outside any git worktree silently skip broken-set insertion
- **Outer timeout integration**: When `snapshot_baseline`'s outer `_loop.run` timeout triggers, `_mark_broken_for_file` is called, and subsequent `enabled_for` calls return `False`

This prevents every edit from re-paying the full timeout cost when a language server is wedged or missing.
