## Details

A stdlib-only JSON-RPC LSP server mock for testing `agent.lsp.client.LSPClient`:

- **Protocol**: Reads/writes Content-Length framed JSON-RPC messages on stdin/stdout
- **Configurable scripts** via `MOCK_LSP_SCRIPT` env var:

- **Supported methods**: `initialize`, `initialized`, `workspace/didChangeConfiguration`, `workspace/didChangeWatchedFiles`, `textDocument/didOpen`, `textDocument/didChange`, `textDocument/diagnostic` (pull), `textDocument/didSave`, `shutdown`, `exit`
