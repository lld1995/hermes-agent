## Summary

Tests transport auto-detection logic that selects the correct wire protocol (OpenAI chat.completions vs Anthropic Messages) based on endpoint URLs and explicit api_mode overrides.

## Details

Regression tests for the April 2026 Kimi Coding Plan 404 bug, where auxiliary clients sent chat.completions to endpoints that only speak Anthropic Messages.

**`_endpoint_speaks_anthropic_messages` URL detection:**
- Triggers on: `api.kimi.com/coding`, `api.minimax.io/anthropic`, `/anthropic` suffix, `api.anthropic.com`
- Does NOT trigger on: OpenRouter, OpenAI, Moonshot legacy, Nous, empty/None

**`_maybe_wrap_anthropic` decision table:**
- Rewraps plain OpenAI clients pointed at Kimi Coding or `/anthropic` URLs into `AnthropicAuxiliaryClient`
- Skips wrapping for OpenRouter/OpenAI/Moonshot URLs
- `api_mode=chat_completions` explicitly bypasses wrapping; `api_mode=anthropic_messages` forces it
- Already-wrapped `AnthropicAuxiliaryClient` passes through unchanged (double-wrap safe)
- `CodexAuxiliaryClient` is never re-dispatched
- ImportError on anthropic SDK falls back to plain client with warning

**Integration test:**
- `resolve_provider_client('kimi-coding', 'kimi-for-coding')` with `KIMI_API_KEY` must return `AnthropicAuxiliaryClient` targeting `api.kimi.com/coding`
