## Summary

Tests for context reference parsing and expansion, covering @file, @folder, @diff, @git, and @url references with path safety, budget gating, and async URL fetching.

## Details

- **Reference parsing**: `parse_context_references()` extracts typed references (`@file:path:lines`, `@folder:path`, `@diff`, `@git:N`, `@url:url`) while ignoring emails and `@mentions`. Handles quoted paths with spaces and strips trailing punctuation.
- **File/folder expansion**: `preprocess_context_references()` expands `@file` ranges and `@folder` listings (via `rg` or fallback), injecting content into the message with `--- Attached Context ---` markers.
- **Git operations**: Expands `@diff` (unstaged), `@staged`, and `@git:N` (log with patch) using subprocess git commands.
- **Path safety**: `allowed_root` parameter restricts expansion to a workspace root. Paths outside the root or sensitive locations (`.hermes/.env`, `.ssh/id_rsa`) are blocked with warnings.
- **Budget gating**: Soft budget (25% of context) warns; hard budget (50%) blocks expansion entirely, preserving the original reference syntax.
- **Async URL fetching**: `preprocess_context_references_async()` and the sync wrapper support a pluggable `url_fetcher` coroutine for `@url` expansion.
- **Binary/missing files**: Produce warnings instead of crashing, with descriptive messages in the output.
