## Summary

Comprehensive test suite for ContextCompressor covering compression thresholds, summary generation, error fallback chains, role-collision resolution, token-budget tail protection, and JSON argument truncation safety.

## Details

- **Threshold & trigger logic**: Tests `should_compress()` against `threshold_percent`, explicit token overrides, and edge cases at exact boundaries.
- **Summary generation**: Validates `_generate_summary()` handles `content=None` (tool-call-only messages), dict content coercion, and non-string LLM responses without crashing.
- **Fallback chain**: When `summary_model_override` fails (404, 400, JSONDecodeError, streaming disconnect), the compressor retries once on the main model before entering cooldown. Tests verify cooldown durations (30s for transient errors, 60s for unknowns) and that aux-model failures are surfaced via `_last_aux_model_failure_*` fields.
- **Role collision resolution**: Summary messages must not create consecutive same-role messages. Tests cover head/tail collision detection, role flipping, and double-collision merging into the first tail message (including structured list content).
- **Token-budget tail protection**: Tail protection uses a token budget (`tail_token_budget`) rather than fixed message count, preventing large tool outputs from blocking compaction. Includes soft-ceiling (1.5x) and hard-minimum (3 messages) guards.
- **JSON argument truncation**: `_truncate_tool_call_args_json` must produce valid, parseable JSON when shrinking oversized `function.arguments`, preserving structure while truncating string values.
- **Budget recalculation**: `update_model()` must recalculate `tail_token_budget` and `max_summary_tokens` proportionally to the new context length.
