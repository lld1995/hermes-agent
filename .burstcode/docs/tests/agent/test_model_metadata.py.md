- **Context probe tiers**: Descending sequence from 256k to 8k; `get_next_probe_tier` steps down on context-exceeded errors
- **Error parsing**: Extracts context limits from OpenAI, Ollama, Anthropic, LMStudio, and MiniMax error formats; rejects unreasonable values
- **Persistent cache**: YAML file keyed by `model@base_url`; handles corruption, wrong structure, and special characters in model names
