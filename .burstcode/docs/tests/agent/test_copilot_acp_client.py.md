## Summary

Safety-layer regression tests for CopilotACPClient, covering permission denial, file read/write blocking, sensitive content redaction, and HOME environment propagation.

## Details

- **Permission requests**: `session/request_permission` messages are never auto-allowed; outcome defaults to `cancelled`.
- **Read blocking**: `fs/read_text_file` blocks access to internal Hermes paths (`.hermes/skills/.hub/`) and redacts sensitive content (API keys) when `agent.redact._REDACT_ENABLED` is active.
- **Write blocking**: `fs/write_text_file` respects `is_write_denied` denylist (e.g., `.ssh/id_rsa`) and `HERMES_WRITE_SAFE_ROOT` env-var sandbox — writes outside the safe root are rejected.
- **HOME propagation**: `_run_prompt()` subprocess calls propagate `HOME` from the Hermes profile home (`HERMES_HOME/home`) when available, or fall back to a clean env with `HOME` set. Ensures Copilot subprocess inherits the correct user context.
