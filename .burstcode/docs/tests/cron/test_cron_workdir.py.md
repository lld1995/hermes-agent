## Summary

Tests per-job workdir support in the cron scheduler, covering path normalization, job CRUD plumbing, tool JSON round-trips, sequential execution partitioning, and TERMINAL_CWD mutation/restoration during job runs.

## Details

- **`_normalize_workdir`**: Validates absolute paths, expands `~`, rejects relative/missing/file paths, returns `None` for empty/whitespace.
- **`create_job` / `update_job`**: Persist `workdir` as resolved absolute string; `None`/empty clears it; invalid paths raise `ValueError`.
- **`cronjob_tools`**: JSON round-trip preserves `workdir`; `_format_job` omits the field when unset to reduce agent output noise; schema advertises `workdir` with "absolute" in description.
- **`scheduler.tick()`**: Partitions jobs — workdir jobs run sequentially on the main thread (outside `ThreadPoolExecutor`) to avoid `TERMINAL_CWD` race conditions; parallel jobs run after.
- **`scheduler.run_job()`**: Sets `TERMINAL_CWD` to workdir, flips `skip_context_files=False`, restores original `TERMINAL_CWD` in `finally` even on error; no-workdir jobs leave `TERMINAL_CWD` untouched.
