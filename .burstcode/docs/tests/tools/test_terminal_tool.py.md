## Summary

Regression tests for sudo command detection, password handling, caching, and workdir validation in `terminal_tool`.

## Details

- `_transform_sudo_command` ignores `sudo` in search queries, printf literals, and grep arguments
- Actual `sudo` commands are rewritten with `-S -p ''` and stdin password injection
- Cached sudo passwords are isolated by `HERMES_SESSION_KEY`
- Passwordless sudo (`sudo -n`) skips interactive prompts and rewrite
- Passwordless probe rechecks on each call and is disabled for non-local backends
- `_validate_workdir` allows Windows drive/UNC paths but blocks shell metacharacters (`;`, `$()`, newlines)
