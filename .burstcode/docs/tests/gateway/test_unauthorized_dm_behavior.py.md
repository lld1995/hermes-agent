## Summary

Tests unauthorized DM handling across platforms. Covers allowlist resolution, WhatsApp LID mapping, wildcard authorization, group-specific allowlists, pairing defaults, rate limiting, and the allowlist-derived 'ignore' default behavior.

## Details

- Tests `_is_user_authorized` with platform-specific allowlist env vars
- WhatsApp LID-to-phone mapping via session directory JSON files
- `*` wildcard in allowlists authorizes any user
- QQ group allowlists authorize by chat_id, not user_id
- Telegram group allowlists: sender IDs vs legacy chat-ID backward compat
- Default behavior: unauthorized DMs trigger pairing code generation
- Allowlist presence changes default to 'ignore' (no pairing spam)
- Rate-limited users get silent rejection
- `unauthorized_dm_behavior` config can override allowlist-derived defaults
- Global `GATEWAY_ALLOWED_USERS` also triggers ignore behavior
