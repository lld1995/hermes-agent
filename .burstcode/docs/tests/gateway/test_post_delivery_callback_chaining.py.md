## Summary

Tests the post-delivery callback chaining mechanism on BasePlatformAdapter, verifying ordered execution, exception isolation, and generation-based stale rejection.

## Details

- **Single callback**: Registers and pops one callback, confirms it fires.
- **Chaining**: Two and three callbacks chain in registration order; composing over an already-chained callback preserves order.
- **Exception isolation**: A callback that raises does not block subsequent callbacks from executing.
- **Generation tracking**: Callbacks registered with the same generation chain together; popping with a different generation returns None.
- **Stale rejection**: Registering a callback with an older generation than the existing entry is silently rejected — it does not clobber the newer run's slot.
- **Edge cases**: Empty session key and non-callable values are no-ops, leaving `_post_delivery_callbacks` empty.
