## Summary

Shared helper to safely load platform plugin `adapter.py` modules in tests without polluting `sys.path` or causing `sys.modules` collisions.

## Details

- Solves xdist worker race conditions where multiple plugins share the `adapter` module name.
- Uses `importlib.util.spec_from_file_location` to load adapters under unique names (`plugin_adapter_<name>`).
- Caches loaded modules in `sys.modules` to prevent redundant imports.
- Raises clear `FileNotFoundError` if the plugin directory or adapter file is missing.
- Ensures modules can self-reflect via `sys.modules[__name__]` by registering before execution.
