## Summary

Tests the pre_gateway_dispatch plugin hook that intercepts incoming messages before auth and agent dispatch, supporting skip, rewrite, and allow actions.

## Details

- **Skip action**: Plugin returning `{"action": "skip"}` drops the message before auth; no pairing code generated, no adapter.send called.
- **Rewrite action**: Plugin returning `{"action": "rewrite", "text": "..."}` mutates `event.text` before it reaches the agent handler.
- **Allow action**: Plugin returning `{"action": "allow"}` continues normal dispatch through the auth chain.
- **Exception safety**: A raising plugin hook does not break the gateway; dispatch falls through to auth.
- **Internal event bypass**: Events with `event.internal=True` skip the plugin hook entirely, even if the hook would return skip.
- **Test harness**: `_make_runner` constructs a minimal `GatewayRunner` with mocked adapters, pairing store, and session store; `_clear_auth_env` removes all allowed-user env vars for clean auth testing.
