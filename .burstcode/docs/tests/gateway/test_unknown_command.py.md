## Summary

Tests unknown slash command handling and the `command:<name>` hook system. Verifies that unrecognized commands return user guidance instead of leaking to the LLM, and that hooks can deny, handle, allow, or rewrite commands.

## Details

- Tests unknown `/command` returns guidance with `/commands` hint
- Underscored forms (Telegram autocomplete) also guarded
- Known builtins like `/status` bypass the unknown guard
- `command:<name>` hook system: deny/handled/allow/rewrite decisions
- Deny blocks dispatch with custom or default message
- Handled short-circuits with custom reply
- Allow is passthrough to normal handler
- Rewrite re-resolves to a different command (e.g., `/status` → `/metricas`)
- Plugin-registered commands also trigger hooks
- Non-dict hook return values are safely ignored
