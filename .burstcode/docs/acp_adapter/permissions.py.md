## Summary

Bridges ACP permission requests to Hermes' dangerous-command approval system, mapping protocol options to internal approval strings and handling timeouts.

## Details

- `_build_permission_options()`: Constructs ACP `PermissionOption` lists matching Hermes semantics (`allow_once`, `allow_session`, `allow_always`, `deny`).
- `_build_permission_tool_call()`: Creates a unique `perm-check-N` tool call update for each request.
- `_map_outcome_to_hermes()`: Translates ACP `AllowedOutcome` back to Hermes approval strings.
- `make_approval_callback()`: Returns a synchronous callback that runs `request_permission` on the async loop via `run_coroutine_threadsafe`, enforcing a configurable timeout and auto-denying on failure.
