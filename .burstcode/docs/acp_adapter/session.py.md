## Summary

Session management and persistence layer that maps ACP sessions to `AIAgent` instances, handles Windows/WSL path translation, and syncs state to SQLite.

## Details

- `SessionState` dataclass: Tracks per-session history, agent instance, CWD, model, cancellation events, and queued prompts.
- `SessionManager`: Thread-safe manager for creating, restoring, forking, and listing sessions. Persists to `hermes_state.SessionDB`.
- Path translation: `_translate_acp_cwd()` and `_win_path_to_wsl()` convert Windows drive paths to WSL `/mnt/<drive>/` equivalents for cross-platform tool execution.
- `_make_agent()`: Factory that instantiates `AIAgent` with resolved provider config, enabled toolsets, and session-specific context.
- `_persist()` & `_restore()`: Handle atomic history replacement and metadata synchronization with the shared state database.
