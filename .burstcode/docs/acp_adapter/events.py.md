## Summary

Callback factories that bridge synchronous AIAgent events to asynchronous ACP session updates, handling tool progress, reasoning, steps, and messages.

## Details

- `_send_update()`: Fire-and-forget helper using `asyncio.run_coroutine_threadsafe` to push updates from worker threads to the main event loop.
- `make_tool_progress_cb()`: Tracks tool call IDs in FIFO queues per tool name to handle parallel/duplicate calls; emits `ToolCallStart` updates.
- `make_thinking_cb()` & `make_message_cb()`: Stream reasoning and response text to the client.
- `make_step_cb()`: Processes completed tool results from AIAgent, matches them to queued IDs, and emits `ToolCallComplete` updates.
