## Summary

Authentication helpers that detect the currently configured Hermes runtime provider by querying the CLI's runtime provider resolver.

## Details

- `detect_provider()`: Attempts to resolve the active runtime provider and API key from `hermes_cli.runtime_provider`. Returns the normalized provider string or `None` on failure.
- `has_provider()`: Convenience wrapper returning `True` if `detect_provider()` yields a non-`None` result.
- Uses broad exception handling to gracefully degrade when CLI dependencies are missing.
