_Generated by BurstCode background explorer at 2026-05-14T11:59:22.789Z_

## Summary

Maps Hermes tool names to ACP ToolKind categories, builds human-readable tool-call titles, formats structured completion results into Markdown, and constructs ACP ToolCallStart/ToolCallProgress events with diff content for file-editing tools.

## Details

Key responsibilities:
- **TOOL_KIND_MAP**: Dict mapping ~40 Hermes tool names to ACP `ToolKind` values (read, edit, execute, fetch, think, other).
- **_POLISHED_TOOLS**: Set of tool names that get structured result formatting and hide raw output from ACP.
- **build_tool_title()**: Generates concise, argument-aware titles for ~25 tool types (terminal, read_file, patch, delegate_task, etc.).
- **Result formatters**: A family of `_format_*_result()` functions that parse JSON tool output into readable Markdown (todo lists, file reads, search results, delegation summaries, browser results, etc.).
- **_build_patch_mode_content()**: Parses V4A patch text via `tools.patch_parser` into ACP diff blocks (UPDATE, ADD, DELETE, MOVE operations).
- **_parse_unified_diff_content()**: Converts unified diff text into `acp.tool_diff_content` blocks.
- **build_tool_start()**: Constructs `ToolCallStart` events with appropriate content (diff blocks for write/patch, text previews for terminal/code, empty for read_file/web_extract).
- **build_tool_complete()**: Constructs `ToolCallProgress` completion events, optionally calling `agent.display.extract_edit_diff` for write_file/patch/skill_manage.
- **extract_locations()**: Pulls file path + line from tool arguments for ACP location tracking.
- **Helpers**: `_json_loads_maybe()` handles JSON-with-trailing-hint payloads; `_fenced_text()` produces backtick fences that won't break on embedded backticks; `_truncate_text()` caps output lengths.
