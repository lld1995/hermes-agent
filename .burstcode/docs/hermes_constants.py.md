## Summary

Import-safe shared constants and path resolvers for Hermes, including `HERMES_HOME` resolution, profile fallback warnings, environment detection (WSL/Container/Termux), and IPv4 preference patching.

## Details

- **Home resolution**: `get_hermes_home()` reads `HERMES_HOME`, falls back to `~/.hermes`, and emits a one-shot stderr warning if a non-default profile is active but `HERMES_HOME` is unset.
- **Profile & Docker roots**: `get_default_hermes_root()` navigates `<root>/profiles/<name>` structures to locate the true data root for listing profiles.
- **Subprocess isolation**: `get_subprocess_home()` returns `{HERMES_HOME}/home/` if it exists, allowing git/ssh/npm to write configs inside the Hermes data directory.
- **Environment detection**: `is_wsl()`, `is_container()`, and `is_termux()` cache results for fast runtime checks.
- **Network patching**: `apply_ipv4_preference()` monkey-patches `socket.getaddrinfo` to skip IPv6 lookups when `network.force_ipv4` is enabled.
