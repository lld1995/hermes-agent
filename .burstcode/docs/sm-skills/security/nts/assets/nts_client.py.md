## Summary

Minimal CLI client for the NTS WebAPI v7.3.0. Handles system info, health, netlinks, IOC queries, and pcap downloads. Parses custom binary pcap streams into standard libpcap format. Includes alert file parsing and batch download workflows.

## Details

- Implements `NTSClient` for querying system status, network links, and IOCs (DNS, IP, hash, URL, email, cert, JA3)
- Handles chunked binary pcap downloads, translating NTS's custom header format into standard libpcap files
- Provides `parse_alerts_file` to extract four-tuple records from JSON, JSONL, or syslog-style alert logs
- CLI subcommands: `version`, `health`, `netlinks`, `payload`, `download-pcap`, `query-ioc`, `parse-alerts`, `batch-download`, `workflow`
- Auth via `Auth-Key` header; defaults to `NTS_URL`/`NTS_TOKEN` env vars
- Disables TLS verification by default for self-signed NTS appliances
