## Summary

Centralized logging setup providing rotating file handlers, session context injection, component filtering, and secret redaction across CLI, gateway, and cron modes.

## Details

- **Idempotent setup**: `setup_logging()` configures `agent.log`, `errors.log`, and `gateway.log` (when `mode="gateway"`), skipping re-initialization unless `force=True`.
- **Session context**: `_install_session_record_factory()` injects a `session_tag` into every `LogRecord` via thread-local storage, enabling per-conversation filtering.
- **Component routing**: `_ComponentFilter` uses `COMPONENT_PREFIXES` to isolate gateway-specific logs into `gateway.log` while keeping `agent.log` as a catch-all.
- **Secret redaction**: All file handlers use `agent.redact.RedactingFormatter` to mask sensitive data before disk writes.
- **NixOS compatibility**: `_ManagedRotatingFileHandler` applies `chmod 0660` after creation/rollover to respect setgid state directories.
