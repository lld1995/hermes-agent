Stdio MCP server exposing Hermes messaging conversations as tools, backed by an `EventBridge` that polls `SessionDB` and `sessions.json` for live updates.

## Details

- **MCP tool surface**: Exposes `conversations_list`, `messages_read`, `events_poll`, `events_wait`, `messages_send`, `channels_list`, and approval management tools.
- **Approval tracking**: `_pending_approvals` dict captures approval requests observed during the bridge session, allowing MCP clients to resolve them.
- **Lazy SDK import**: `FastMCP` is imported conditionally; missing `mcp` package surfaces a clear install hint at runtime.
- **Data extraction**: `_extract_message_content` and `_extract_attachments` normalize multi-part content blocks and `MEDIA:` tags for consistent tool outputs.
