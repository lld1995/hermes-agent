## Summary

Windows-only UTF-8 bootstrap module. Sets `PYTHONUTF8`/`PYTHONIOENCODING` env vars and reconfigures `sys.stdout`/`stderr`/`stdin` to UTF-8 to prevent `UnicodeEncodeError` crashes on Windows consoles.

## Details

- **Env vars**: `os.environ.setdefault("PYTHONUTF8", "1")` and `"PYTHONIOENCODING"` so child processes inherit UTF-8 mode.
- **Stream reconfiguration**: Uses `TextIOWrapper.reconfigure(encoding="utf-8", errors="replace")` on `stdout`, `stderr`, and `stdin`.
- **Idempotent**: `_bootstrap_applied` guard prevents double-reconfigure; safe to import multiple times.
- **POSIX no-op**: Does nothing on non-Windows platforms to avoid interfering with user `LANG`/`LC_*` settings.
- **Import-side-effect**: Calls `apply_windows_utf8_bootstrap()` at module level, so entry points just need `import hermes_bootstrap` at the top.
