## Summary

Timezone-aware clock helper that resolves IANA timezones from `HERMES_TIMEZONE` or `config.yaml`, caching the result for fast `now()` calls.

## Details

- **Resolution order**: Prioritizes `HERMES_TIMEZONE` env var, then `timezone` key in `config.yaml`, falling back to server local time.
- **Validation & caching**: `_get_zoneinfo()` validates IANA strings and caches the `ZoneInfo` object; `reset_cache()` forces re-resolution after config changes.
- **Safe fallbacks**: Invalid timezone strings log a warning and gracefully degrade to `datetime.now().astimezone()` instead of crashing.
- **Import safety**: Uses `zoneinfo` (Python 3.9+) with a `backports.zoneinfo` fallback, avoiding heavy dependencies at module load time.
