## Summary

Pure utility module for model metadata resolution, context length detection, and rough token estimation. Supports live probing of OpenRouter, custom endpoints, local servers (Ollama, LM Studio, vLLM, llama.cpp), and provider-specific APIs (Codex OAuth, Nous Portal, Anthropic).

## Details

- **Context length resolution** (`get_model_context_length`): 10-step cascade — config override → persistent cache → Bedrock static table → custom endpoint probe → local server query → Anthropic API → provider-specific lookups (Copilot, Nous, Codex OAuth, GMI, Ollama, models.dev) → OpenRouter cache → hardcoded defaults → local fallback → 256K default.
- **Provider prefix stripping**: `_strip_provider_prefix()` removes known provider prefixes (e.g., `local:`, `openrouter/`) while preserving Ollama `model:tag` colons.
- **Local endpoint detection**: `is_local_endpoint()` recognizes loopback, RFC-1918, link-local, Tailscale CGNAT, and container DNS suffixes. `detect_local_server_type()` probes for Ollama, LM Studio, vLLM, llama.cpp.
- **Persistent caching**: `save_context_length()` / `get_cached_context_length()` store discovered limits in `context_length_cache.yaml` keyed by `model@base_url`. Stale entries (Codex OAuth, Kimi underreports, Nous) are invalidated.
- **Token estimation**: `estimate_request_tokens_rough()` counts system prompt, messages, and tool schemas (~4 chars/token). Images cost a flat 1500 tokens each to avoid base64 inflation.
- **Error parsing**: `parse_context_limit_from_error()` extracts limits from API error messages; `parse_available_output_tokens_from_error()` detects output-cap errors vs prompt-length errors.
