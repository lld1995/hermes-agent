## Summary

Provides a secure, host-owned LLM facade for trusted plugins. Enforces per-plugin trust policies from `config.yaml` to gate provider/model overrides, and delegates actual inference to `agent.auxiliary_client`.

## Details

- Exposes `PluginLlm` class with `complete()`, `complete_structured()`, and async variants
- Trust gate (`_TrustPolicy`) validates `allow_*_override` flags and allowlists per plugin
- Normalizes text/image inputs into OpenAI-compatible message formats
- Handles JSON schema validation (optional `jsonschema` dependency) and code fence stripping
- Extracts usage metrics and resolves attribution (provider/model) from responses
- Lazy-imports `agent.auxiliary_client` to avoid circular dependencies at plugin discovery
