## Summary

Schema sanitizer that strips OpenAI/JSON Schema keys unsupported by Gemini's `FunctionDeclaration.parameters`, recursively cleaning nested properties and coercing typed enums to strings.

## Details

- Maintains `_GEMINI_SCHEMA_ALLOWED_KEYS` whitelist matching Google's documented schema subset
- Recursively sanitizes `properties`, `items`, and `anyOf` blocks to remove incompatible keys
- Drops `enum` arrays when parent type is `integer`/`number`/`boolean` to satisfy Gemini's string-only enum rule
- Guarantees a valid `{"type": "object", "properties": {}}` fallback for empty or malformed schemas
- Used by the native adapter to prevent 400 Bad Request errors on tool definition injection
