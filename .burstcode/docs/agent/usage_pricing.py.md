## Summary

Cross-provider token usage normalization and cost estimation engine with hardcoded pricing snapshots for Anthropic, OpenAI, Google, Bedrock, DeepSeek, and MiniMax models.

## Details

Usage normalization and pricing estimation across all supported providers.

- **CanonicalUsage**: Frozen dataclass with granular token buckets (`input_tokens`, `output_tokens`, `cache_read_tokens`, `cache_write_tokens`, `reasoning_tokens`). Derived properties compute `prompt_tokens` and `total_tokens`.
- **PricingEntry**: Per-model cost rates (per-million tokens) with source attribution (`official_docs_snapshot`, `provider_models_api`, etc.).
- **_OFFICIAL_DOCS_PRICING**: Hardcoded pricing table for ~30 models across Anthropic (Claude 3/4 series), OpenAI (GPT-4o/4.1/o3), Google Gemini, AWS Bedrock, DeepSeek, and MiniMax.
- **resolve_billing_route()**: Determines billing mode from provider/base_url (subscription_included for Codex, official_docs_snapshot for Anthropic/OpenAI, etc.).
- **normalize_usage()**: Converts raw API usage objects into `CanonicalUsage`, handling three API shapes: Anthropic (separate cache fields), Codex Responses (input_tokens includes cache), OpenAI Chat Completions (prompt_tokens includes cache). Includes fallback for OpenAI-compatible proxies that expose Anthropic-style cache fields.
- **estimate_usage_cost()**: Computes USD cost from `CanonicalUsage` + pricing entry, with per-bucket validation.
- **get_pricing_entry()**: Resolves pricing via OpenRouter models API, custom endpoint metadata, or hardcoded snapshot.
