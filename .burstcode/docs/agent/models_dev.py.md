## Summary

Integrates with the models.dev registry to fetch, cache, and query provider/model metadata. Implements a multi-tier caching strategy (in-memory, disk, network) and provides helper functions to resolve context windows, capabilities, and filter agentic models.

## Details

- Fetches registry from `https://models.dev/api.json` with offline-first fallback
- Caches data in-memory (1h TTL) and on-disk (`~/.hermes/models_dev_cache.json`)
- Maps Hermes provider IDs to models.dev IDs via `PROVIDER_TO_MODELS_DEV`
- Provides `lookup_models_dev_context()` and `get_model_capabilities()` for runtime model introspection
- Filters out non-agentic/noise models (TTS, embeddings, low-TPM Gemma variants)
- Exposes `ModelInfo` and `ProviderInfo` dataclasses for rich metadata
