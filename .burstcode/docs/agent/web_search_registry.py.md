## Details

Central registry for web search/extract/crawl backends with sophisticated fallback logic.

- **_providers dict**: Thread-safe map of provider name → `WebSearchProvider`, protected by `_lock`.
- **register_provider()**: Adds/overwrites providers. Validates type and non-empty name.
- **_read_config_key()**: Resolves dotted config paths from `config.yaml`.
- **_LEGACY_PREFERENCE**: Ordered tuple `(firecrawl, parallel, tavily, exa, searxng, brave-free, ddgs)` preserving pre-migration behavior.
- **_resolve(configured, capability)**: Core resolution with 3 tiers:
  1. Explicit config wins (even if unavailable — surfaces precise error).
  2. Single eligible provider shortcut.
  3. Legacy preference walk filtered by `supports_<capability>()` and `is_available()`.
- **get_active_search/extract/crawl_provider()**: Public entry points reading `web.{capability}_backend` or `web.backend` from config.
- **_is_available_safe()**: Wraps `is_available()` in try/except so buggy providers don't kill resolution.
- **_reset_for_tests()**: Clears registry for test isolation.
