## Summary

Orchestrates background skill maintenance by auto-transitioning lifecycle states and spawning a forked LLM agent to consolidate, archive, or prune agent-created skills.

## Details

- Manages `.curator_state` to track run intervals, idle thresholds, and pause status, deferring the first run until a full interval elapses.
- Applies pure time-based state transitions (active → stale → archived) before invoking the LLM review pass.
- Spawns a dedicated `AIAgent` fork with isolated credentials, high iteration limits, and suppressed context/memory to execute the `CURATOR_REVIEW_PROMPT`.
- Reconciles LLM-reported YAML summaries, tool-call heuristics, and `absorbed_into` declarations to accurately classify consolidated vs. pruned skills.
- Delegates skill reference updates to `cron.jobs.rewrite_skill_refs` and writes detailed `run.json`/`REPORT.md` artifacts under `~/.hermes/logs/curator/`.
