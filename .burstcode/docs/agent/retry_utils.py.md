## Summary

Jittered exponential backoff utility that decorrelates concurrent retries across multiple sessions hitting the same rate-limited provider, preventing thundering-herd retry spikes.

## Details

- **`jittered_backoff()`**: Computes delay as `min(base_delay * 2^(attempt-1), max_delay) + uniform_jitter`. Default: base=5s, max=120s, jitter_ratio=0.5.
- **Decorrelation**: Uses a monotonic `_jitter_counter` protected by `_jitter_lock` to ensure unique seeds even when multiple threads call simultaneously. Seed combines `time_ns()` XOR'd with a scaled counter tick.
- **Design**: Stateless except for the shared counter. No provider-specific logic — purely a delay calculator. The caller is responsible for sleeping and retrying.
- **Edge cases**: Caps delay at `max_delay` when exponent >= 63 or base_delay <= 0 to prevent overflow.
