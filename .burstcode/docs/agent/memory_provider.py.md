## Summary

Abstract base class defining the contract for pluggable memory providers. Specifies core lifecycle methods, optional hooks for session events and compression, and config schema support for the setup wizard.

## Details

- **Core lifecycle** (must implement): `name`, `is_available()`, `initialize()`, `get_tool_schemas()`. Optional overrides: `system_prompt_block()`, `prefetch()`, `queue_prefetch()`, `sync_turn()`, `handle_tool_call()`, `shutdown()`.
- **Optional hooks**: `on_turn_start()` (per-turn tick), `on_session_end()` (end-of-session extraction), `on_session_switch()` (mid-process session_id rotation with `reset` flag), `on_pre_compress()` (extract insights before compression), `on_delegation()` (parent-side subagent observation), `on_memory_write()` (mirror builtin memory writes).
- **Config schema**: `get_config_schema()` returns fields for the `hermes memory setup` wizard; `save_config()` writes non-secret config to native locations.
- **Design constraints**: Only one external provider allowed at a time (enforced by MemoryManager). Providers should be non-blocking — use background threads for latency-heavy operations. `session_id` is passed for concurrent-session scoping.
- **Backward compatibility**: Default implementations return empty strings/no-ops so older providers work without overriding every hook.
