## Summary

Fetches and renders account usage/limit snapshots from OpenAI Codex, Anthropic (OAuth), and OpenRouter providers, exposing a unified AccountUsageSnapshot dataclass and Markdown rendering.

## Details

Key components:
- **AccountUsageWindow**: Frozen dataclass for a single usage window (label, used_percent, reset_at, detail).
- **AccountUsageSnapshot**: Frozen dataclass aggregating provider, plan, windows, details, and availability status.
- **render_account_usage_lines()**: Formats a snapshot into human-readable lines with remaining percentages and relative reset times; supports optional Markdown bolding.
- **_fetch_codex_account_usage()**: Calls OpenAI Codex usage API, resolves credentials via `hermes_cli.auth`, parses session/weekly rate limits and credits balance.
- **_fetch_anthropic_account_usage()**: Calls Anthropic OAuth usage API; requires OAuth token (resolved via `agent.anthropic_adapter`); parses 5-hour, 7-day, Opus, and Sonnet utilization windows plus extra usage credits.
- **_fetch_openrouter_account_usage()**: Calls OpenRouter credits and key APIs; parses total credits, usage, and per-key quota limits.
- **fetch_account_usage()**: Public dispatcher that normalizes the provider string and routes to the appropriate fetcher; returns None on any exception.
- **Helpers**: `_parse_dt()` handles ISO strings, timestamps, and Z-suffixes; `_format_reset()` computes relative time-to-reset strings.
