## Summary

Realigns markdown tables for accurate terminal rendering with CJK and wide characters. Uses display-width calculations and falls back to vertical key-value layout when tables exceed terminal width.

## Details

- Uses `wcwidth.wcswidth` to calculate true display width per cell
- `split_table_row()` and `is_table_divider()` parse pipe-delimited blocks
- `realign_markdown_tables()` rewrites contiguous table blocks with correct padding
- Falls back to `_render_vertical()` when horizontal width exceeds `available_width`
- Conservative: only rewrites blocks with a divider line; leaves prose untouched
- Clamps negative `wcwidth` results to 0 to prevent column math corruption
