## Summary

CLI subcommand handlers for `hermes lsp`. Provides status, list, install, install-all, restart, and which commands for managing language server binaries and service state.

## Details

### Purpose
Self-contained CLI layer for LSP management, wired into the main argparse via `register_subparser`.

### Subcommands
- **`status`**: Shows service state, active clients, broken pairs, disabled servers, and registry with install status. Supports `--json`.
- **`list`**: Prints supported servers with install status. `--installed-only` filters.
- **`install <server>`**: Eagerly installs one server binary via `try_install`.
- **`install-all`**: Attempts all servers with known recipes. `--include-manual` for manual-install servers.
- **`restart`**: Calls `shutdown_service()` to tear down clients.
- **`which <server>`**: Prints resolved binary path (staged or on PATH).

### Helpers
- **`_recipe_pkg_for`**: Maps server IDs to install-recipe package keys (e.g., `vue-language-server` → `@vue/language-server`).
- **`_backend_warnings`**: Detects missing sidecar binaries (e.g., `shellcheck` for `bash-language-server`) and emits actionable warnings.
