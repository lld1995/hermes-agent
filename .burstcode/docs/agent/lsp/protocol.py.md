## Summary

Minimal LSP JSON-RPC 2.0 framer and envelope builder. Handles Content-Length header parsing, async stream reading, and message classification for the LSP client layer.

## Details

- Encodes/decodes LSP wire format: `Content-Length` header + UTF-8 JSON body
- `read_message()` parses headers with an 8 KiB cap, validates `Content-Length`, and decodes JSON
- Raises `LSPProtocolError` for framing violations, `LSPRequestError` for server error responses
- Provides envelope builders: `make_request`, `make_notification`, `make_response`, `make_error_response`
- `classify_message()` routes incoming payloads to request/response/notification/invalid buckets
- Defines standard LSP error codes (`ERROR_CONTENT_MODIFIED`, `ERROR_REQUEST_CANCELLED`, etc.)
