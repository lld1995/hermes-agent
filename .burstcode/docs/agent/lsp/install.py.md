## Summary

Handles auto-installation of LSP server binaries into a Hermes-owned staging directory. Supports npm, Go, and pip strategies with thread-safe per-package locking, caching, and graceful fallback to manual or in-process checking.

## Details

- Installs missing servers into `~/.hermes/lsp/bin/` to avoid polluting global toolchains
- Supports `auto`, `manual`, and `off` strategies; `auto` triggers subprocess installs
- Uses per-package `threading.Lock` to deduplicate concurrent install requests
- Caches results in `_install_results` to prevent redundant installs
- Symlinks or copies binaries from package managers into the staging dir for stable PATH access
- All failures are non-fatal; returns `None` and lets callers fall back to syntax checkers
