## Summary

Formats raw LSP diagnostics into compact, severity-filtered XML-like blocks for model consumption. Defaults to errors only, caps per-file and total character limits, and handles truncation.

## Details

- Filters diagnostics by severity (defaults to `ERROR` only to avoid flooding the agent)
- `format_diagnostic()` produces one-line summaries with 1-indexed line/column, code, and source
- `report_for_file()` wraps filtered diagnostics in `<diagnostics file="...">` blocks
- Caps output at 20 diagnostics per file and 4000 total characters
- `truncate()` hard-caps formatted strings with a `…[truncated]` marker
- Returns empty strings when no diagnostics pass filters, enabling simple truthy checks
