## Summary

Orchestrates async LSP clients via a background asyncio loop. Manages client lifecycle per server/workspace pair, implements delta diagnostic baselines, and provides a synchronous API for the file operations layer.

## Details

- Runs a single asyncio event loop in a daemon thread (`_BackgroundLoop`)
- Lazily spawns `LSPClient` instances keyed by `(server_id, workspace_root)`
- Maintains a broken-set to permanently skip servers that fail to spawn/initialize
- Tracks diagnostic deltas: `snapshot_baseline()` captures pre-edit state, `get_diagnostics_sync()` filters it out
- Bridges sync callers to async internals via `run_coroutine_threadsafe`
- Exposes `is_active()`, `enabled_for()`, and `get_status()` for CLI and tool layer gating
