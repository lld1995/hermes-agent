## Summary

Registry of per-language LSP server definitions. Maps file extensions to spawn builders, project root resolvers, and initialization options, with fallbacks to auto-install when binaries are missing.

## Details

- `ServerDef` dataclass ties extensions, root resolvers, and spawn builders together
- Spawn builders (`_spawn_*`) resolve binaries, detect venvs, apply env/init overrides, and call `install.try_install()` if missing
- Root resolvers (`_root_*`) walk up for language-specific markers (e.g., `pyproject.toml`, `package.json`)
- Supports exclude markers (e.g., TypeScript skips `deno.json` projects)
- `find_server_for_file()` and `language_id_for()` provide quick lookup utilities
- Registry covers 25+ languages including Python, TS/JS, Go, Rust, PHP, Dockerfile, Terraform, etc.
