## Summary

Implements snapshot and rollback functionality for the ~/.hermes/skills/ directory, ensuring safe recovery before curator maintenance passes.

## Details

- Creates timestamped tar.gz archives of skills, excluding `.curator_backups` and `.hub` to prevent recursion and hub lockfile conflicts.
- Captures auxiliary state files (`.usage.json`, `.archive/`, `.curator_state`, `.bundled_manifest`) to fully rehydrate the skills environment.
- Backs up `~/.hermes/cron/jobs.json` alongside skill archives to preserve cron job skill references during rollback.
- Provides `rollback()` which stages current skills, extracts the target snapshot, and surgically restores only the `skills`/`skill` fields in the live cron jobs file.
- Prunes old snapshots based on configurable retention (`keep`), cleaning up stale `.rollback-staging-*` directories opportunistically.
