## Summary

Implements a cross-session rate limit breaker for Nous Portal using a shared JSON state file. Prevents retry amplification by recording 429 reset times and distinguishing genuine account exhaustion from transient upstream capacity issues.

## Details

- Writes rate limit state to `~/.hermes/rate_limits/nous.json` atomically
- Parses `x-ratelimit-*` and `retry-after` headers to estimate reset windows
- `is_genuine_nous_rate_limit()` differentiates between account quota exhaustion (triggers breaker) and upstream provider jitter (allows fallback/retry)
- Uses a 60-second minimum reset threshold to avoid false positives on transient throttling
- Provides `record_nous_rate_limit()`, `nous_rate_limit_remaining()`, and `clear_nous_rate_limit()` for lifecycle management
