## Summary

Utilities for saving conversation trajectories to JSONL files, including tag conversion from legacy REASONING_SCRATCHPAD to  tags and completion-status-based file routing.

## Details

- `convert_scratchpad_to_think()`: replaces `<REASONING_SCRATCHPAD>` tags with ``/`` for compatibility
- `has_incomplete_scratchpad()`: detects unclosed scratchpad tags (opening without closing)
- `save_trajectory()`: appends a JSONL entry with conversation list, timestamp, model name, and completion flag
- Routes to `trajectory_samples.jsonl` (completed) or `failed_trajectories.jsonl` (failed)
- Wraps file I/O in try/except with warning-level logging on failure
- Static helpers only; `_convert_to_trajectory_format` remains on AIAgent per docstring
