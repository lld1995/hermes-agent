## Summary

Resolves reasoning effort levels for LM Studio's OpenAI-compatible chat.completions endpoint. Maps user config to valid effort values and clamps against the model's declared allowed options.

## Details

### Purpose
Translates the agent's `reasoning_config` into LM Studio's `reasoning_effort` vocabulary, ensuring the value is supported by the target model.

### Key Function
- **`resolve_lmstudio_effort`**: Takes `reasoning_config` dict and `allowed_options` list from model capabilities. Returns a valid effort string or `None` (omit field).

### Mapping Logic
- User `enabled=False` → `"none"`
- Raw effort values aliased: `"off"` → `"none"`, `"on"` → `"medium"`
- Valid efforts: `none`, `minimal`, `low`, `medium`, `high`, `xhigh`
- If `allowed_options` is provided and the resolved effort isn't in the allowed set, returns `None` to let LM Studio use its default.

### Design Notes
- Toggle-style models publish `allowed_options` as `["off", "on"]`; graduated models use `["off", "minimal", "low"]` etc.
- When `allowed_options` is falsy (probe failed), the resolved effort is sent anyway without clamping.
