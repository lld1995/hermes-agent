## Summary

Stateless system prompt assembly module that composes identity, platform hints, skills index, environment awareness, and context files into the agent's system prompt. Includes prompt-injection scanning for context files and a two-layer skills cache (in-process LRU + disk snapshot).

## Details

- **Context file scanning**: `_scan_context_content()` checks AGENTS.md, .cursorrules, SOUL.md, etc. against 11 regex patterns for prompt injection (ignore instructions, hidden divs, curl exfil, invisible unicode). Blocked files are replaced with a `[BLOCKED: ...]` marker.
- **Skills index**: `build_skills_system_prompt()` assembles a categorized skill list from `~/.hermes/skills/` and external dirs. Uses a two-layer cache: in-process `OrderedDict` LRU (max 8 entries) and a disk snapshot (`.skills_prompt_snapshot.json`) validated by mtime/size manifest. Skills are filtered by platform compatibility, disabled lists, and conditional tool/toolset requirements.
- **Environment hints**: `build_environment_hints()` probes the active terminal backend. For local backends, reports host OS, home, cwd. For remote backends (docker, modal, ssh, etc.), runs a live probe command inside the sandbox and caches the result. WSL and Windows-bash hints are appended conditionally.
- **Platform guidance**: `PLATFORM_HINTS` dict contains per-channel instructions for WhatsApp, Telegram, Discord, Slack, Signal, email, cron, CLI, SMS, BlueBubbles, Mattermost, Matrix, Feishu, Weixin, WeCom, QQ, Yuanbao, API server, and WebUI. Each describes markdown support and `MEDIA:/path` file delivery syntax.
- **Model-specific guidance**: `TOOL_USE_ENFORCEMENT_GUIDANCE` and `OPENAI_MODEL_EXECUTION_GUIDANCE` steer GPT/Codex models. `GOOGLE_MODEL_OPERATIONAL_GUIDANCE` targets Gemini/Gemma. `COMPUTER_USE_GUIDANCE` is universal for the `computer_use` toolset.
- **Context file loading**: `build_context_files_prompt()` loads project context with priority: .hermes.md > AGENTS.md > CLAUDE.md > .cursorrules. Each source is capped at 20,000 chars with head/tail truncation.
