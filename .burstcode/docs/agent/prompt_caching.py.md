## Summary

Pure-function module implementing Anthropic's prompt caching strategy. Applies `cache_control` markers to the system prompt and last 3 non-system messages to reduce input token costs by ~75% within a session.

## Details

- **Strategy**: `system_and_3` layout places up to 4 cache breakpoints — the system prompt plus the last 3 non-system messages — all at the same TTL (5m or 1h).
- **`apply_anthropic_cache_control()`**: Takes a list of API messages, deep-copies them, and injects `cache_control` markers. Returns the modified copy.
- **`_apply_cache_marker()`**: Handles all content format variations — string content is wrapped into a list with a text part; list content gets the marker on the last element; tool-role messages are handled specially for native Anthropic format.
- **`_build_marker()`**: Constructs the marker dict. TTL `"1h"` adds an explicit `ttl` field; `"5m"` uses the default ephemeral type.
- **Design**: Stateless, no class dependencies, no AIAgent coupling. Safe to call independently of the agent loop.
