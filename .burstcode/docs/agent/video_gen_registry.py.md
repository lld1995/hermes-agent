## Summary

Thread-safe registry for video generation providers, resolving the active provider from config.yaml with single-provider fallback.

## Details

Central registry for video generation backends.

- **_providers dict**: Thread-safe map of provider name → `VideoGenProvider` instance, protected by `_lock`.
- **register_provider()**: Adds or overwrites a provider. Validates type and non-empty name. Logs debug on re-registration for hot-reload scenarios.
- **list_providers()**: Returns all providers sorted by name.
- **get_provider(name)**: Direct lookup by name.
- **get_active_provider()**: Resolution logic:
  1. Read `video_gen.provider` from `config.yaml`.
  2. If configured name is registered, return it.
  3. If exactly one provider is registered, use it.
  4. Otherwise return `None` (tool surfaces setup error).
- **_reset_for_tests()**: Clears the registry for test isolation.
- Mirrors `agent/image_gen_registry.py` design.
