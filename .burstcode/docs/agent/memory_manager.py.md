## Summary

Orchestrates pluggable memory providers for the agent, enforcing a one-external-provider limit. Provides context fencing helpers, a streaming scrubber for chunked output, and lifecycle hooks for prefetch, sync, session switches, compression, and delegation.

## Details

- **Context fencing**: `sanitize_context()` strips `<memory-context>` tags and system notes from provider output. `StreamingContextScrubber` is a stateful state machine that survives chunk boundaries, holding back partial tags and discarding span contents.
- **MemoryManager class**: Registers providers (builtin always first, at most one external). Indexes tool names to providers for routing.
- **Prefetch/sync**: `prefetch_all()` collects recall context from all providers before each turn; `sync_all()` persists completed turns; `queue_prefetch_all()` schedules background recall for the next turn.
- **Tool routing**: `get_all_tool_schemas()` deduplicates schemas across providers; `handle_tool_call()` routes to the correct provider, returning `tool_error()` on failure.
- **Lifecycle hooks**: `on_turn_start`, `on_session_end`, `on_session_switch`, `on_pre_compress`, `on_delegation`, `shutdown_all`, `initialize_all`.
- **Signature introspection**: `_provider_memory_write_metadata_mode()` uses `inspect.signature` to determine whether a provider accepts `metadata` as keyword, positional, or legacy (no metadata) — enabling backward-compatible `on_memory_write` calls.
- **Error isolation**: All provider calls are wrapped in try/except; failures in one provider never block others.
