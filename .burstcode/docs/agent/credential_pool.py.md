## Summary

Persistent credential management system supporting multi-key failover, exhaustion cooldowns, and automatic token refresh. It seeds credentials from environment variables, OAuth files, and custom providers, syncs with external auth stores to handle single-use refresh tokens, and implements selection strategies like round-robin and least-used.

## Details

- `PooledCredential` dataclass tracks tokens, status, exhaustion timestamps, and provider-specific metadata.
- `CredentialPool` manages entry selection via configurable strategies (`fill_first`, `round_robin`, `random`, `least_used`) and tracks active leases.
- Implements exhaustion tracking with HTTP-status-based cooldowns (401 vs 429) and provider-supplied reset timestamps.
- Syncs tokens with external files (`~/.claude/.credentials.json`, `auth.json`) to resolve single-use refresh token races across processes.
- Seeds pools from singletons, environment variables, and custom provider configs, pruning stale entries on load.
