## Summary

Parses and expands `@` references in user messages (files, folders, git diffs, URLs) into formatted context blocks, enforcing security boundaries and token limits.

## Details

- Regex-based parser extracts `@file`, `@folder`, `@diff`, `@git`, and `@url` references from user input.
- Expands references into markdown blocks with token estimates, respecting line ranges for files and command outputs for git.
- Enforces a 50% hard limit and 25% soft limit on injected tokens relative to the model's context length.
- Blocks sensitive paths (`.ssh`, `.aws`, Hermes internal dirs) and validates expansions against an `allowed_root`.
- Uses `rg` or `os.walk` for folder listings and delegates URL fetching to `tools.web_tools.web_extract_tool`.
- Handles async/sync execution compatibility to run safely in both CLI and gateway environments.
