## Summary

Thread-safe registry for image generation providers, managing plugin registration, availability checks, and active provider resolution with explicit config and legacy fallback logic.

## Details

- Maintains a thread-safe `_providers` dictionary keyed by provider name
- `get_active_provider()` prioritizes explicit `config.yaml` selection over fallbacks
- Applies `is_available()` checks during fallback resolution to avoid uncredentialed backends
- Preserves legacy preference for `fal` provider when no explicit config exists
- Wraps availability checks in try/except to prevent buggy plugins from crashing resolution
