## Summary

AWS Bedrock Converse API adapter that bridges OpenAI-format messages and tools to Bedrock's native SDK, handling client caching, credential resolution, model discovery, and response normalization.

## Details

- Lazily imports `boto3` and caches runtime/control clients per region to optimize startup and connection reuse.
- Implements stale-connection detection (`is_stale_connection_error`) to evict dead HTTP pools and trigger fresh client allocation.
- Resolves AWS credentials and regions via environment variables, named profiles, and implicit IAM roles.
- Converts OpenAI-style messages, tools, and multimodal content to Bedrock Converse format, enforcing strict role alternation and filtering unsupported tool-calling models.
- Normalizes both synchronous and streaming responses into OpenAI-compatible `SimpleNamespace` objects, mapping stop reasons and token usage.
- Discovers available foundation models and inference profiles, caching results for 1 hour.
- Classifies Bedrock-specific errors (context overflow, throttling, overload) to guide agent retry and compression logic.
- Maintains a static fallback table for model context window sizes.
