## Summary

Session Insights Engine that queries the SQLite state database to produce usage reports covering tokens, costs, tool/skill usage, activity patterns, and notable sessions. Formats output for terminal and gateway display.

## Details

### Purpose
Analyzes historical session data to produce comprehensive usage insights, inspired by Claude Code's `/insights` command.

### Key Components
- **`InsightsEngine`**: Main class initialized with a `SessionDB` instance. `generate(days=30)` produces a full report dict.
- **Data gathering**: SQL queries fetch sessions, tool usage (from both `tool_name` column and `tool_calls` JSON), skill usage (`skill_view`/`skill_manage`), and message stats.
- **Computation**: `_compute_overview`, `_compute_model_breakdown`, `_compute_platform_breakdown`, `_compute_tool_breakdown`, `_compute_skill_breakdown`, `_compute_activity_patterns`, `_compute_top_sessions`.
- **Formatting**: `format_terminal()` for CLI display with box-drawing characters; `format_gateway()` for shorter messaging output.

### Cost Estimation
Delegates to `agent.usage_pricing` (`estimate_usage_cost`, `has_known_pricing`). Tracks models with/without known pricing and separates estimated vs actual costs.

### Activity Analysis
Computes day-of-week and hour-of-day distributions, active days count, and max consecutive-day streak.
