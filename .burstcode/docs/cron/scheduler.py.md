## Summary

Orchestrates scheduled cron job execution, supporting both pure-script watchdogs and LLM-driven agents. Handles prompt assembly, skill injection, security scanning, multi-platform delivery routing, and parallel/sequential job scheduling with file-based locking.

## Details

- **Entry Point**: `tick()` acquires a cross-platform file lock, fetches due jobs, advances schedules, and partitions jobs into sequential (workdir-mutating) and parallel batches.
- **Execution Paths**: `run_job()` short-circuits for `no_agent=True` jobs (pure script execution) or initializes `AIAgent` for LLM runs, injecting skills, pre-run scripts, and context from prior jobs.
- **Security & Prompting**: `_build_job_prompt()` assembles instructions, scans the final payload for injection patterns (`_scan_assembled_cron_prompt`), and applies wake-gate logic to skip unnecessary LLM calls.
- **Delivery Routing**: `_deliver_result()` resolves targets via origin, home channels, or explicit platform references, preferring live gateway adapters for E2EE support and falling back to standalone HTTP sends.
- **Isolation & Cleanup**: Uses `contextvars` for per-job session state, mutates `TERMINAL_CWD` for workdir jobs (serialized to avoid global env corruption), and aggressively reaps agent resources, MCP orphans, and stale async clients post-run.
