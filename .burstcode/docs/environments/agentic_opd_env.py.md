## Summary

Implements an On-Policy Distillation (OPD) environment for training agentic LLMs on coding tasks. It runs standard rollouts, extracts hindsight hints from tool results using an LLM judge, and scores student tokens under enhanced distributions via VLLM logprobs to generate dense training signals.

## Details

- Inherits from `HermesAgentBaseEnv` and overrides `collect_trajectories` to inject `distill_token_ids` / `distill_logprobs` into `ScoredDataGroup`.
- Uses a majority-voted LLM judge to extract actionable hints from `(assistant_turn, next_state)` pairs, appending them to prompts for teacher scoring.
- Computes multi-signal rewards: correctness (test pass/fail), efficiency (turn count), and tool usage (terminal + file tools).
- Supports built-in coding tasks (FizzBuzz, Two Sum, etc.) or HuggingFace datasets, with automatic train/eval splits.
- Includes evaluation mode, wandb logging for OPD metrics, and requires a VLLM backend for prompt logprob scoring.
