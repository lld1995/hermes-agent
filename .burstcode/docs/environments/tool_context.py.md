## Summary

Provides a per-rollout handle granting reward and verification functions direct access to all hermes-agent tools, scoped to a specific task_id.

## Details

- Wraps terminal, file I/O, web search, and browser tools with convenience methods.
- Uses `_run_tool_in_thread` to offload sync tool calls to a thread pool, preventing asyncio deadlocks when backends use `asyncio.run()`.
- Implements binary-safe file upload/download via base64 chunking through the terminal.
- Exposes `cleanup()` to deterministically release VMs, browsers, and background processes tied to the rollout.
