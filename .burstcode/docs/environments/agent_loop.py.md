## Summary

Implements a reusable multi-turn agent loop for RL environments, dispatching OpenAI-spec tool calls via `handle_function_call`, managing tool execution in a thread pool, and tracking reasoning, errors, and turn budgets.

## Details

- **Core Loop**: `HermesAgentLoop.run()` iterates up to `max_turns`, sending messages to any OpenAI-compatible server, parsing `tool_calls`, and dispatching via `model_tools.handle_function_call`.
- **Tool Execution**: Routes `todo` locally via an ephemeral `TodoStore`, blocks `memory`/`session_search`, and offloads other tools to a configurable `ThreadPoolExecutor` to prevent `asyncio.run()` deadlocks in sandbox backends.
- **Fallback Parsing**: If the server returns raw tool tags instead of structured `tool_calls`, invokes `environments.tool_call_parsers` to extract and normalize them.
- **State & Budgeting**: Tracks `reasoning_per_turn` across provider formats, records `ToolError` instances, and enforces per-turn result budgets via `tools.tool_result_storage`.
- **Result Packaging**: Returns an `AgentResult` containing the full message history, managed server state (if available), turn count, natural finish flag, and error logs.
