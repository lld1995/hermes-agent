## Summary

A comprehensive evaluation environment for Terminal-Bench 2.0 that runs agentic LLMs in isolated Docker/Modal sandboxes. It handles dataset loading, per-task image resolution, concurrent execution with timeouts, and binary reward verification via test suites.

## Details

- Loads TB2 dataset from HuggingFace, applies task filters, and skips Modal-incompatible tasks (e.g., QEMU, brute-force).
- Resolves Docker images via pre-built Hub tags or extracts Dockerfiles from base64 tar archives using safe extraction helpers.
- Runs `HermesAgentLoop` per task, registers Modal sandbox overrides, and executes test suites in a thread pool to avoid event loop blocking.
- Implements per-task wall-clock timeouts, concurrency control via `asyncio.Semaphore`, streaming JSONL logging, and per-category pass rate aggregation.
- Cleans up sandboxes, thread pools, and temp files on completion or interruption.
