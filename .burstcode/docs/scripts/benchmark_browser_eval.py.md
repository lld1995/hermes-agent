Manual benchmark comparing supervisor WebSocket Runtime.evaluate path against agent-browser subprocess eval path. Starts a headless Chrome instance and runs N iterations of `1 + 1` evaluation.

## Details

- `_find_chrome()` locates Chrome binary via `shutil.which()`

- Warm-up: starts supervisor via `SUPERVISOR_REGISTRY.get_or_start()`, runs sanity check

- Bench 2: agent-browser subprocess path — calls `_run_browser_command(task_id, "eval", [...])` N times; skipped if `agent-browser` CLI not found
- Reports mean, median, min, max latency for each path and computed speedup ratio
