## Summary

Diagnostic tool for Discord voice channel support. Checks Python packages, system tools, environment variables, config, and bot permissions needed for voice mode.

## Details

- `check_packages()`: verifies discord.py, PyNaCl (with Aead test), davey (DAVE E2EE), faster-whisper, edge-tts, elevenlabs
- `check_system_tools()`: checks Opus codec loading (with platform-specific fallback paths) and ffmpeg availability
- `check_env_vars()`: loads `.env` via `hermes_cli.env_loader`, checks DISCORD_BOT_TOKEN, DISCORD_ALLOWED_USERS (resolves usernames via Discord API), GROQ_API_KEY, ELEVENLABS_API_KEY
- `check_config()`: reads `~/.hermes/config.yaml` for STT/TTS provider settings; validates provider-key consistency; checks `gateway_voice_mode.json` state
- `check_bot_permissions()`: authenticates via Discord API, checks guild permissions against required voice bits (Connect, Speak, View Channel, Send Messages)
- Color-coded output with OK/FAIL/WARN symbols
