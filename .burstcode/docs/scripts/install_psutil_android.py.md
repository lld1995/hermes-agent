## Summary

Installs psutil on Termux/Android by patching upstream platform detection to include 'android' alongside 'linux'. Downloads sdist, applies one-line patch, installs with pip/uv.

## Details

- Pins psutil 7.2.2 sdist URL; patches `LINUX = sys.platform.startswith("linux")` to include "android"
- `_resolve_install_cmd()` auto-detects `uv` on PATH, falls back to `python -m pip`; supports `--pip` and `--uv` flags
- Downloads tarball to temp dir, extracts, locates `psutil/_common.py`
- Validates marker string exists before patching; exits with message if upstream changed
- Installs patched tree with `--no-build-isolation` to avoid re-running setup
- Documented as stopgap pending upstream merge of psutil#2762
