## Summary

Performance profiling harness for the Hermes TUI. Launches the Node.js TUI in a PTY, simulates sustained keystroke input, parses `perf.log` for React and Ink pipeline events, and computes percentile/FPS/phase breakdowns with A/B diff support.

## Details

- Forks a PTY to run `node dist/entry.js` with `HERMES_DEV_PERF=1` and `HERMES_TUI_RESUME` set
- Simulates key-repeat input (PageUp, wheel, etc.) at configurable Hz for a set duration
- Parses `perf.log` JSONL, filtering events by timestamp to isolate the test window
- Computes p50/p95/p99/max for React render times, Ink frame durations, and sub-phases (yoga, renderer, diff, write, commit)
- Derives throughput (FPS), interframe gap distributions, patch counts, write bytes, drain latency, and backpressure flags
- `--loop` mode watches TypeScript sources, rebuilds via `npm run build`, and auto-reruns with A/B diffs
- Saves metrics to `/tmp/perf-<LABEL>.json` for later `--compare` runs
