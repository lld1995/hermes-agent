## Summary

Crawls multiple skill sources (skills.sh, GitHub, ClawHub, LobeHub, Claude Marketplace) and builds a deduplicated JSON index with resolved GitHub paths. Uses parallel tree lookups for efficient path resolution.

## Details

- Imports skill source classes from `tools.skills_hub`: `GitHubSource`, `SkillsShSource`, `ClawHubSource`, etc.
- `crawl_skills_sh()` searches with popular queries (react, python, web, etc.) for broad coverage
- `crawl_source()` dispatches to individual sources with ThreadPoolExecutor (max_workers=4)
- `batch_resolve_paths()` optimizes GitHub path resolution: groups skills by repo, fetches one tree per repo, matches SKILL.md files
- `_fetch_repo_tree()` gets default branch and recursive tree via GitHub API
- Deduplication by `identifier`; sorting by source priority then name
- Output: `website/static/api/skills-index.json` with version, timestamp, skill count
- Requires `GITHUB_TOKEN` for better rate limits; warns if anonymous
