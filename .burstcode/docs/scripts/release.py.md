## Summary

Automated release tool for Hermes Agent. Generates CalVer tags, bumps semver, parses git history into categorized changelogs, resolves authors to GitHub @mentions, and optionally publishes via the `gh` CLI with built Python artifacts.

## Details

- Determines CalVer date (YYYY.M.D) and handles same-day suffixes (v2026.3.15.2)
- Bumps semver in `hermes_cli/__init__.py` and `pyproject.toml` on `--publish`
- Parses `git log` with null-delimited format to extract sha, author, subject, and body
- Categorizes commits by conventional-commit prefixes (feat, fix, refactor, etc.) with heuristic fallbacks
- Resolves git authors to GitHub @mentions via a large `AUTHOR_MAP` dict and noreply email regex patterns
- Extracts `Co-authored-by` trailers, filtering out AI/bot emails
- Generates Markdown changelog grouped by category with contributor counts
- On `--publish`: commits version bump, creates annotated tag, pushes, builds sdist/wheel, and invokes `gh release create`
