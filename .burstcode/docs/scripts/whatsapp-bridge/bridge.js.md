## Summary

Standalone Node.js bridge connecting WhatsApp to the Python gateway via Baileys. Exposes HTTP endpoints for messaging, media handling, and health checks while managing QR pairing, session persistence, echo-back prevention, and DNS rebinding protection.

## Details

- Connects to WhatsApp using Baileys with multi-file auth state and QR terminal printing
- Exposes REST endpoints (`/messages`, `/send`, `/edit`, `/send-media`, `/typing`, `/chat/:id`, `/health`) for the Python gateway
- Supports `self-chat` and `bot` modes with allowlist filtering and sender identity normalization
- Prevents message echo-back loops by tracking recently sent IDs and filtering agent prefixes
- Handles media downloads (images, videos, audio, documents) with MIME-based caching and ffmpeg conversion for voice notes
- Implements DNS rebinding protection by validating `Host` headers against loopback aliases
- Manages connection lifecycle with automatic reconnection on disconnect codes and graceful shutdown in pair-only mode
