## Summary

CLI tool that diffs ruff and ty diagnostic JSON reports between two git refs, producing a Markdown summary for GitHub PR comments or step summaries. Normalizes diagnostics to a stable (path, rule, message) key so line-number shifts from unrelated edits don't create false positives.

## Details

- Accepts four JSON inputs: base/head ruff and base/head ty reports
- Normalizes ruff's `{code, filename, location.row, message}` and ty's GitLab-style `{check_name, location.path, ...}` into a unified schema
- Keys diagnostics by `(path, rule, message)` — intentionally omitting line numbers to treat same-file/same-rule issues as identical across commits
- Computes new, fixed, and unchanged sets; renders rule-count tables and collapsible entry lists
- Gracefully handles missing, empty, or malformed input files (treats as zero diagnostics)
- Outputs Markdown to stdout or a file via `--output`
