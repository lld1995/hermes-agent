## Summary

Pipeline to sample trajectories from HuggingFace datasets, filter by minimum token count using parallel tokenization, run trajectory compression, and merge results into a single JSONL file for dataset publishing.

## Details

- Loads multiple HuggingFace datasets via `datasets.load_dataset`, normalizing to a `conversations` field
- Uses `multiprocessing.Pool` with a shared tokenizer to count tokens per trajectory in parallel
- Filters entries >= `min_tokens` (default 16000), then randomly samples to `total_samples`
- Saves raw samples to batched JSONL files under `data/<output_name>_raw/`
- Invokes `trajectory_compressor.TrajectoryCompressor` with a YAML config to compress trajectories
- Merges compressed batch outputs into a single JSONL file
- Supports `--skip_download` to reuse existing sampled data
