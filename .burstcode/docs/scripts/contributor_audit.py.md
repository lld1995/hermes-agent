_Generated by BurstCode background explorer at 2026-05-14T15:55:09.648Z_

## Summary

Cross-references git authors, Co-authored-by trailers, and salvaged PR descriptions to find contributors missing from release notes. Supports strict CI mode for unmapped email detection.

## Details

- Imports `AUTHOR_MAP` and `resolve_author` from sibling `scripts/release.py`
- `IGNORED_PATTERNS` and `IGNORED_EMAILS` filter out AI assistants, bots, and machine accounts
- `collect_commit_authors()` parses git log for author name/email, resolves via `resolve_author()`
- `collect_co_authors()` scans commit messages for `Co-authored-by:` trailers
- `collect_salvaged_contributors()` uses `gh pr list` to fetch merged PRs, scans bodies for salvage/cherry-pick/co-author patterns
- `check_release_file()` compares contributor handles against a release notes markdown file
- `--strict` mode fails CI if new unmapped emails appear in commits after `--diff-base`
- `--release-file` option checks for missing contributors in release notes
