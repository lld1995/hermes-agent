## Summary

Interactive prompt_toolkit app that displays how the current terminal identifies keystrokes. Shows Keys.* identifiers and raw escape bytes for debugging keybinding issues.

## Details

- Uses `prompt_toolkit.Application` with `KeyBindings` and `FormattedTextControl`
- `<any>` handler captures every keystroke, extracts `kp.key` and `kp.data` from `event.key_sequence`
- Maintains rolling `_HISTORY` of last 20 keystrokes
- `c-q` and `c-c` quit handlers
- Header explains common questions: Ctrl+Enter vs Enter, Alt+Enter interception, Shift+Enter collapsing, Home/End byte sequences
- Example output: `key=<Keys.ControlJ: 'c-j'> data='\n'` for Ctrl+Enter on Windows Terminal
- Intended for debugging Hermes keybinding additions, especially on Windows terminals
