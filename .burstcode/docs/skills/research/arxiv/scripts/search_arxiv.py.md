## Summary

CLI tool for searching arXiv papers via the export API. Supports keyword queries, author/category filters, direct ID lookups, and sorting by relevance/date/updated. Parses Atom XML responses and formats clean output.

## Details

- **Purpose**: Query arXiv's public API and display formatted paper results
- **Search modes**: Free-text query, author filter (`au:`), category filter (`cat:`), or direct ID lookup (`id_list`)
- **Sorting**: relevance (default), submittedDate, lastUpdatedDate — all descending
- **Output format**: Numbered results with title, arXiv ID + version, publish/update dates, authors, categories, truncated abstract (300 chars), and abs/pdf links
- **HTTP**: Uses `urllib.request` with custom User-Agent `HermesAgent/1.0` and 15s timeout
- **XML parsing**: ElementTree with Atom namespace; handles OpenSearch totalResults metadata
- **CLI**: Positional query argument with `--max`, `--sort`, `--author`, `--category`, `--id` flags; no argparse — manual arg parsing loop
