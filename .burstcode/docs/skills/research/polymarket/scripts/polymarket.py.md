## Summary

CLI helper for querying Polymarket prediction market data across three API endpoints (Gamma, CLOB, Data). Supports market search, trending events, price/orderbook queries, price history visualization, and recent trades.

## Details

- **Purpose**: Interface with Polymarket's public APIs for prediction market intelligence
- **Three API bases**: Gamma (search/events/markets), CLOB (price/orderbook/history), Data (trades)
- **Commands**: search, trending, market, event, price, book, history, trades
- **Data handling**: Double-encoded JSON field parsing (`outcomePrices`, `outcomes`, `clobTokenIds`); percentage formatting; volume humanization ($K/$M)
- **History visualization**: ASCII bar chart with timestamp, price percentage, and proportional █ blocks
- **Orderbook**: Sorted bids (descending) and asks (ascending), showing top 10 each with price and size
- **Error handling**: HTTPError and URLError caught with stderr output and sys.exit(1)
- **HTTP**: `urllib.request` with User-Agent `hermes-agent/1.0` and 15s timeout
