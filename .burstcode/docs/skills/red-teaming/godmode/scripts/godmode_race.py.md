## Summary

Multi-model racing engine that queries up to 55 LLMs via OpenRouter in parallel, scores responses on quality, refusal detection, and hedge patterns, then returns the best unfiltered answer. Includes tiered model selection and a 'classic' mode racing 5 jailbreak prompt combos.

## Details

- **Purpose**: Race multiple LLMs against a query and return the highest-scoring non-refusal response
- **Model tiers**: fast (10), standard (24), smart (38), power (49), ultra (55) models via OpenRouter
- **Scoring**: Length bonus, hedge penalty (-30 each), code block/list/header bonuses, keyword overlap, technical term detection, actionable content detection
- **Refusal detection**: 14 regex patterns matching common refusal phrases ("I cannot", "I'm sorry", etc.)
- **Hedge detection**: 11 regex patterns for disclaimers, warnings, and safety caveats
- **Classic mode**: Races 5 specific model+jailbreak prompt combos (Claude 3.5 Sonnet, Grok 3, Gemini 2.5 Flash, GPT-4o, Hermes 4 405b)
- **Concurrency**: ThreadPoolExecutor with configurable max_workers (default 10) and per-request timeout (default 60s)
- **Usage**: Designed for `exec()` injection into agent code execution context; requires `openai` package and `OPENROUTER_API_KEY` env var
