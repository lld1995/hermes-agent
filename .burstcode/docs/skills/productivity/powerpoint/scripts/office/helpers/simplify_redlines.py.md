## Summary

Simplifies DOCX tracked changes by merging adjacent `<w:ins>` or `<w:del>` elements from the same author. Also provides author inference by comparing tracked changes between original and modified documents.

## Details

- **Merge rules**: Only merges same-type elements (`ins`↔`ins`, `del`↔`del`) from the same author
- **Adjacency**: Only merges if truly adjacent (whitespace-only between elements)
- **Scope**: Processes tracked changes in paragraphs (`<w:p>`) and table cells (`<w:tc>`)
- **Author inference**: `infer_author()` compares tracked change authors between original DOCX and modified unpacked directory
- **Author extraction**: `get_tracked_change_authors()` parses unpacked XML; `_get_authors_from_docx()` reads zipped DOCX
- **Conflict detection**: Raises `ValueError` if multiple authors added new changes
- **XML parsing**: Uses `defusedxml.minidom` for DOM manipulation, `xml.etree.ElementTree` for XPath queries
- **Returns**: Tuple of (merge_count, status_message)
