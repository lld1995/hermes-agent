## Summary

Merges adjacent DOCX runs with identical formatting, removes rsid revision metadata, and strips proofErr elements. Operates on unpacked DOCX `word/document.xml` to reduce XML bloat.

## Details

- **Run merging**: Combines adjacent `<w:r>` elements with identical `<w:rPr>` properties
- **Scope**: Works on runs in paragraphs and inside tracked changes (`<w:ins>`, `<w:del>`)
- **Metadata cleanup**: Removes `rsid` attributes (revision IDs that don't affect rendering)
- **Proof markers**: Strips `<proofErr>` elements that block merging
- **Text consolidation**: Merges adjacent `<w:t>` text nodes within runs
- **Whitespace handling**: Preserves `xml:space="preserve"` when merged text has leading/trailing spaces
- **Adjacency check**: Considers runs adjacent only if separated by whitespace text nodes
- **XML parsing**: Uses `defusedxml.minidom` for safe DOM manipulation
- **Returns**: Tuple of (merge_count, status_message)
