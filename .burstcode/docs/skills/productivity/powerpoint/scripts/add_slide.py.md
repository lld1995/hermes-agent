## Summary

Adds slides to unpacked PPTX directories by duplicating existing slides or creating from layout templates. Updates [Content_Types].xml, presentation.xml.rels, and prints the sldId element for manual insertion.

## Details

- **Two modes**: Duplicate existing slide (`slide2.xml`) or create from layout (`slideLayout2.xml`)
- **Auto-numbering**: Finds next available slide number from existing `slide*.xml` files
- **Layout creation**: Generates minimal slide XML with proper namespace declarations and relationship to layout
- **Relationship management**: Adds entries to `presentation.xml.rels` with auto-incremented rId
- **Content types**: Registers new slide in `[Content_Types].xml`
- **Slide ID**: Computes next `sldId` from `presentation.xml` (starts at 256 if none exist)
- **Output**: Prints the `<p:sldId>` element to add to `presentation.xml`'s `<p:sldIdLst>`
- **Notes cleanup**: Strips notesSlide relationships when duplicating slides
