## Summary

Non-interactive Google Workspace OAuth2 setup script designed for agent-driven workflows, supporting PKCE flow, scope validation, and live API health checks.

## Details

- Commands: `--check`, `--check-live`, `--client-secret`, `--auth-url`, `--auth-code`, `--revoke`, `--install-deps`
- PKCE flow with `google-auth-oauthlib`; stores pending state/code_verifier in `google_oauth_pending.json`
- Accepts full redirect URL or raw code for `--auth-code`; validates state match
- Handles partial scope grants: stores only actually-granted scopes to prevent `invalid_scope` on refresh
- `--check-live` makes a real Calendar API call to detect disabled clients/accounts
- Auto-installs `google-api-python-client`, `google-auth-oauthlib`, `google-auth-httplib2` if missing
- Token and client secret stored in HERMES_HOME; revocation calls Google's revoke endpoint
