## Summary

Standalone HERMES_HOME resolver that mirrors hermes_constants' API, enabling Google Workspace scripts to run outside the Hermes process without import dependencies.

## Details

- Tries to import `get_hermes_home` and `display_hermes_home` from `hermes_constants`; falls back to stdlib-only implementations if unavailable
- Fallback `get_hermes_home()`: reads `HERMES_HOME` env var, defaults to `~/.hermes`
- Fallback `display_hermes_home()`: shortens path relative to home directory using `~` prefix
- Designed for scripts that may run in system Python, Nix env, or CI where `hermes_constants` is not on `sys.path`
- All Google Workspace scripts in this directory import from this module instead of duplicating path resolution
