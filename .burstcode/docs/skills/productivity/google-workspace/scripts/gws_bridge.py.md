## Summary

Token refresh bridge that validates/refreshes the Google OAuth token, then execs the gws CLI with the access token injected as an environment variable.

## Details

- Reads token from `HERMES_HOME/google_token.json`; checks expiry timestamp
- If expired, performs direct HTTP POST to `token_uri` with refresh_token grant type (no google-auth dependency)
- Updates token file with new access token and recalculated expiry
- Injects `GOOGLE_WORKSPACE_CLI_TOKEN` env var before exec'ing `gws` with remaining CLI args
- `_normalize_authorized_user_payload()` ensures `type: authorized_user` field is present
- Uses `urllib.request` for token refresh — stdlib only, no external HTTP library
- Exits with gws return code; errors printed to stderr
