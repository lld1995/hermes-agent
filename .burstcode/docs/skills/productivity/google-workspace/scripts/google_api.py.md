## Summary

Comprehensive Google Workspace API CLI supporting Gmail, Calendar, Drive, Contacts, Sheets, and Docs — with dual execution paths via gws CLI or Python client libraries.

## Details

- Every command checks for `gws` binary first (`_gws_binary()`), falling back to `googleapiclient` Python libraries
- Gmail: search, get, send, reply, labels, modify — with MIMEText construction and base64 encoding
- Calendar: list, create, delete events with timezone-aware datetime handling
- Drive: search, get metadata, upload (multipart), download (with native export for Docs/Sheets/Slides), create folder, share, delete/trash
- Contacts: list connections with names, emails, phones
- Sheets: get, update, append values; create spreadsheets
- Docs: get text, create with optional body, append text via batchUpdate
- Token stored at `HERMES_HOME/google_token.json`; auto-refreshes expired tokens
- `_gws_env()` injects `GOOGLE_WORKSPACE_CLI_CREDENTIALS_FILE` for gws subprocess
