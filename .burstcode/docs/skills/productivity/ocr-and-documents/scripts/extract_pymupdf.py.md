## Summary

Lightweight document text extraction using pymupdf (~25MB, no ML models). Supports plain text, markdown, tables, images, and metadata extraction from PDFs with optional page range filtering.

## Details

- **Engine**: pymupdf + pymupdf4llm
- **Modes**: `--markdown` (LLM-friendly), `--tables` (pandas DataFrames), `--images` (PNG extraction), `--metadata` (JSON)
- **Page filtering**: `--pages 0-4` or `--pages 3` for selective extraction
- **Image extraction**: Converts CMYK images to RGB, saves as PNG with page/image indexing
- **Table extraction**: Uses pymupdf's `find_tables()` with pandas markdown output
- **Metadata**: Pages, title, author, subject, creator, producer, format
- **Lightweight**: No ML models, ~25MB footprint vs marker-pdf's ~5GB
- **Complementary**: Referenced by `extract_marker.py` as fallback when disk space is low
