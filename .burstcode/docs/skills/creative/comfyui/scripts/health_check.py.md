## Summary

Verifies ComfyUI environment readiness by checking CLI availability, server reachability, checkpoint presence, optional workflow dependencies, and an optional smoke test.

## Details

- Checks for `comfy` CLI or `uvx` fallback on PATH.
- Pings `/system_stats` and `/models/checkpoints` endpoints to verify server health and model availability.
- Optionally validates a specific workflow's dependencies via `check_deps`.
- Runs a minimal SD1.5 smoke test workflow, submitting and immediately cancelling it to verify round-trip execution without burning compute.
- Outputs a JSON report with `pass`, `warn`, or `fail` verdicts.
