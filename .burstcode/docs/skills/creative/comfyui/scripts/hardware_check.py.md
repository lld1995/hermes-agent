## Summary

Detects local machine capabilities (GPU, RAM, disk, OS, WSL/Rosetta) to determine if ComfyUI can run locally or should fallback to cloud. Outputs a structured JSON report with verdicts and CLI flags.

## Details

- Scans NVIDIA, AMD, Apple Silicon, and Intel Arc GPUs using platform-specific CLI tools (`nvidia-smi`, `rocm-smi`, `sysctl`, `clinfo`, PowerShell).
- Detects edge cases like WSL2, Rosetta translation on Apple Silicon, and low disk/RAM thresholds.
- Classifies hardware into `ok`, `marginal`, or `cloud` verdicts based on VRAM/Unified Memory thresholds.
- Optionally probes PyTorch for CUDA/MPS availability.
- Emits JSON or human-readable output; exit codes map to verdicts.
