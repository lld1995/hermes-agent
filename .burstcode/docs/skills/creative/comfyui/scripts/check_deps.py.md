## Summary

Verifies a ComfyUI workflow's dependencies (custom nodes, models, embeddings) against a running server, handling cloud vs local API differences, folder aliasing, and free-tier restrictions.

## Details

- Queries `/object_info` and `/models/<folder>` endpoints to enumerate installed nodes and models
- Handles ComfyUI's folder renames (e.g., `unet` → `diffusion_models`) via alias unioning
- Distinguishes 200-empty, 404, and 403 responses to avoid false positives on cloud free tiers
- Maps missing nodes to `comfy node install` commands or git URLs for manual installation
- Detects embedding references in prompt text and verifies them against server listings
- Outputs structured JSON with missing dependencies, remediation hints, and server readiness status
