## Summary

Standalone CLI that encrypts and uploads .excalidraw JSON files to excalidraw.com's public v2 API, returning a shareable URL with the decryption key embedded in the URL fragment.

## Details

- Encrypts diagram JSON client-side using AES-GCM (128-bit key, 12-byte nonce) before upload — server never sees plaintext
- Implements Excalidraw v2 concat-buffers binary format: version header followed by length-prefixed buffers
- Compresses inner payload with zlib, then wraps with encoding metadata (version, compression, encryption fields)
- Key is base64url-encoded (no padding) and appended to the URL fragment as `#json=<id>,<key>`
- Validates input is JSON with an `elements` key (warns but proceeds if missing)
- Requires `cryptography` package; exits with install instructions if absent
- Uses `urllib.request` for HTTP POST — no external HTTP library dependency
