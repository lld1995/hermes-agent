## Summary

Library of named RGB palettes (hardware and artistic) for pixel art generation, with a helper to build PIL-compatible palette images for quantization.

## Details

- Contains 20+ hardware palettes (NES, C64, GameBoy variants, PICO-8, ZX Spectrum, Apple II, CGA, MSX, Windows 16/256, Teletext) and 10 artistic palettes (Pastel Dream, Neon Cyber, Retro Warm, etc.)
- Each palette is a list of (R, G, B) tuples
- `build_palette_image(name)` creates a 1x1 PIL 'P'-mode image with the palette, padding to 768 bytes (256 colors) as PIL requires
- Used by `pixel_art.py` for named palette quantization via `Image.quantize(palette=...)`
