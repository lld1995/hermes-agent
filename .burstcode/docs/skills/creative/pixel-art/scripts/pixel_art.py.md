## Summary

Image-to-pixel-art converter using Floyd-Steinberg dithering, supporting both adaptive palettes and named hardware/artistic palettes via configurable presets.

## Details

- 14 presets: adaptive (arcade, snes) and hardware-accurate (nes, gameboy, pico8, c64, apple2, teletext, mspaint, mono_green, mono_amber, neon, pastel)
- Pipeline: contrast/color/sharpness enhancement → posterize → nearest-neighbor downscale by block size → Floyd-Steinberg quantization → nearest-neighbor upscale
- Quantization uses either adaptive N-color palette or named palette from `palettes.py` via `build_palette_image()`
- Imports `palettes` with try/except fallback for standalone vs package execution
- CLI supports `--preset`, `--palette` (int or name), and `--block` overrides
- Returns the resulting PIL.Image for programmatic use
