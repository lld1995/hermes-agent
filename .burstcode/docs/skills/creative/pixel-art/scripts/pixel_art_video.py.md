## Summary

Overlays procedural pixel animations (stars, rain, fireflies, etc.) onto a base image and encodes the result to MP4 and optionally GIF via ffmpeg.

## Details

- 12 animation layers: stars, fireflies, leaves, dust motes, sparkles, rain, lightning, bubbles, embers, snowflakes, neon pulse, heat shimmer
- 12 scene presets combining layers (night, dusk, tavern, urban, nature, magic, storm, underwater, fire, snow, desert)
- Each layer has `init_*` (randomized state) and `draw_*` (time-driven rendering) functions using deterministic `random.Random(seed)`
- Renders frames to a temp directory, then invokes ffmpeg for MP4 (libx264, CRF 18) and optional GIF (palettegen/paletteuse filter, scaled to 320px)
- Requires ffmpeg on PATH; raises RuntimeError if missing
- CLI and importable API (`pixel_art_video(base_image, output_path, scene, duration, fps, seed, export_gif)`)
