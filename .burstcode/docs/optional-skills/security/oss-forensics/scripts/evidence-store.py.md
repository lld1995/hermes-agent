## Summary

JSON-based evidence store manager for open-source security forensics. Supports adding, listing, verifying, querying, exporting, and summarizing evidence entries with SHA-256 integrity tracking and chain-of-custody logging.

## Details

- **Evidence types**: git, gh_api, gh_archive, web_archive, ioc, analysis, manual, vendor_report
- **IOC subtypes**: COMMIT_SHA, FILE_PATH, API_KEY, SECRET, IP_ADDRESS, DOMAIN, PACKAGE_NAME, etc.
- **Verification states**: unverified, single_source, multi_source_verified
- **Core operations**:
  - `add`: Creates entries with auto-generated IDs (EV-0001), SHA-256 content hashes, timestamps, and chain-of-custody records
  - `list`: Filters by type or actor
  - `verify`: Re-computes SHA-256 hashes and reports mismatches
  - `query`: Keyword search across content, source, actor, and URL fields
  - `export`: Generates Markdown tables for evidence and chain of custody
  - `summary`: Statistics by type, verification state, and unique actors
- **Storage**: Single JSON file with atomic read/write; handles corruption gracefully
- **CLI**: argparse-based with subcommands and optional flags
