## Summary

CLI tool querying the USDA FoodData Central API for nutritional information per 100g. Supports batch queries via CLI args or stdin, falling back to a demo key if `USDA_API_KEY` is unset.

## Details

- Fetches food data using `urllib` and parses nutrient values (calories, protein, fat, carbs, fiber, sugar).
- Handles rate limiting with a 1-second sleep between batch queries.
- Reads `USDA_API_KEY` from environment, defaults to `DEMO_KEY`.
- Outputs formatted text blocks for each matched food item.
- Stdlib-only, minimal error handling for API failures.
