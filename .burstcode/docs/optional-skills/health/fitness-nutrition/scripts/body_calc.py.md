## Summary

Standalone fitness calculator CLI computing BMI, TDEE, one-rep max, macros, and body fat percentage using standard formulas. Outputs human-readable text for direct user consumption or agent relay.

## Details

- Subcommands: `bmi`, `tdee`, `1rm`, `macros`, `bodyfat`.
- Uses Mifflin-St Jeor for BMR/TDEE, Epley/Brzycki/Lombardi for 1RM, and US Navy formula for body fat.
- Calculates macro splits based on cut/maintain/bulk goals.
- Stdlib-only, parses positional arguments manually via `sys.argv`.
- Prints formatted tables and training percentages.
