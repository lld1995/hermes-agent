## Summary

A DCF Excel model validator that checks for formula errors, verifies terminal growth < WACC, validates WACC ranges, and assesses terminal value proportions using openpyxl.

## Details

- Loads workbook twice: once for formulas, once for computed values (`data_only=True`)
- Scans all sheets for Excel error strings (`#DIV/0!`, `#REF!`, etc.)
- Heuristic cell scanning to locate terminal growth, WACC, and enterprise values
- Flags critical errors (terminal growth >= WACC) and warnings (unusual WACC/terminal proportions)
- Outputs structured JSON results with pass/fail status for agent consumption
