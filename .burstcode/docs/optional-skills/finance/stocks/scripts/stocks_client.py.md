## Summary

Stdlib-only CLI for fetching stock and crypto market data via Yahoo Finance and Alpha Vantage. Provides commands for quotes, search, history, comparison, and crypto prices, handling session cookies and exponential backoff.

## Details

- Implements HTTP layer with retry logic, exponential backoff, and Yahoo Finance crumb/cookie management.
- Commands: `quote`, `search`, `history`, `compare`, `crypto`.
- Extracts and formats financial metrics (PE, market cap, 52w ranges) from nested JSON responses.
- Optionally enriches data using `ALPHA_VANTAGE_KEY` environment variable.
- Outputs structured JSON for agent parsing.
