## Summary

A utility script that recalculates Excel formulas in `.xlsx` files using headless LibreOffice, solving the problem of openpyxl writing formulas without computing values.

## Details

- Locates `libreoffice` or `soffice` on PATH and runs headless conversion
- Converts the input file to a temporary directory, then copies the recomputed file back
- Handles timeouts and subprocess errors gracefully, returning status JSON
- Designed to bridge the gap between openpyxl formula writing and downstream `data_only=True` reads
- Exits with appropriate codes and prints JSON status for pipeline integration
