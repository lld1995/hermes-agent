## Summary

Zero-dependency CLI tool for querying Hyperliquid perpetual and spot markets, account states, and trade history. Features custom .env loading, formatted table rendering, and post-trade PnL review analytics.

## Details

- Queries Hyperliquid's `/info` endpoint for market data, order books, funding rates, and user positions/fills.
- Implements 12 subcommands (`dexs`, `markets`, `spots`, `candles`, `funding`, `l2`, `state`, `spot-balances`, `fills`, `orders`, `review`, `export`) with flexible sorting and filtering.
- Defaults to human-readable ASCII table output, with a `--json` flag for raw data export.
- Includes a `review` command that calculates realized PnL, win rates, directional bias, and market context alignment.
- Parses `.env` files from the project root and `~/.hermes/.env` to resolve `HYPERLIQUID_API_URL` and user addresses, bypassing standard environment inheritance.
