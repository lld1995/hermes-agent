## Summary

A meme generation CLI that overlays text on template images using Pillow, supporting curated templates, Imgflip API lookups, and custom image inputs with automatic font scaling and text wrapping.

## Details

- Resolves templates by curated ID, slugified name, or Imgflip API ID
- Caches Imgflip template list and downloaded images locally for 24 hours
- Auto-scales font size and wraps text to fit within defined percentage-based fields
- Supports overlay mode (custom positioning) and bar mode (top/bottom text strips)
- Handles RGBA to RGB conversion for JPEG output and finds system fonts with fallbacks
