## Summary

A polling monitor for running Kanban video pipelines that detects stuck tasks, overtime execution, and repeated retries by querying the `hermes kanban` CLI.

## Details

- Polls `hermes kanban list --tenant <slug> --json` at configurable intervals
- Falls back to plain-text parsing if JSON output is unavailable
- Detects issues: missing heartbeats (>2 min), exceeded `max_runtime_s`, and flapping retries (>=2)
- Prints periodic status snapshots to stdout and alerts to stderr
- Designed for human/AI oversight rather than automatic task restarts
