## Summary

Zero-dependency Node.js reverse proxy for GitNexus. Serves a static production web UI from a dist directory and proxies `/api/*` requests to a backend server. Handles SPA fallback routing.

## Details

- **Static serving**: Maps file extensions to MIME types, serves files from a configurable dist directory
- **SPA fallback**: If a requested path doesn't exist and has no extension, serves `index.html`
- **API proxy**: Forwards `/api/*` requests to `127.0.0.1:${API_PORT}` (default 4747), preserving method, headers, and body
- **Error handling**: Returns 502 with a helpful message if the backend is unreachable
- **Caching**: Sets `no-cache` for HTML, `public, max-age=86400` for static assets
- **Config**: `DIST_DIR` from argv[2], `PORT` from argv[3] (default 8888), `API_PORT` from env (default 4747)
- Uses only Node.js built-in modules (`http`, `fs`, `path`)
