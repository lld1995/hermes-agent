## Summary

Batch Lipinski Rule-of-5 and Veber criteria screening tool using the PubChem PUG REST API. Accepts compound names via CLI args or stdin, fetches molecular properties, and reports pass/fail status.

## Details

- Queries PubChem PUG API for molecular properties: MW, XLogP, HBD, HBA, RotatableBondCount, TPSA
- **Ro5 check**: Counts violations (MW>500, LogP>5, HBD>5, HBA>10); passes if ≤1 violation
- **Veber check**: TPSA≤140 and RotatableBonds≤10
- **Combined pass**: Ro5 pass AND Veber pass
- Reads compound names from CLI args or stdin (if `-` or no args)
- Prints formatted table with status, compound name, properties, and violation flags
- Includes 0.3s sleep between API calls to respect rate limits
- No external dependencies beyond stdlib
