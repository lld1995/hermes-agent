## Summary

CLI tool that searches the ChEMBL database for a biological target and retrieves top active compounds. Queries EBI's REST API for target metadata and activity data, filtering by minimum pChEMBL value.

## Details

- Queries `https://www.ebi.ac.uk/chembl/api/data` for target search and activity endpoints
- Accepts a target name (e.g., "EGFR"), optional `--min-pchembl` threshold (default 6.0), and `--limit` (default 10)
- Fetches target metadata (pref_name, target_type, organism) then retrieves activities with `assay_type=B`
- Deduplicates molecules by `molecule_chembl_id`, prints a formatted table with pChEMBL value, standard_type, standard_value, and units
- Includes 0.1s sleep between compound prints to respect API rate limits
- No external dependencies beyond stdlib
