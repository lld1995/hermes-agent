## Summary

Passive OSINT CLI tool for domain intelligence gathering using only Python stdlib. Supports subdomain discovery via crt.sh, SSL certificate inspection, WHOIS lookups, DNS record resolution, and domain availability checks. Outputs structured JSON.

## Details

- **Subdomain discovery**: Queries crt.sh Certificate Transparency logs, filters expired certs, deduplicates and sorts results
- **SSL inspection**: Connects via TLS, extracts certificate metadata (subject, issuer, SANs, expiry), handles verification errors gracefully by retrying with CERT_NONE
- **WHOIS lookup**: Maintains a hardcoded map of ~50 TLD-to-server mappings, parses raw WHOIS responses with regex patterns for registrar, dates, name servers, status
- **DNS records**: Uses `socket.getaddrinfo` for A/AAAA, Google DoH API for MX/NS/TXT/CNAME
- **Availability check**: Combines DNS, SSL reachability, and WHOIS signals into a verdict (LIKELY AVAILABLE / REGISTERED / UNCERTAIN) with confidence levels
- **Bulk mode**: Runs multiple checks across multiple domains in parallel via `ThreadPoolExecutor` (max 10 workers)
- **CLI**: Single-file entry point with subcommands; all output is JSON
