## Summary

A generic JSON endpoint watcher that polls any REST API, extracts items via dotted path navigation, deduplicates by a configurable ID field, and renders Markdown output.

## Details

- Accepts `--url`, `--items-path` (dotted JSON navigation), and `--id-field` arguments
- Supports custom HTTP headers via repeatable `--header KEY: VALUE` flags
- Filters out non-dict items defensively before passing to the watermark system
- Uses `_watermark.Watermark` for state persistence and deduplication
- Outputs Markdown via `format_items_as_markdown` with configurable title/url/body fields
