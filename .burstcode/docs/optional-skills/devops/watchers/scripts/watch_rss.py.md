## Summary

An RSS/Atom feed watcher that parses XML feeds, extracts entries, deduplicates using the watermark system, and outputs new items as Markdown for cron delivery.

## Details

- Handles both RSS 2.0 `<item>` and Atom `<entry>` tags with namespace stripping
- Extracts `guid`/`id`, `title`, `link`/`href`, and `description`/`summary` fields
- Falls back to URL as ID if no GUID is present, skipping items without identifiers
- Uses `_watermark.Watermark` for deduplication and baseline establishment
- Configurable `--max` and `--with-summary` flags for output control
