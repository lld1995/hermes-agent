## Summary

A GitHub activity watcher that polls issues, PRs, releases, or commits via the REST API, deduplicates using the watermark system, and outputs new items as Markdown.

## Details

- Supports `--repo` (scoped polling) and `--search` (GitHub search API) modes
- Flattens nested commit/issue/release JSON into uniform `{id, title, url, body}` dicts
- Reads `GITHUB_TOKEN` or `GH_TOKEN` from environment to bypass rate limits
- Uses `_watermark.Watermark` for deduplication and `format_items_as_markdown` for output
- Configurable `--per-page`, `--max`, and `--with-body` flags for cron tuning
