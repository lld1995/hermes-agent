## Summary

A shared state management module for watcher scripts that tracks seen item IDs to prevent duplicate emissions across cron runs, using atomic JSON file writes.

## Details

- `Watermark` class persists a bounded list of seen IDs to `$HERMES_HOME/watcher-state/`
- `filter_new()` returns only unseen items and updates the in-memory state
- First run records all IDs but emits nothing (baseline establishment)
- Uses atomic `.tmp` + `os.replace()` writes to prevent corruption on crash
- Includes `format_items_as_markdown()` helper for rendering cron output
