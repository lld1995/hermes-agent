## Summary

CLI wrapper for the Canvas LMS REST API. Authenticates via personal access token and provides commands to list enrolled courses and course assignments with pagination support.

## Details

- Reads `CANVAS_API_TOKEN` and `CANVAS_BASE_URL` from environment variables.
- Implements `_paginated_get` to follow `Link` headers for complete result fetching.
- Commands: `list_courses` (filters by enrollment state) and `list_assignments` (orders by field).
- Truncates assignment descriptions to 500 characters.
- Outputs structured JSON, requires `requests` library.
