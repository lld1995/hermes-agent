## Summary

FastMCP server template for wrapping external REST APIs. Defines tools for health checks, resource retrieval, and searching, configured via environment variables for base URL, token, and timeout.

## Details

- Uses `httpx` for synchronous HTTP requests with configurable timeouts.
- Injects Bearer token authorization if `API_TOKEN` is set.
- Exposes `health_check`, `get_resource`, and `search_resources` tools.
- Structured for easy adaptation to specific upstream API schemas.
- Requires `fastmcp` and `httpx` dependencies.
