## Summary

Read-only SQLite MCP server template. Provides tools to list tables, describe schemas, and execute parameterized SELECT queries with strict mutation rejection and row limits.

## Details

- Connects to SQLite in read-only mode (`mode=ro`).
- Validates table names against a strict alphanumeric regex.
- Wraps user SQL in a subquery with a configurable `LIMIT` to prevent excessive data returns.
- Rejects non-SELECT statements explicitly.
- Returns column names and rows as dictionaries.
