## Summary

MCP server template for local text file operations. Offers tools to summarize files, search for text matches, and expose file contents as MCP resources.

## Details

- Reads UTF-8 text files using `pathlib`, handling `FileNotFoundError` and `UnicodeDecodeError`.
- `summarize_text_file` returns character/line counts and a preview.
- `search_text_file` performs case-insensitive line matching with a max match limit.
- `read_file_resource` exposes file content via MCP resource protocol.
- Stdlib-only except for `fastmcp`.
