## Summary

## Details

### model_tools.py

**Purpose:** Central tool orchestration — discovery, schema generation, argument coercion, and dispatch.

**Async Bridging:**
- **`_get_tool_loop()`** — Persistent event loop for the main CLI thread, preventing "Event loop is closed" errors on cached httpx/AsyncOpenAI client GC.
- **`_get_worker_loop()`** — Per-worker-thread persistent loop via `threading.local()`.
- **`_run_async()`** — Three-path dispatcher: (1) inside running loop → spawn disposable thread with its own loop + 300s timeout + cancellation; (2) worker thread → use per-thread persistent loop; (3) main thread → use shared persistent loop.

**Tool Discovery:**
- `discover_builtin_tools()` called at module level.
- `discover_plugins()` wrapped in try/except for fail-open behavior.
- MCP discovery removed from module level (was blocking gateway startup for up to 120s).

**Schema Generation (`get_tool_definitions`):**
- Memoized on `(enabled_toolsets, disabled_toolsets, registry._generation, config_mtime)`.
- Returns shallow copy to prevent cache poisoning from downstream mutations.
- Dynamic schema rebuilding for `execute_code` (sandbox tool filtering), `discord`/`discord_admin` (intent-based), and `browser_navigate` (web tool cross-reference stripping).
- Final pass through `tools.schema_sanitizer.sanitize_tool_schemas()` for llama.cpp compatibility.

**Argument Coercion (`coerce_tool_args`):**
- Handles string→integer/number/boolean/array/object coercion.
- Wraps bare scalars in lists when schema expects array.
- Guards against `inf`/`nan` (not JSON-serializable).
- Parses JSON-encoded strings for array/object types.

**Dispatch (`handle_function_call`):**
- Intercepts `_AGENT_LOOP_TOOLS` (todo, memory, session_search, delegate_task) with stub errors.
- Fires `pre_tool_call` hook (block directive support) unless `skip_pre_tool_call_hook=True`.
- Measures `duration_ms` via `time.monotonic()`.
- Fires `post_tool_call` and `transform_tool_result` hooks.
- Fail-open on all hook invocations.
