## Summary

Implements progressive-disclosure skill tools (skills_list, skill_view) that scan local and external skill directories, parse YAML frontmatter, check platform compatibility, validate prerequisites, and serve content with security guards against path traversal and prompt injection.

## Skills Tool Module

- **Core tools**: `skills_list` returns minimal metadata (name, description, category); `skill_view` loads full SKILL.md content, linked files, and prerequisite state.
- **Directory scanning**: Recursively searches `~/.hermes/skills/` and configured `external_dirs`; supports categorized paths (`category/skill`) and legacy flat `.md` files.
- **Plugin skills**: Qualified names (`namespace:skill`) route to the plugin manager; plugin skills get bundle-context banners and sibling skill hints.
- **Frontmatter parsing**: Delegates to `agent.skill_utils.parse_frontmatter`; extracts name, description, tags, related_skills, platforms, prerequisites, and `required_environment_variables`.
- **Prerequisite resolution**: Normalizes legacy `prerequisites.env_vars` and modern `required_environment_variables`/`setup.collect_secrets` into a unified list; checks persistence via `load_env()` and `os.getenv()`.
- **Secret capture**: Uses `_secret_capture_callback` (set externally) to prompt for missing env vars; skips capture on gateway surfaces and falls back to manual `.env` instructions.
- **Security guards**: Blocks path traversal via `tools.path_security.validate_within_dir`; scans content against `_INJECTION_PATTERNS`; warns on skills outside trusted directories.
- **Remote sandbox integration**: Registers available env vars with `tools.env_passthrough.register_env_passthrough` and credential files with `tools.credential_files.register_credential_files` for Modal/Docker/SSH backends.
- **Telemetry**: `_skill_view_with_bump` wrapper calls `tools.skill_usage.bump_view` and `bump_use` on successful loads.
- **Collision detection**: Collects all candidate SKILL.md files across directories; refuses ambiguous names and surfaces explicit paths to the caller.
