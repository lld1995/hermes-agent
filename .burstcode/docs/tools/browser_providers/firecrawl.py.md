## Summary

Firecrawl cloud browser provider with direct API key authentication. Creates ephemeral browser sessions with configurable TTL, returning CDP URLs for agent interaction. Simple lifecycle with POST creation and DELETE cleanup.

## Details

- Minimal provider requiring only `FIRECRAWL_API_KEY`.
- Configurable session TTL via `FIRECRAWL_BROWSER_TTL` env var (default 300s).
- Creates sessions via POST to `/v2/browser`; closes via DELETE.
- Emergency cleanup catches `ValueError` for missing credentials and swallows other exceptions.
- Returns standardized session dict with `cdp_url` and `firecrawl` feature flag.
