## Summary

Browserbase cloud browser provider using direct credentials. Supports optional paid features (proxies, stealth, keep-alive) with automatic 402 fallback retry logic. Manages session lifecycle via POST/DELETE to Browserbase API.

## Details

- Direct-credential-only provider requiring `BROWSERBASE_API_KEY` and `BROWSERBASE_PROJECT_ID`.
- Reads optional env vars for `proxies`, `advanced_stealth`, `keep_alive`, and `session_timeout`.
- Implements progressive 402 fallback: retries session creation without `keepAlive`, then without `proxies`, logging warnings for degraded capabilities.
- Creates sessions via POST to `/v1/sessions`; closes via POST with `status: REQUEST_RELEASE`.
- Returns feature-enabled flags in the session dict so downstream tools know which capabilities are active.
