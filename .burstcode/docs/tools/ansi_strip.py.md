## Summary

Strips ANSI escape sequences from subprocess output to prevent terminal control codes from polluting the model's context window.

## Details

- Covers the full ECMA-48 spec: CSI, OSC, DCS/SOS/PM/APC strings, nF, Fp/Fe/Fs, and 8-bit C1 controls.
- Uses a fast-path regex check to skip full substitution when no escape bytes are present.
- Integrated into `terminal_tool`, `code_execution_tool`, and `process_registry` output pipelines.
- Prevents models from copying escape sequences into file writes or tool arguments.
