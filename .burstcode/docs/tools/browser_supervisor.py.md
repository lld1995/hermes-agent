## Summary

Persistent CDP WebSocket supervisor managing browser dialogs, frame trees, and console events per task. Injects a dialog bridge script to intercept alert/confirm/prompt calls, supports configurable auto-dismiss/accept policies, and provides thread-safe snapshots for tool handlers.

## Details

- Runs one `CDPSupervisor` per `task_id` on a dedicated daemon thread with its own asyncio loop.
- Injects `_DIALOG_BRIDGE_SCRIPT` via `Page.addScriptToEvaluateOnNewDocument` to override native dialogs with sync XHRs intercepted by `Fetch.enable`.
- Supports three dialog policies: `must_respond`, `auto_dismiss`, `auto_accept`, with watchdog timers for unhandled dialogs.
- Tracks frame tree (capped at 30 entries, 2 OOPIF depth), console events (50-entry ring buffer), and recent dialogs.
- Provides thread-safe `snapshot()` and `respond_to_dialog()` APIs; reconnects WebSocket with exponential backoff on drops.
