## Details

### `tools/debug_helpers.py`

**Purpose:** Consolidates debug session boilerplate previously duplicated across `web_tools`, `vision_tools`, `mixture_of_agents_tool`, and `image_generation_tool`.

**Key features:**
- **Environment activation:** `DebugSession(tool_name, env_var="...")` checks `os.getenv(env_var)` — all methods are cheap no-ops when disabled.
- **Call logging:** `log_call(call_name, call_data)` appends timestamped entries to an in-memory list. Zero overhead when disabled.
- **JSON persistence:** `save()` writes `{session_id, start_time, end_time, total_calls, tool_calls}` to `HERMES_HOME/logs/<tool_name>_debug_<uuid>.json`.
- **Session info:** `get_session_info()` returns a summary dict for external callers (e.g., tool status endpoints).
- **UUID scoping:** Each enabled session gets a unique `session_id` to prevent log file collisions.

**Usage pattern:** Tool modules instantiate `_debug = DebugSession("web_tools", env_var="WEB_TOOLS_DEBUG")` and call `_debug.log_call()` / `_debug.save()` at appropriate points.
