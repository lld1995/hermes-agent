## Summary

A multi-backend terminal execution tool supporting local, Docker, Modal, and Vercel Sandbox environments. It provides safe environment variable parsing, Vercel credential validation, disk usage monitoring, and thread-local sudo password caching to isolate concurrent ACP sessions.

## Details

- **Multi-Backend Execution**: Routes commands to local, Docker, Modal, SSH, Singularity, Daytona, or Vercel Sandbox based on the `TERMINAL_ENV` variable.
- **Safe Config Parsing**: `_safe_parse_import_env` prevents import-time crashes from malformed numeric environment variables, ensuring module stability across CLI, ACP, and test contexts.
- **Vercel Sandbox Validation**: `_check_vercel_sandbox_requirements` enforces supported runtimes, fixed disk limits, and strict credential triads (`VERCEL_TOKEN`, `PROJECT_ID`, `TEAM_ID`) or OIDC fallbacks.
- **Disk Monitoring**: `_check_disk_usage_warning` recursively scans `hermes-*` scratch directories and logs warnings when usage exceeds the `TERMINAL_DISK_WARNING_GB` threshold.
- **Session-Scoped Sudo Cache**: `_sudo_password_cache` uses thread-local/session-key scoping to prevent password leakage across concurrent ACP sessions, addressing `GHSA-qg5c-hvr5-hjgr`.
