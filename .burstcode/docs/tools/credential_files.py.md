## Details

### `tools/credential_files.py`

**Purpose:** Ensures credential files, skill directories, and host-side cache directories are mounted or synced into remote sandbox backends.

**Key features:**
- **Session-scoped registry:** Uses `ContextVar` (`_registered_files_var`) to prevent cross-session data bleed in the gateway pipeline. `register_credential_file()` adds files relative to `HERMES_HOME`.
- **Path security:** Rejects absolute paths and traversal sequences (`..`). Uses `tools.path_security.validate_within_dir()` to enforce containment within `HERMES_HOME`. Resolves symlinks before containment checks.
- **Skill directory mounting:** `get_skills_directory_mount()` returns bind-mount info. Detects symlinks via `rglob`; if found, creates a sanitized temp copy (regular files only) to prevent symlink escape attacks.
- **Cache directories:** Mirrors `cache/documents`, `cache/images`, `cache/audio`, `cache/screenshots` into sandboxes. `to_agent_visible_cache_path()` translates host paths to container paths for Docker backends.
- **Config-based files:** `_load_config_files()` reads `terminal.credential_files` from `config.yaml`, applying the same traversal guards.
- **Iterators:** `iter_skills_files()` and `iter_cache_files()` yield individual file entries for backends that upload files individually (Modal, Daytona) rather than bind-mounting directories.

**State:** `_config_files` cached per-process. `_safe_skills_tempdir` reused across calls with `atexit` cleanup.
