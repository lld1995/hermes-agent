## Details

### `tools/cronjob_tools.py`

**Purpose:** Single compressed tool for managing scheduled cron jobs — create, list, update, pause, resume, remove, trigger.

**Key features:**
- **Prompt injection scanner:** `_scan_cron_prompt()` blocks invisible unicode, prompt injection patterns (`ignore previous instructions`), deception, secret exfiltration (`curl`/`wget` with tokens), and destructive commands. Allows GitHub API auth headers as a narrow exception.
- **Script path validation:** `_validate_cron_script_path()` rejects absolute paths and `~` expansion. Uses `tools.path_security.validate_within_dir()` to enforce containment within `HERMES_HOME/scripts/`.
- **Model override pinning:** `_resolve_model_override()` pins the current main provider when only a model name is supplied, preventing drift when the user later changes defaults. Bare `"custom"` provider is treated as missing.
- **Delivery normalization:** `_normalize_deliver_param()` flattens list/tuple inputs (from MCP clients) into comma-separated strings to prevent serialization artifacts.
- **Context chaining:** `context_from` references other job IDs; validates existence before storage. Injects most recent completed output as context.
- **No-agent mode:** `no_agent=True` skips the LLM entirely — runs `script` on schedule and delivers stdout verbatim. Requires a script; `prompt`/`skills` are ignored.
- **Origin tracking:** `_origin_from_env()` captures `HERMES_SESSION_PLATFORM`/`CHAT_ID`/`THREAD_ID` for delivery routing.

**State:** Imports from `cron.jobs` for persistence. Uses `gateway.session_context.get_session_env()` for origin capture.
