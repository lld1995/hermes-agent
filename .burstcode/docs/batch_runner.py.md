## Summary

Parallel batch processing engine that runs the AIAgent across dataset prompts with multiprocessing, checkpointing, and content-based resume. Extracts tool usage and reasoning statistics, normalizes schemas for HuggingFace compatibility, and merges per-batch JSONL outputs into a unified trajectories file.

## Details

- Loads JSONL datasets, splits into configurable batches, and processes them via `multiprocessing.Pool`
- Supports resume via content-matching against existing `batch_*.jsonl` files, not just index tracking
- Per-prompt container image overrides registered via `tools.terminal_tool.register_task_env_overrides` for Docker/Modal/Singularity/Daytona
- Samples toolsets per prompt from `toolset_distributions` rather than using a fixed set
- Extracts tool stats (count/success/failure) and reasoning coverage from message histories
- Normalizes tool stats against `model_tools.TOOL_TO_TOOLSET_MAP` to ensure consistent Arrow/Parquet schemas
- Discards trajectories with zero reasoning across all assistant turns
- Incremental checkpoint writes via `utils.atomic_json_write` with a `multiprocessing.Lock`
- Combines all batch files into `trajectories.jsonl`, filtering entries with hallucinated tool names
- CLI via `fire.Fire(main)` with provider routing, reasoning effort, and prefill message support
